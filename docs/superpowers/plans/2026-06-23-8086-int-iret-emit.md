## Scope

`CD` INT imm8, `CC` INT3 (vector 3), `CE` INTO (vector 4 iff OF set), `CF` IRET. Transcribes
`InterruptExecute` + `RaiseInterrupt` (`src/CpuEmulator.Cpus.M8086/M8086Cpu.Interrupt.cs:54/39`)
one-for-one. **BOUND (`62`/`63`) stays fallback** (out of #4 scope — §4 of the spec). All four ops change
CS:IP → each ENDS the block (DECISION II-1).

## The shipped scaffolding this reuses (verified file:line)

  inside the shared helper.

- The shared `EmitM8086RaiseInterrupt(ctx, vector)` (Row MD Task 3 — the IVT push: PushWord FLAGS, clear
  IF/TF, PushWord CS, PushWord IP, load CS:IP from `[0:vector*4]`). Plus `M8086FlagIF`/`M8086FlagTF`/
  `M8086FlagOF` consts (MD adds IF/TF; OF already at `:40`).
- The decode preamble (scan prefixes; the imm8 for `CD` rides `r.X86.Imm` OR the const reads via
  `M8086CodePhys` — the arm uses the same emit-time read as the other arms).
- The discriminator-counter pattern (`BlockCompiler.cs:60-83`) + Register-case routing (`:670-705`) + the
  endsBlock re-force (`CpuEmitter.cs:4909-4910`).
- The 8086 reserved-bit forcing: `FlagsDefinedMask` (0x0FD5) + `FlagsForcedBits` (0xF002) — Interrupt.cs:84
  (POPF/IRET force the nine defined bits + the reserved 1s/0s). The arm reads these as compile-time
  constants (mirror the interpreter's `FlagsDefinedMask`/`FlagsForcedBits` — confirm the exact field

## Task 2 — the INT n / INT3 arm (the frame + vector + block-end)

**Test first** — `Int_n_emits_pushes_frame_and_vectors` (Task 1) + `Int3_vectors_through_vector_3`.

**Then** `EmitM8086Interrupt` with the decode preamble. The crux (Interrupt.cs:16/58-59): the pushed IP
is the RETURN ip — so the arm advances IP past the instruction FIRST (mirroring `Step`'s `IP += length`
before dispatch), THEN raises:

```csharp
/// <summary>Row II: emit one 8086 soft-interrupt instruction (CD/CC/CE/CF). Transcribes InterruptExecute
/// (Interrupt.cs:54) one-for-one. INT n / INT3 advance IP to the return point (IP += length) THEN raise via
/// the shared EmitM8086RaiseInterrupt (the pushed IP must be the return ip — Interrupt.cs:58-59). INTO
/// raises vector 4 ONLY when OF is set. IRET pops IP:CS:FLAGS (the reverse of the entry push), forcing the
/// 8086 reserved bits. Every form changes CS:IP → ENDS the block (DECISION II-1): each path exits via
/// EmitNormalExit. The default throws (the gate↔arm lockstep tripwire).</summary>
private void EmitM8086Interrupt(EmitContext ctx, ushort pc, OpcodeDescriptor d, int length, byte x86Seg)
{
    ILGenerator il = ctx.Il;
    int opcodePc = pc;
    while (M8086IsPrefixByte(_bus.Read8(M8086CodePhys((ushort)opcodePc)))) opcodePc++;
    byte opcode = _bus.Read8(M8086CodePhys((ushort)opcodePc));
    int operandPc = opcodePc + 1;
    ushort returnIp = (ushort)(pc + length);

    switch (opcode)
    {
        case 0xCD:   // INT imm8 — vector = the imm8 (a compile-time constant from the code stream).
        {
            byte vector = _bus.Read8(M8086CodePhys((ushort)operandPc));
            EmitM8086SetIp(ctx, returnIp);                 // IP = return point (the pushed IP)
            EmitM8086RaiseInterrupt(ctx, vector);          // PushWord FLAGS:CS:IP, clear IF/TF, vector
            EmitNormalExit(ctx);                            // DYNAMIC vectored CS:IP — ends the block
            return;
        }
        case 0xCC:   // INT3 — vector 3 (fixed).
        {
            EmitM8086SetIp(ctx, returnIp);
            EmitM8086RaiseInterrupt(ctx, 3);
            EmitNormalExit(ctx);
            return;
        }
        case 0xCE: EmitM8086Into(ctx, returnIp); return;   // Task 3
        case 0xCF: EmitM8086Iret(ctx); return;             // Task 4
        default:
            throw new EmulationException(
                $"BlockCompiler: no 8086 interrupt emit branch for opcode 0x{opcode:X2}; "
              + "the gate (IsEmittableX86Family) admitted a form the arm does not handle — a lockstep bug.");
    }
}
```

> **TDD-shaping note (bounded, mine):** the `CD` vector can come from `r.X86.Imm` (the decoder already
> captures it — the interpreter reads `r.X86.Imm` at Interrupt.cs:61) OR from the emit-time const read
> shown above. Both are compile-time constants; the const read via `M8086CodePhys` is consistent with the
> other arms (MOV/ALU read imm via `M8086CodePhys`), so use it. The `EmitM8086SetIp(returnIp)` BEFORE the
> raise is load-bearing — `EmitM8086RaiseInterrupt` pushes `_fpc`, so `_fpc` must hold the return ip at
> that point. The frame-byte memcmp test catches a wrong pushed IP.

Run INT n + INT3 tests green.

## Task 3 — INTO (conditional on OF)

**Test first** — `Into_with_of_set_vectors` (OF=1 → vector 4, frame pushed) + `Into_without_of_is_noop`
(OF=0 → no push, IP advanced past the 1-byte op, block ends).

**Then** `EmitM8086Into` — transcribes the `CE` case (Interrupt.cs:71-73): `if ((FLAGS & OF) != 0)
RaiseInterrupt(4)`. Both paths end the block (DECISION II-1 — the not-taken path falls through to the
exit under the unchanged CS:IP):

```csharp
/// <summary>Row II: CE INTO — interrupt-on-overflow (Interrupt.cs:71). Raises vector 4 ONLY when OF is set;
/// otherwise a no-op (IP already at the return point). Both paths END the block (DECISION II-1): the taken
/// path vectors + exits; the not-taken path sets IP to the return point + exits under the unchanged CS:IP.</summary>
private void EmitM8086Into(EmitContext ctx, ushort returnIp)
{
    ILGenerator il = ctx.Il;
    Label noVector = il.DefineLabel();
    // if ((FLAGS & OF) == 0) goto noVector;
    il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, _m8086FLAGS!); il.Emit(OpCodes.Ldc_I4, M8086FlagOF); il.Emit(OpCodes.And);
    il.Emit(OpCodes.Brfalse, noVector);
    // OF set: vector 4 (the pushed IP is the return point).
    EmitM8086SetIp(ctx, returnIp);
    EmitM8086RaiseInterrupt(ctx, 4);
    EmitNormalExit(ctx);
    // not taken: IP = return point, end the block.
    il.MarkLabel(noVector);
    EmitM8086SetIp(ctx, returnIp);
    EmitNormalExit(ctx);
}
```

> **TDD-shaping note (bounded, mine):** `EmitNormalExit` ends with `ret`, so the taken path's exit does
> not fall through to `noVector` — the `Brfalse` is the only way into `noVector`. The not-taken `INTO` is
> endsBlock=true (it exits the block under the unchanged CS:IP — the next instruction dispatches normally);
> this is the simplest correct choice (one chain-edge round-trip for the rare not-taken INTO). The OF=0
> test pins that IP is at the return point and the block ends cleanly.

Run both INTO tests green.

## Task 4 — IRET (pop IP:CS:FLAGS + reserved-bit forcing)

**Test first** — `Iret_pops_ip_cs_flags_and_forces_reserved_bits`: seed a far+flags frame at SS:SP
(IP lo, CS, FLAGS) including the corpus case `popped 0x28CF → FLAGS 0xF8C7` (Interrupt.cs:78), assert
CS/IP/SP/FLAGS byte-identical to the interpreter.

**Then** `EmitM8086Iret` — transcribes the `CF` case (Interrupt.cs:80-86): pop IP, pop CS, pop FLAGS with
the `(popped & FlagsDefinedMask) | FlagsForcedBits` forcing:

```csharp
/// <summary>Row II: CF IRET — pop IP, then CS, then FLAGS (the reverse of the entry push; Interrupt.cs:80).
/// FLAGS applies the 8086 reserved-bit forcing (the same as POPF): only the nine DEFINED bits take the
/// popped value; the reserved bits force to 1/0 — FLAGS = (popped & FlagsDefinedMask) | FlagsForcedBits.
/// The popped CS:IP is DYNAMIC → ends the block via EmitNormalExit.</summary>
private void EmitM8086Iret(EmitContext ctx)
{
    ILGenerator il = ctx.Il;
    EmitM8086PopWord(ctx); EmitM8086SetIpFromStack(ctx);   // IP = PopWord()
    EmitM8086PopWord(ctx); EmitM8086SetCsFromStack(ctx);   // CS = PopWord()
    // FLAGS = (PopWord() & FlagsDefinedMask) | FlagsForcedBits.
    EmitM8086PopWord(ctx);                                  // popped FLAGS on the stack
    il.Emit(OpCodes.Ldc_I4, M8086FlagsDefinedMask); il.Emit(OpCodes.And);
    il.Emit(OpCodes.Ldc_I4, M8086FlagsForcedBits);  il.Emit(OpCodes.Or);
    il.Emit(OpCodes.Conv_U2); il.Emit(OpCodes.Stloc, ctx.DataLocal);
    il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldloc, ctx.DataLocal); il.Emit(OpCodes.Stfld, _m8086FLAGS!);
    EmitNormalExit(ctx);                                   // DYNAMIC popped CS:IP — ends the block
}
```

> **TDD-shaping note (bounded, mine):** add the two constants beside the flag masks (`:35`):
> `private const int M8086FlagsDefinedMask = 0x0FD5;` and `private const int M8086FlagsForcedBits =
> 0xF002;` — confirm the EXACT values against `M8086Cpu`'s `FlagsDefinedMask`/`FlagsForcedBits` (grep
> them; the spec comment Interrupt.cs:77 says "bits 12-15 + bit 1 force to 1 (0xF002), bits 3 & 5 force
> to 0" and "the nine defined bits mask 0x0FD5"). The `popped 0x28CF → 0xF8C7` test is the exact oracle
> for these two constants — if either is wrong, that case fails. `EmitM8086PopWord` leaves the popped
> word on the stack (`:1016`), so the FLAGS pop chains directly into the mask/or.

Run the IRET test green.
