# 68000 Field-Grammar Disassembler Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The generator emits a real 68000 `Disassemble` that walks `FieldGrammar.Ops`, so the `--board m68000` monitor renders mnemonics (`MOVE.W D0,D1`, `BNE *+8`, `JSR (A0)`, `RTS`) instead of `???`.

**Architecture:** The 68000 carries no `InstructionDef` rows (it is field-grammar), so the existing `EmitDisassembler` (which iterates `model.Instructions`) emits a `???`-only stub. We add a `FieldGrammar`-gated branch that emits an `EmitM68kDisassembler` body walking the same `Decode68k.Ops` table the decoder walks — deriving the mnemonic family, size suffix, condition code, and EA operands from the 16-bit opword. Operands that live in extension words render honest placeholders (`#<imm>`, `<abs>`, `<d16>`), the way the Z80's opcode-encoded modes already do. Monitor-display-only: no IL, no execution-path change.

**Tech Stack:** C# / .NET 10 Roslyn source generator (`CpuEmulator.Generators`), xUnit v2.9.3.

## Global Constraints

- **AOT-clean Core:** generated C# walking a static `FieldOp[]`; no reflection, no `Reflection.Emit`.
- **Interpreter-as-oracle / byte-identical JIT parity:** D68 emits **no IL** and changes **no execution path**. The TomHarte / decode / JIT-parity gates are untouched.
- **No regression to 6502/Z80/8086:** the new emit branch is gated on `model.FieldGrammar is not null` (only the 68000). The other three generated `Disassemble` tables must have an **empty git-diff** (the DECISION-R regression gate).
- **Contract unchanged:** `IMonitorSupport.Disassemble(byte opcode, byte operandLo, byte operandHi)` is NOT widened (decision D68-3). Extension-word operands render placeholders.
- **No 68000 assembler** (D68-1): `TryAssemble` stays the always-fail stub; the round-trip gate is a curated table.

```csharp
    /// <summary>Emit the 68000 field-grammar disassembler (roadmap #6 / D68). Walks the grammar Ops in order;
    /// the first (opword & Mask) == Match wins, then renders the mnemonic + size suffix + cc suffix + EA
    /// operand(s) from the opword. Extension-word operands (#imm, abs, d16) render placeholders — the
    /// IMonitorSupport contract carries only 3 bytes (D68-2/D68-3). Monitor-display-only; no IL.</summary>
    private static void EmitM68kDisassembler(StringBuilder sb, FieldGrammarModel grammar)
    {
        sb.AppendLine();
        sb.AppendLine("    /// <summary>Disassemble one 68000 instruction (field-grammar walk). Returns a");
        sb.AppendLine("    /// human-readable string; \"???\" for an undefined opword. Extension-word operands");
        sb.AppendLine("    /// render placeholders (#&lt;imm&gt;/&lt;abs&gt;/&lt;d16&gt;) — the monitor's 3-byte");
        sb.AppendLine("    /// disassembly contract cannot carry them; the byte column shows the raw hex.</summary>");
        sb.AppendLine("    public static string Disassemble(uint opcode, byte operandLo, byte operandHi)");
        sb.AppendLine("    {");
        sb.AppendLine("        ushort opword = (ushort)opcode;");

        foreach (var op in grammar.Ops)
        {
            // The branch arm: family-specific rendering. Most families are MNEMONIC[.size] EA; the flow/cc
            // families and the dual-EA MOVE are special-cased.
            sb.AppendLine($"        if ((opword & 0x{op.Mask:X4}) == 0x{op.Match:X4})");
            sb.AppendLine("        {");
            sb.AppendLine($"            return DisasmM68k_{op.Operation}(opword);");
            sb.AppendLine("        }");
        }

        sb.AppendLine("        return \"???\";");
        sb.AppendLine("    }");

        // Emit the per-family render helpers + the shared statics. The helpers are small and family-keyed so
        // a reviewer can read one family at a time; they all share Ea(), Cc(), and SizeSuffix().
        EmitM68kDisasmHelpers(sb, grammar);
    }
```

> **Implementer note (the heart of the task):** `EmitM68kDisasmHelpers` emits one tiny `DisasmM68k_<Operation>`
> static per distinct `Operation` name in the grammar (83 of them, but most share a shape). To keep this
> tractable and DRY, group families by render shape and emit a shared renderer each calls:
>
> - **Implied** (`NOP`,`RTS`,`RTE`,`RTR`,`RESET`,`STOP`,`TRAPV`,`ILLEGAL`): `return "NOP";` etc. — the mnemonic
>   is the family name with `_` stripped where present (`ORI_CCR` -> `"ORI CCR"` rendered as `"ORI #<imm>,CCR"`).
> - **EA-single** (`CLR`,`NEG`,`NOT`,`TST`,`NEGX`,`NBCD`,`TAS`,`JMP`,`JSR`,`PEA`,`Scc`,`SWAP`,`EXT`, the bit ops):
>   `return $"{MNEMONIC}{SizeSuffix(opword, shift, width, enc)} {Ea(opword, eaShift)}";`
> - **Dn,EA / EA,Dn** (`ADD`,`SUB`,`AND`,`OR`,`EOR`,`CMP`,`CHK`,`DIVU`,`DIVS`,`MULU`,`MULS`): direction bit
>   (bit 8) selects operand order; `Dn = (opword>>9)&7`.
> - **A-family** (`ADDA`,`SUBA`,`CMPA`,`LEA`): dst `A{(opword>>9)&7}`; size from bit 8 (.W/.L) for ADDA/SUBA/CMPA,
>   fixed .L for LEA.
> - **MOVE/MOVEA:** src `Ea(opword, 0)`, dst from reg `(opword>>9)&7` + mode `(opword>>6)&7` (the SWAPPED dst
>   field, `M68000Cpu.Move.cs:81-83`); size from bits 13-12 via `SizeEncoding.Move`.
> - **MOVEQ:** `$"MOVEQ #<imm>,D{(opword>>9)&7}"`.
> - **Bcc/DBcc:** cc = `(opword>>8)&0xF` via `Cc()`; `Bcc` cc=0 -> `BRA`, cc=1 -> `BSR`; render `*+<d16>` (or
>   `*<sd8>` if you choose to decode the in-opword 8-bit displacement — optional, the 8-bit disp IS in the
>   opword low byte, so you MAY render it as a signed value: `BNE *+6`). DBcc: `$"DB{Cc(...)} D{opword&7},*+<d16>"`.
> - **ADDQ/SUBQ:** quick `#{((opword>>9)&7) == 0 ? 8 : (opword>>9)&7}` + EA.
> - **Shifts** (`ASLR_REG`,`LSLR_REG`,`ROXLR_REG`,`ROLR_REG`,`SHIFT_MEM`): direction bit (bit 8) -> L/R; the
>   base mnemonic from the family (`AS`/`LS`/`ROX`/`RO`) + `L`/`R` + size; register form renders `Dx,Dy` or a
>   count; memory form renders the EA.
> - **TRAP:** `$"TRAP #{opword & 0xF}"`. **LINK/UNLK:** `$"LINK A{opword&7},#<d16>"` / `$"UNLK A{opword&7}"`.
>
> Emit `Cc(int)` (the 16-name table `T,F,HI,LS,CC,CS,NE,EQ,VC,VS,PL,MI,GE,LT,GT,LE`), `SizeSuffix(opword,
> shift, width, enc)` (`.B`/`.W`/`.L` per `SizeEncoding`), and `Ea(opword, shift)` (mode/reg -> the operand
> string per §4 of the spec) as shared generated statics. This is mechanical but voluminous; write the corpus
> families first (Task 1's 16 rows), get those green, then fill the long tail (the decoder-agreement gate in
> Task 3 catches any family you mis-wire on family selection).
