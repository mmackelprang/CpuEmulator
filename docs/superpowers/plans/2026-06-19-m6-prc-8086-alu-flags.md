# M6 PR-C — the 8086 ALU + FLAGS emit arm

> **Status:** PLANNED (2026-06-19). The second 8086 emit PR — adds the integer-ALU bodies + the 8086
> FLAGS word (CF/PF/AF/ZF/SF/OF) atop PR-B's EA infrastructure. The FLAGS computation is the per-CPU pole
> (the 8086's analogue of the Z80's SZ5H3PNC word and the 68000's XNZVC CCR). Mirrors PR-2 (Z80 ALU+flags)
> for the flag-helper discipline and reuses PR-B's ModR/M EA resolver verbatim.
>
> **Dependencies:** PR-B (the 8086 MOV emit arm + the ModR/M EA resolver + the segmented Discover/Task-0
> fix — REQUIRED; PR-C reuses `EmitM8086EaOffset`/`EmitM8086SegValue`/the byte/word EA access helpers +
> `M8086CodePhys` unchanged). PR-0 (wide-register helper — DONE). Main @ PR-B's merge.

---

## 1. Scope

**EMIT (this PR):** the hot integer-ALU families — the profiler's #2-#6 8086 ops (ADD/SUB/INC/DEC + the
logical/compare core, ADR 0011 §6). All `JitOpClass.Register` ALU rows the interpreter `AluExecute`
(`M8086Cpu.Alu.cs:115-190`) handles, EXCEPT the microcoded/exception tail:

- **00-3D** — the eight ALU families' r/m,reg + reg,r/m + acc,imm forms (ADD/OR/ADC/SBB/AND/SUB/XOR/CMP),
  byte + word, all six form-variants per family (`AluStd`, `Alu.cs:238`).
- **80/81/83 group** — ALU `r/m,imm` (the ModR/M reg field selects the op; 0x83 sign-extends imm8→16),
  keys `0x400-0x41F` (`AluGroupImm`, `Alu.cs:288`).
- **84/85, A8/A9** — TEST `r/m,reg` and TEST `acc,imm` (`AluTestRm` + the inline acc forms, `Alu.cs:146-149`).
- **40-47/48-4F** — INC/DEC r16 (the register-shortcut forms, CF preserved; `Alu.cs:152-155`).
- **FE/FF group /0 /1** — INC/DEC `r/m8`/`r/m16` (keys `0x7F0/0x7F1/0x7F8/0x7F9`; CF preserved;
  `AluIncDecRm`, `Alu.cs:320`).
- **F6/F7 group /2 /3** — NOT (no flags) and NEG (SUB-form flags) (`AluUnaryNot`/`AluUnaryNeg`,
  `Alu.cs:343-364`). F6/F7 /0 /1 TEST also emits (`AluUnaryTestImm`, `Alu.cs:336`).

**FALLBACK (stays interpreter — out of PR-C scope, per ADR 0011 §2):**
- **F6/F7 /4 /5 MUL/IMUL** — multi-result (DX:AX), undefined-flag fallout (`AluMul`, `Alu.cs:369`). The
  product is simple but the CF/OF "upper-significant" predicate + the undefined SZP fallout are
  fiddly-for-low-ROI; MUL is rare in the hot path. Stays fallback (correctness-free).
- **F6/F7 /6 /7 DIV/IDIV** — the divide-error → INT0 vector (`AluDiv`, `Alu.cs:412`) is exception-capable
  (ADR 0011 §2: exception ops stay fallback) AND carries the documented IDIV-sign-quirk + undefined-flag
  deferrals the sweep already discloses. Stays fallback.
- **The BCD adjusts (DAA/DAS/AAA/AAS/AAM/AAD)** — `M8086Cpu.Bcd.cs`, a separate family, out of the ALU
  scope. Stays fallback.

**The shared FLAGS infrastructure PR-C builds (reused by PR-D's flag-affecting branches — none, actually;
PR-D's Jcc only READS flags):** a shared `EmitM8086Flags` helper family that transcribes the interpreter's
`AddFlags`/`SubFlags`/`LogicFlags`/`IncDecFlags`/`SetSzp`/`ParityEven` (`M8086Cpu.Alu.cs:36-111`) into IL,
one-for-one. This is the densest correctness pocket and the per-CPU pole.

## 2. Design decisions

### DECISION C-1: the FLAGS helper — a shared, value-computing IL transcription of the oracle

The 8086 FLAGS word (CF=bit0, PF=bit2, AF=bit4, ZF=bit6, SF=bit7, OF=bit11 — `Alu.cs:28-33`) is computed
inline into the `FLAGS` ushort field, byte-identical to the interpreter. The helpers mirror the oracle's
exact arithmetic so the TomHarte FLAGS-mask compare passes. The shared shape (the Z80 PR-2 / 68000 PR-5
precedent: a per-CPU flag plug-in that the ALU arm calls):

- `EmitM8086SetSzp(value, width16)` — SF/ZF/PF from a width-masked result (`SetSzp`, `Alu.cs:48`). The
  parity bit uses `System.Numerics.BitOperations.PopCount(result & 0xFF) & 1 == 0` — emit a `call` to
  `BitOperations.PopCount(uint)` (a static method handle resolved once, like the bus-helper handles), then
  `& 1`, `== 0`. SF/ZF are the width-aware sign-bit + zero tests.
- `EmitM8086AddFlags(width16)` — the ADD/ADC flag set (`AddFlags`, `Alu.cs:62`): CF = carry out of the
  width; AF = `(a^b^result) & 0x10`; OF = `~(a^b) & (a^result) & signBit`; then SetSzp. Takes `a, b,
  carryIn` from survivor locals (see C-2), leaves the width-masked result on the stack.
- `EmitM8086SubFlags(width16)` — the SUB/SBB/CMP/NEG flag set (`SubFlags`, `Alu.cs:77`): CF = borrow; AF =
  `(a^b^result) & 0x10`; OF = `(a^b) & (a^result) & signBit`; SetSzp. (Note the OF predicate differs from
  ADD — no `~`.)
- `EmitM8086LogicFlags(width16)` — AND/OR/XOR/TEST (`LogicFlags`, `Alu.cs:93`): CF=0, OF=0, AF=0, then
  SetSzp from the result.
- `EmitM8086IncDecFlags(decrement, width16)` — INC/DEC (`IncDecFlags`, `Alu.cs:105`): like ADD/SUB of 1 but
  **CF is PRESERVED** — save CF, run the add/sub-1 flag set, restore CF. (The emit form saves the CF bit
  into a local before the sub-flag computation and ORs it back after.)

**Each helper is value-computing + side-effecting on FLAGS:** it reads the operand survivor locals, writes
the six flag bits into the `FLAGS` field (via a read-modify-write `SetFlag`-style emit:
`FLAGS = (FLAGS & ~mask) | (cond ? mask : 0)`), and leaves the width-masked result on the stack for the
ALU arm to store (or discard, for CMP/TEST).

**Why shared, not generic:** the 8086 flag word differs in bits and semantics from the Z80/68000 (AF/PF
are 8086-specific; OF is bit 11 not the CCR's bit 1), so the helper is per-CPU (DECISION 2 of ADR 0011:
the flag computation is the irreducible per-CPU content). But it factors WITHIN the 8086 — all ALU forms
call the same five helpers, exactly as the interpreter's `AluCompute` (`Alu.cs:220`) dispatches to the
same flag functions.

### DECISION C-2: the ALU operand survivors + the read-compute-write ordering

An ALU op reads operand `a` (a register or a memory r/m), operand `b` (a register/imm/memory), computes
`a OP b` with flags, and writes the result back (to the r/m for `00/01/80/81/83/FE/FF`-dest forms, to the
reg for `02/03`, to AL/AX for `04/05/A8/A9`, or discards for CMP/TEST). The memory r/m can be BOTH the
read source AND the write dest (the RMW forms `00/01/80/81/83/FE/FF`), so the resolved EA must survive the
operand read.

PR-C adds three survivor locals (mirroring the 68000's `M68kALocal`/`M68kBLocal`/`M68kResultLocal`,
`EmitHelpers.cs`):

```
M8086ALocal (int)       — operand a (survives the b-read + the flag compute)
M8086BLocal (int)       — operand b
M8086ResultLocal (int)  — the width-masked result (survives the FLAGS write + the dest write)
```

The RMW memory dest reuses PR-B's `M8086SegLocal`/`M8086OffsetLocal` survivors: resolve the r/m EA ONCE
into `(M8086SegLocal, M8086OffsetLocal)`, read `a` from it (the byte/word offset-wrap helper), compute,
then write the result back to the SAME `(seg, offset)` — no second EA resolution (the address-once
discipline; the 8086 r/m EA has no auto-increment side effect, so re-forming the physical from the
survivors is exactly correct).

**The CF-preserve ordering for INC/DEC:** `IncDecFlags` saves CF before and restores after (`Alu.cs:107-109`),
because the sub-flag computation clobbers CF. The emit form does the same: `Ldfld FLAGS; Ldc_I4 FlagCF; And`
→ stash in `M8086ALocal` (reuse as the saved-CF scratch), run the add/sub-1 flag emit, then
`FLAGS = (FLAGS & ~FlagCF) | savedCf`.

### DECISION C-3: ADC/SBB carry-in — read CF as the carry/borrow-in BEFORE the compute

ADC reads CF as `carryIn` (`AluCompute` → `AddFlags(a, b, FLAGS & FlagCF, …)`, `Alu.cs:223`); SBB reads CF
as `borrowIn` (`Alu.cs:225`). The emit form loads `FLAGS & FlagCF` (= 0 or 1) onto the stack as the
carry/borrow-in operand to `EmitM8086AddFlags`/`EmitM8086SubFlags` BEFORE the flag helper overwrites CF.
The helper signatures take `carryIn`/`borrowIn` from a survivor local (`M8086ResultLocal` reused as the
carry-in scratch before it holds the result) so the order is: read CF-in → compute `a±b±carry` → write the
new flags (including the new CF).

### DECISION C-4: the dispatch + the gate (mirrors PR-B exactly)

- Route under `JitOpClass.Register` + `(TargetIsM8086, d.Mnemonic ∈ {ADD,OR,ADC,SBB,AND,SUB,XOR,CMP,
  TEST,INC,DEC,NOT,NEG})` → `EmitM8086Alu(ctx, pc, d)`. (The MOV route from PR-B stays; the ALU route is a
  parallel mnemonic check in the same `Register` case.)
- The gate-flip extends `IsEmittableX86Family` (PR-B's whitelist) with the ALU opcode set. MUL/IMUL/DIV/IDIV
  (F6/F7 /4../7) are EXCLUDED — they stay fallback (the F6/F7 group keys `0x7B4-0x7B7`, `0x7BC-0x7BF`).
- The lookahead fallback valve (`CanEmitM8086Alu`): like MOV, every 8086 ALU ModR/M EA is emittable, so the
  valve returns true for the in-scope ALU rows and false for the excluded MUL/DIV group keys (so a garbage
  lookahead decoding as F6 /4 falls back, not throws). The arm default throws (lockstep).

### DECISION C-5: the cycle model — coarse BaseCycles, data-axis-only (inherited from PR-B DECISION B-4)

Same as PR-B: charge a coarse `d.BaseCycles` once + the per-byte access charges; the parity gate is the
data axis (regs + FLAGS-mask + RAM), cycles carried-not-asserted. No `JitBaseCycles` change.

### DECISION C-6: the override-prefix scope (inherited from PR-B Task 3b)

If PR-B landed Task 3b (the decoded override threaded into the arm — recommended), PR-C inherits it for
free: the ALU memory operands resolve through `EmitM8086SegValue(…, over)` with the real override. If PR-B
took the fallback cut instead, PR-C inherits the cut (override-prefixed ALU stays fallback). **PR-C should
assume Task 3b landed** (the clean path) and thread `over` into every ALU memory access.

## 3. Tasks (literal-code)

### Task 1 — the shared FLAGS helper family

**File:** `src/CpuEmulator.Jit/BlockCompiler.M8086.cs` (append to PR-B's partial)

First, the FLAGS bit constants + the static `PopCount` handle (near the top of the partial):

```csharp
    // M6 PR-C: the 8086 FLAGS bit masks (M8086Cpu.Alu.cs:28-33 — the M8086Spec layout).
    private const int M8086FlagCF = 1 &lt;&lt; 0;
    private const int M8086FlagPF = 1 &lt;&lt; 2;
    private const int M8086FlagAF = 1 &lt;&lt; 4;
    private const int M8086FlagZF = 1 &lt;&lt; 6;
    private const int M8086FlagSF = 1 &lt;&lt; 7;
    private const int M8086FlagOF = 1 &lt;&lt; 11;

    // The BitOperations.PopCount(uint) handle for the parity bit (resolved once; CPU-agnostic static).
    private static readonly MethodInfo MPopCount =
        typeof(System.Numerics.BitOperations).GetMethod("PopCount", [typeof(uint)])!;
```

The `FLAGS`-field handle (`_m8086FLAGS`) resolves in the ctor (alongside `_m8086CS`):

```csharp
        _m8086FLAGS = target.CpuType.GetField("FLAGS");   // M6 PR-C: the 8086 FLAGS word (the ALU flag core)
```

The set-flag-bit emit (read-modify-write a single bit from a bool condition on the stack):

```csharp
    /// <summary>M6 PR-C: FLAGS = (FLAGS &amp; ~mask) | (cond ? mask : 0). The boolean condition is on the stack
    /// (any nonzero ⇒ set). Mirrors M8086Cpu.SetFlag (Alu.cs:36).</summary>
    private void EmitM8086SetFlag(EmitContext ctx, int mask)
    {
        ILGenerator il = ctx.Il;
        // stack: cond(int)  ->  stash, then FLAGS = (FLAGS &amp; ~mask) | (cond!=0 ? mask : 0)
        Label setIt = il.DefineLabel(), done = il.DefineLabel();
        il.Emit(OpCodes.Brtrue, setIt);
        il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Br, done);
        il.MarkLabel(setIt); il.Emit(OpCodes.Ldc_I4, mask);
        il.MarkLabel(done);
        il.Emit(OpCodes.Stloc, ctx.DataLocal);     // the bit-or-0 to apply
        il.Emit(OpCodes.Ldarg_0);
        il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, _m8086FLAGS!);
        il.Emit(OpCodes.Ldc_I4, ~mask); il.Emit(OpCodes.And);   // FLAGS &amp; ~mask
        il.Emit(OpCodes.Ldloc, ctx.DataLocal); il.Emit(OpCodes.Or);
        il.Emit(OpCodes.Conv_U2); il.Emit(OpCodes.Stfld, _m8086FLAGS!);
    }

    /// <summary>M6 PR-C: SF/ZF/PF from a result in M8086ResultLocal (SetSzp, Alu.cs:48). width16 picks the
    /// sign bit (0x8000 vs 0x80) and the zero-width mask (0xFFFF vs 0xFF). PF = even parity of the LOW 8 bits.</summary>
    private void EmitM8086SetSzp(EmitContext ctx, bool width16)
    {
        ILGenerator il = ctx.Il;
        int signBit = width16 ? 0x8000 : 0x80;
        int widthMask = width16 ? 0xFFFF : 0xFF;
        // ZF: (result &amp; widthMask) == 0
        il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal); il.Emit(OpCodes.Ldc_I4, widthMask); il.Emit(OpCodes.And);
        il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Ceq);   // (… == 0) ? 1 : 0
        EmitM8086SetFlag(ctx, M8086FlagZF);
        // SF: (result &amp; signBit) != 0
        il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal); il.Emit(OpCodes.Ldc_I4, signBit); il.Emit(OpCodes.And);
        EmitM8086SetFlag(ctx, M8086FlagSF);
        // PF: (PopCount((uint)(result &amp; 0xFF)) &amp; 1) == 0
        il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal); il.Emit(OpCodes.Ldc_I4, 0xFF); il.Emit(OpCodes.And);
        il.Emit(OpCodes.Conv_U4); il.Emit(OpCodes.Call, MPopCount);
        il.Emit(OpCodes.Ldc_I4_1); il.Emit(OpCodes.And);
        il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Ceq);   // even ⇒ 1
        EmitM8086SetFlag(ctx, M8086FlagPF);
    }
```

The ADD/SUB/LOGIC/INCDEC flag computations (each takes `a` in `M8086ALocal`, `b` in `M8086BLocal`,
carry/borrow-in in `M8086ResultLocal` for the carry forms, computes, stores the result in
`M8086ResultLocal`, sets the six bits, leaves the result on the stack):

```csharp
    /// <summary>M6 PR-C: ADD/ADC flag set (AddFlags, Alu.cs:62). a in M8086ALocal, b in M8086BLocal, carryIn in
    /// M8086ResultLocal (0 for ADD, FLAGS&amp;CF for ADC). Computes full = a+b+carry; result = full &amp; widthMask;
    /// sets CF/AF/OF then SF/ZF/PF; stores result in M8086ResultLocal and leaves it on the stack.</summary>
    private void EmitM8086AddFlags(EmitContext ctx, bool width16)
    {
        ILGenerator il = ctx.Il;
        int widthMask = width16 ? 0xFFFF : 0xFF;
        int signBit = width16 ? 0x8000 : 0x80;
        // full = a + b + carryIn   (carryIn currently in M8086ResultLocal)
        il.Emit(OpCodes.Ldloc, ctx.M8086ALocal); il.Emit(OpCodes.Ldloc, ctx.M8086BLocal); il.Emit(OpCodes.Add);
        il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal); il.Emit(OpCodes.Add);
        il.Emit(OpCodes.Stloc, ctx.M8086BLocal);                 // reuse BLocal to hold `full` (b no longer needed raw)
        // result = full &amp; widthMask  -> M8086ResultLocal
        il.Emit(OpCodes.Ldloc, ctx.M8086BLocal); il.Emit(OpCodes.Ldc_I4, widthMask); il.Emit(OpCodes.And);
        il.Emit(OpCodes.Stloc, ctx.M8086ResultLocal);
        // CF: (full &amp; (widthMask+1)) != 0
        il.Emit(OpCodes.Ldloc, ctx.M8086BLocal); il.Emit(OpCodes.Ldc_I4, widthMask + 1); il.Emit(OpCodes.And);
        EmitM8086SetFlag(ctx, M8086FlagCF);
        // AF: ((a ^ b ^ result) &amp; 0x10) != 0   — but b here was overwritten by `full`; recompute from the ORIGINAL
        //     a (M8086ALocal) ^ original b. PR-C stashes the original b in M8086OffsetLocal before the overwrite
        //     (or recomputes b = full - a - carry). The literal arm stashes original-b in a dedicated scratch —
        //     Builder declares M8086BOrigLocal; the helper reads (a ^ bOrig ^ result) &amp; 0x10.
        il.Emit(OpCodes.Ldloc, ctx.M8086ALocal); il.Emit(OpCodes.Ldloc, ctx.M8086BOrigLocal); il.Emit(OpCodes.Xor);
        il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal); il.Emit(OpCodes.Xor);
        il.Emit(OpCodes.Ldc_I4, 0x10); il.Emit(OpCodes.And);
        EmitM8086SetFlag(ctx, M8086FlagAF);
        // OF: (~(a ^ b) &amp; (a ^ result) &amp; signBit) != 0
        il.Emit(OpCodes.Ldloc, ctx.M8086ALocal); il.Emit(OpCodes.Ldloc, ctx.M8086BOrigLocal); il.Emit(OpCodes.Xor); il.Emit(OpCodes.Not);
        il.Emit(OpCodes.Ldloc, ctx.M8086ALocal); il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal); il.Emit(OpCodes.Xor); il.Emit(OpCodes.And);
        il.Emit(OpCodes.Ldc_I4, signBit); il.Emit(OpCodes.And);
        EmitM8086SetFlag(ctx, M8086FlagOF);
        EmitM8086SetSzp(ctx, width16);
        il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal);            // leave result on the stack
    }

    /// <summary>M6 PR-C: SUB/SBB/CMP/NEG flag set (SubFlags, Alu.cs:77). a in M8086ALocal, b (orig) in
    /// M8086BOrigLocal, borrowIn in M8086ResultLocal. full = a - b - borrow; result = full &amp; widthMask; CF=borrow;
    /// AF=(a^b^result)&amp;0x10; OF=((a^b)&amp;(a^result)&amp;signBit) (NO ~, the SUB form); SetSzp. Leaves result on stack.</summary>
    private void EmitM8086SubFlags(EmitContext ctx, bool width16)
    {
        ILGenerator il = ctx.Il;
        int widthMask = width16 ? 0xFFFF : 0xFF;
        int signBit = width16 ? 0x8000 : 0x80;
        // full = a - b - borrowIn
        il.Emit(OpCodes.Ldloc, ctx.M8086ALocal); il.Emit(OpCodes.Ldloc, ctx.M8086BOrigLocal); il.Emit(OpCodes.Sub);
        il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal); il.Emit(OpCodes.Sub);
        il.Emit(OpCodes.Stloc, ctx.M8086BLocal);                 // `full`
        il.Emit(OpCodes.Ldloc, ctx.M8086BLocal); il.Emit(OpCodes.Ldc_I4, widthMask); il.Emit(OpCodes.And);
        il.Emit(OpCodes.Stloc, ctx.M8086ResultLocal);
        // CF (borrow): (full &amp; (widthMask+1)) != 0
        il.Emit(OpCodes.Ldloc, ctx.M8086BLocal); il.Emit(OpCodes.Ldc_I4, widthMask + 1); il.Emit(OpCodes.And);
        EmitM8086SetFlag(ctx, M8086FlagCF);
        // AF: ((a ^ b ^ result) &amp; 0x10) != 0
        il.Emit(OpCodes.Ldloc, ctx.M8086ALocal); il.Emit(OpCodes.Ldloc, ctx.M8086BOrigLocal); il.Emit(OpCodes.Xor);
        il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal); il.Emit(OpCodes.Xor);
        il.Emit(OpCodes.Ldc_I4, 0x10); il.Emit(OpCodes.And);
        EmitM8086SetFlag(ctx, M8086FlagAF);
        // OF: ((a ^ b) &amp; (a ^ result) &amp; signBit) != 0
        il.Emit(OpCodes.Ldloc, ctx.M8086ALocal); il.Emit(OpCodes.Ldloc, ctx.M8086BOrigLocal); il.Emit(OpCodes.Xor);
        il.Emit(OpCodes.Ldloc, ctx.M8086ALocal); il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal); il.Emit(OpCodes.Xor); il.Emit(OpCodes.And);
        il.Emit(OpCodes.Ldc_I4, signBit); il.Emit(OpCodes.And);
        EmitM8086SetFlag(ctx, M8086FlagOF);
        EmitM8086SetSzp(ctx, width16);
        il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal);
    }

    /// <summary>M6 PR-C: AND/OR/XOR/TEST flag set (LogicFlags, Alu.cs:93). The result is already in
    /// M8086ResultLocal (the caller computed a&amp;b / a|b / a^b). CF=0, OF=0, AF=0; SetSzp. Leaves result on stack.</summary>
    private void EmitM8086LogicFlags(EmitContext ctx, bool width16)
    {
        ILGenerator il = ctx.Il;
        int widthMask = width16 ? 0xFFFF : 0xFF;
        // result &amp;= widthMask
        il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal); il.Emit(OpCodes.Ldc_I4, widthMask); il.Emit(OpCodes.And);
        il.Emit(OpCodes.Stloc, ctx.M8086ResultLocal);
        il.Emit(OpCodes.Ldc_I4_0); EmitM8086SetFlag(ctx, M8086FlagCF);
        il.Emit(OpCodes.Ldc_I4_0); EmitM8086SetFlag(ctx, M8086FlagOF);
        il.Emit(OpCodes.Ldc_I4_0); EmitM8086SetFlag(ctx, M8086FlagAF);
        EmitM8086SetSzp(ctx, width16);
        il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal);
    }

    /// <summary>M6 PR-C: INC/DEC flag set (IncDecFlags, Alu.cs:105) — ADD/SUB of 1 but CF PRESERVED. Save CF,
    /// run the add/sub-1 flag set (b=1, carry/borrow-in=0), restore CF. a in M8086ALocal. Leaves result on stack.</summary>
    private void EmitM8086IncDecFlags(EmitContext ctx, bool decrement, bool width16)
    {
        ILGenerator il = ctx.Il;
        // savedCf = FLAGS &amp; CF  -> M8086BLocal (scratch; b is set to 1 next)
        il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, _m8086FLAGS!); il.Emit(OpCodes.Ldc_I4, M8086FlagCF); il.Emit(OpCodes.And);
        il.Emit(OpCodes.Stloc, ctx.M8086ResultLocal);   // stash savedCf in ResultLocal (free until the compute)
        // b = 1, carry/borrow-in = 0
        il.Emit(OpCodes.Ldc_I4_1); il.Emit(OpCodes.Stloc, ctx.M8086BOrigLocal);
        il.Emit(OpCodes.Ldc_I4_1); il.Emit(OpCodes.Stloc, ctx.M8086BLocal);     // (BLocal reused inside the helper)
        // carry/borrow-in must be 0 — but the Add/Sub helpers read it from M8086ResultLocal, which holds savedCf.
        // So move savedCf to a dedicated M8086SavedCfLocal and zero the carry-in. (Builder declares M8086SavedCfLocal.)
        il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal); il.Emit(OpCodes.Stloc, ctx.M8086SavedCfLocal);
        il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Stloc, ctx.M8086ResultLocal);   // carry/borrow-in = 0
        if (decrement) EmitM8086SubFlags(ctx, width16); else EmitM8086AddFlags(ctx, width16);
        il.Emit(OpCodes.Stloc, ctx.M8086ResultLocal);   // re-stash the result the helper left on the stack
        // restore CF: FLAGS = (FLAGS &amp; ~CF) | savedCf
        il.Emit(OpCodes.Ldarg_0);
        il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, _m8086FLAGS!); il.Emit(OpCodes.Ldc_I4, ~M8086FlagCF); il.Emit(OpCodes.And);
        il.Emit(OpCodes.Ldloc, ctx.M8086SavedCfLocal); il.Emit(OpCodes.Or);
        il.Emit(OpCodes.Conv_U2); il.Emit(OpCodes.Stfld, _m8086FLAGS!);
        il.Emit(OpCodes.Ldloc, ctx.M8086ResultLocal);   // leave result on the stack
    }
```

> **Note on the `M8086BOrigLocal` / `M8086SavedCfLocal` scratch.** The AF/OF predicates need the ORIGINAL
> `b` (the add/sub overwrites `b` with `full`), so the arm stashes the original `b` in `M8086BOrigLocal`
> BEFORE calling the flag helper. INC/DEC needs a CF-save slot distinct from the operand locals. These are
> two more EmitContext locals (Task 2). The exact local-reuse choreography above is illustrative — Builder
> may use cleaner dedicated locals (`M8086FullLocal`, `M8086CarryInLocal`) rather than reusing
> `M8086BLocal`/`M8086ResultLocal` for intermediates; the load-bearing requirement is that `a`, original
> `b`, the carry-in, and the result are each live where the predicate reads them. The interpreter
> `AddFlags`/`SubFlags` is the exact oracle — the TomHarte FLAGS-mask compare is the proof.

### Task 3 — the ALU emit arm

**File:** `src/CpuEmulator.Jit/BlockCompiler.M8086.cs`

The arm decodes the ModR/M/disp/imm at emit time (via `M8086CodePhys`, reusing PR-B's decode preamble),
then dispatches the normalized key to one of the form families. Each transcribes the matching `AluExecute`
case. The structure mirrors `AluExecute`'s `switch` (`Alu.cs:124-189`); the literal arm has one branch per
opcode family. The reusable per-form skeleton (illustrated for the `00-3D` AluStd family — the others
follow the same read-a → read-b → compute → write pattern):

```csharp
    /// <summary>M6 PR-C: emit one 8086 ALU-family instruction. Reached when TargetIsM8086 &amp;&amp; d.Mnemonic is an
    /// in-scope ALU mnemonic. Decodes ModR/M/disp/imm at emit time (M8086CodePhys), reads a/b into the survivor
    /// locals, calls the matching flag helper, writes the result (unless CMP/TEST). The default throws (lockstep).</summary>
    private void EmitM8086Alu(EmitContext ctx, ushort pc, OpcodeDescriptor d)
    {
        // (decode preamble — IDENTICAL to EmitM8086Mov's: read modrm/mod/reg/rm/disp via M8086CodePhys, normalize
        //  the 80/81/83 + F6/F7 + FE/FF group keys to (opcode&lt;&lt;3)|reg, thread `over` from the PR-B Task-3b signal.)
        // ... decode into: byte opcode; uint mod, reg, rm; ushort disp; M8086Cpu_Override over; int operandPc; ...

        // Dispatch by the SAME normalized key shape AluExecute uses (Alu.cs:124). Representative branch:
        switch (key)
        {
            // 00-05 ADD (baseOp 0x00); the form is key - baseOp (0=r/m8&lt;-r8 store, 1=r/m16, 2=r8&lt;-r/m8, 3=r16, 4=AL,imm8, 5=AX,imm16).
            case &gt;= 0x00 and &lt;= 0x05: EmitM8086AluStd(ctx, 0x00, key, M8086AluKind.Add, mod, reg, rm, disp, over, operandPc); break;
            case &gt;= 0x08 and &lt;= 0x0D: EmitM8086AluStd(ctx, 0x08, key, M8086AluKind.Or,  mod, reg, rm, disp, over, operandPc); break;
            case &gt;= 0x10 and &lt;= 0x15: EmitM8086AluStd(ctx, 0x10, key, M8086AluKind.Adc, mod, reg, rm, disp, over, operandPc); break;
            case &gt;= 0x18 and &lt;= 0x1D: EmitM8086AluStd(ctx, 0x18, key, M8086AluKind.Sbb, mod, reg, rm, disp, over, operandPc); break;
            case &gt;= 0x20 and &lt;= 0x25: EmitM8086AluStd(ctx, 0x20, key, M8086AluKind.And, mod, reg, rm, disp, over, operandPc); break;
            case &gt;= 0x28 and &lt;= 0x2D: EmitM8086AluStd(ctx, 0x28, key, M8086AluKind.Sub, mod, reg, rm, disp, over, operandPc); break;
            case &gt;= 0x30 and &lt;= 0x35: EmitM8086AluStd(ctx, 0x30, key, M8086AluKind.Xor, mod, reg, rm, disp, over, operandPc); break;
            case &gt;= 0x38 and &lt;= 0x3D: EmitM8086AluStd(ctx, 0x38, key, M8086AluKind.Cmp, mod, reg, rm, disp, over, operandPc); break;

            // 84/85 TEST r/m,reg ; A8/A9 TEST acc,imm.
            case 0x84: EmitM8086TestRm(ctx, false, mod, reg, rm, disp, over); break;
            case 0x85: EmitM8086TestRm(ctx, true,  mod, reg, rm, disp, over); break;
            case 0xA8: EmitM8086TestAccImm(ctx, false, ReadImm8(ctx, operandPc)); break;
            case 0xA9: EmitM8086TestAccImm(ctx, true,  ReadImm16(ctx, operandPc)); break;

            // 40-47 INC r16 ; 48-4F DEC r16 (CF preserved).
            case &gt;= 0x40 and &lt;= 0x47: EmitM8086IncDecReg16(ctx, key &amp; 7u, decrement: false); break;
            case &gt;= 0x48 and &lt;= 0x4F: EmitM8086IncDecReg16(ctx, key &amp; 7u, decrement: true);  break;

            // 80/81/83 group: ALU r/m,imm (keys 0x400-0x41F; reg field selects op; 0x83 sign-extends imm8).
            case &gt;= 0x400 and &lt;= 0x407: EmitM8086AluGroupImm(ctx, false, false, mod, reg, rm, disp, over, operandPc); break; // r/m8,imm8
            case &gt;= 0x408 and &lt;= 0x40F: EmitM8086AluGroupImm(ctx, true,  false, mod, reg, rm, disp, over, operandPc); break; // r/m16,imm16
            case &gt;= 0x418 and &lt;= 0x41F: EmitM8086AluGroupImm(ctx, true,  true,  mod, reg, rm, disp, over, operandPc); break; // r/m16,imm8 SX

            // FE/FF /0 /1: INC/DEC r/m (CF preserved). Keys 0x7F0/0x7F1 (r/m8), 0x7F8/0x7F9 (r/m16).
            case 0x7F0: EmitM8086IncDecRm(ctx, false, false, mod, rm, disp, over); break;
            case 0x7F1: EmitM8086IncDecRm(ctx, false, true,  mod, rm, disp, over); break;
            case 0x7F8: EmitM8086IncDecRm(ctx, true,  false, mod, rm, disp, over); break;
            case 0x7F9: EmitM8086IncDecRm(ctx, true,  true,  mod, rm, disp, over); break;

            // F6/F7 /0 /1 TEST imm ; /2 NOT (no flags) ; /3 NEG (SUB-form flags). /4../7 (MUL/DIV) are EXCLUDED (fallback).
            case 0x7B0: case 0x7B1: EmitM8086UnaryTestImm(ctx, false, mod, rm, disp, over, ReadImm8(ctx, operandPc)); break;
            case 0x7B8: case 0x7B9: EmitM8086UnaryTestImm(ctx, true,  mod, rm, disp, over, ReadImm16(ctx, operandPc)); break;
            case 0x7B2: EmitM8086UnaryNot(ctx, false, mod, rm, disp, over); break;
            case 0x7BA: EmitM8086UnaryNot(ctx, true,  mod, rm, disp, over); break;
            case 0x7B3: EmitM8086UnaryNeg(ctx, false, mod, rm, disp, over); break;
            case 0x7BB: EmitM8086UnaryNeg(ctx, true,  mod, rm, disp, over); break;

            default:
                throw new EmulationException($"BlockCompiler: no 8086 ALU emit branch for key 0x{key:X}; a lockstep bug.");
        }
        // PC tail advance (ModR/M + disp + imm), like EmitM8086Mov's M8086MovTailLength — an EmitM8086AluTailLength
        // computes the per-form remainder past the opcode.
        int tail = M8086AluTailLength(opcode, mod, rm);
        if (tail &gt; 0) EmitIncrementPC(ctx, tail);
    }

    private enum M8086AluKind { Add, Adc, Sub, Sbb, Cmp, And, Or, Xor }
```

The `AluStd` helper (the canonical read-a → read-b → compute → write, transcribing `Alu.cs:238-284`):

```csharp
    /// <summary>M6 PR-C: the 00-3D standard ALU forms (AluStd, Alu.cs:238). form = key - baseOp selects the
    /// operand layout. Reads a + b into the survivor locals, computes via the kind's flag helper, writes the
    /// result (unless CMP). Memory r/m is resolved ONCE (address-once) into the PR-B survivor pair for the RMW
    /// dest forms (0/1).</summary>
    private void EmitM8086AluStd(EmitContext ctx, uint baseOp, uint key, M8086AluKind kind,
        uint mod, uint reg, uint rm, ushort disp, M8086Cpu_Override over, int operandPc)
    {
        ILGenerator il = ctx.Il;
        uint form = key - baseOp;
        bool width16 = form is 1u or 3u or 5u;
        bool memDest = form is 0u or 1u;   // r/m is the dest (and a source) — the RMW forms
        // ... resolve the r/m EA once (into the PR-B (seg,offset) survivors for memory; or a register name);
        //     read `a` (dest operand for forms 0/1; reg for 2/3; AL/AX for 4/5) into M8086ALocal;
        //     read `b` (reg for 0/1; r/m for 2/3; imm for 4/5) into M8086BLocal + stash original in M8086BOrigLocal;
        //     set the carry/borrow-in in M8086ResultLocal (FLAGS&amp;CF for Adc/Sbb, else 0);
        //     call the kind's flag helper:
        switch (kind)
        {
            case M8086AluKind.Add: case M8086AluKind.Adc: EmitM8086AddFlags(ctx, width16); break;
            case M8086AluKind.Sub: case M8086AluKind.Sbb: case M8086AluKind.Cmp: EmitM8086SubFlags(ctx, width16); break;
            case M8086AluKind.And: case M8086AluKind.Or: case M8086AluKind.Xor:
                // compute a&amp;b / a|b / a^b into M8086ResultLocal first, then LogicFlags.
                il.Emit(OpCodes.Ldloc, ctx.M8086ALocal); il.Emit(OpCodes.Ldloc, ctx.M8086BOrigLocal);
                il.Emit(kind == M8086AluKind.And ? OpCodes.And : kind == M8086AluKind.Or ? OpCodes.Or : OpCodes.Xor);
                il.Emit(OpCodes.Stloc, ctx.M8086ResultLocal);
                EmitM8086LogicFlags(ctx, width16);
                break;
        }
        // stack now holds the result (M8086ResultLocal). CMP discards it; everything else writes it back to the
        // form's destination (r/m for 0/1, reg for 2/3, AL/AX for 4/5).
        if (kind == M8086AluKind.Cmp) { il.Emit(OpCodes.Pop); return; }
        // ... write the result to the dest (the memory RMW dest re-forms its physical from the PR-B survivor pair;
        //     the register dest is a Stfld via RegField / EmitStoreReg16). ...
    }
```

> The remaining helpers (`EmitM8086AluGroupImm`, `EmitM8086TestRm`, `EmitM8086TestAccImm`,
> `EmitM8086IncDecReg16`, `EmitM8086IncDecRm`, `EmitM8086UnaryTestImm`, `EmitM8086UnaryNot`,
> `EmitM8086UnaryNeg`, `ReadImm8`, `ReadImm16`, `M8086AluTailLength`) each transcribe their named
> `AluExecute` sub-body (`Alu.cs:288-364`) using the same read-a → read-b → flag-helper → write skeleton +
> PR-B's EA access helpers. NEG calls `EmitM8086SubFlags` with `a=0, b=operand` (`Alu.cs:355`); NOT writes
> `~operand` with NO flag helper (`Alu.cs:345`); the group-imm op is selected from the ModR/M reg field via
> the same `(key & 7) → AluKind` map the interpreter uses (`Alu.cs:291-295`). Builder writes each verbatim
> against the cited oracle body — there is no novel logic, only the read/compute/write transcription PR-B
> already established for MOV.
