# M6 PR-D — the 8086 branch emit arm (Jcc / JMP / CALL / RET — completes the high-ROI 8086 emit)

> **Status:** PLANNED (2026-06-19). The third 8086 emit PR — adds the control-flow family (the profiler's
> Jcc/JMP/CALL/RET hot ops, ADR 0011 §6), completing the high-ROI 8086 emit arc (MOV + ALU + branch =
> 85-99% of executed instructions). Mirrors PR-3 (Z80 branch/call/stack) for the EndsBlock / static-chain /
> dynamic-exit decisions and PR-6 (68000 Bcc/DBcc/RTS) for the conditional taken/not-taken edge shape.
>
> **Dependencies:** PR-B (the segmented Discover/Task-0 fix + `M8086CodePhys` + the EA resolver — REQUIRED
> for the FF-group indirect targets' memory reads), PR-C (the FLAGS word — Jcc/LOOPE/LOOPNE READ the flags;
> PR-C must have written them correctly for the conditions to be right; PR-D itself sets NO flags). PR-0
> (the stack-push/pop wide-register helper — DONE). Main @ PR-C's merge.

---

## 1. Scope

**EMIT (this PR):** the control-flow family — `JitOpClass.Register` rows the interpreter `ControlExecute`
(`M8086Cpu.Control.cs:55-185`) handles, **NEAR forms only** (see DECISION D-1 for the near-vs-far call):

- **70-7F** — Jcc rel8 (the 16-condition matrix; `JccTaken`, `Control.cs:26`).
- **EB** — JMP rel8 (short); **E9** — JMP rel16 (near).
- **E8** — CALL rel16 (near, push return IP).
- **C3** — RET (near, pop IP); **C2** — RET imm16 (near, pop IP + SP adjust).
- **E0/E1/E2/E3** — LOOPNE / LOOPE / LOOP / JCXZ (the CX-counted short jumps).
- **FF /2 /4** — CALL/JMP r/m16 (near indirect — keys `0x7FA`/`0x7FC`; the operand IS the new IP).

**FALLBACK (stays interpreter — out of PR-D scope, per DECISION D-1 + ADR 0011 §2):**
- **9A/EA** — CALL/JMP ptr16:16 (far DIRECT — change CS). **CB/CA** — RETF / RETF imm16 (far return —
  change CS). **FF /3 /5** — CALL/JMP m16:16 (far INDIRECT — change CS). **All far forms stay fallback**
  because they change CS, which breaks the 16-bit-IP block-cache key's CS-invariance (DECISION D-1). They
  are rare in the hot path (most loops/calls are near).
- **INT/INTO/IRET** — the interrupt vector ops (`M8086Cpu.Interrupt.cs`) — exception-capable, stay fallback
  (ADR 0011 §2). Not part of `ControlExecute`.

**No new shared infrastructure** — PR-D reuses PR-B's EA resolver (for the FF-group indirect operand
reads), PR-C's FLAGS field handle (for the Jcc/LOOP conditions), and the existing `EmitChainOrExit` /
`EmitNormalExit` chaining machinery (`BlockCompiler.cs:1274` / the normal-exit). PR-D adds the 8086 stack
push/pop emit (CALL pushes, RET pops) — the 6502/Z80 stack-emit precedent, adapted to the 8086's
`SS:SP` segmented stack.

---

## 2. Design decisions

### DECISION D-1: NEAR-only scope — the far forms stay fallback (the CS-invariance call)

**The branch scope is NEAR-only.** Every far control-flow form (9A/EA/CB/CA + FF /3 /5) changes CS, and a
JIT block is keyed on the **16-bit IP** and compiled against ONE CS (PR-B's CS-aliasing invariant). A
CS-changing op invalidates that invariant: after a far jump, the same IP maps to different physical code,
so chaining (or even re-dispatch on the 16-bit key) would alias. Three options:

- **(A) Near-only, far → fallback (CHOSEN).** The near forms (Jcc/JMP-near/CALL-near/RET-near/LOOP) never
  change CS, so the 16-bit-IP key stays exact and chaining is valid. Far forms interpret (correctness-free
  via the fallback valve — a far op is exactly the oracle, and `inner.Step` does the full CS:IP load). Far
  control flow is rare in the hot path (the profiler's hot branches are Jcc/JMP-near/CALL-near/RET-near).
  This mirrors the 68000's "emit Bcc/BSR/JMP/JSR/RTS, keep the exception/microcoded tail fallback" and the
  Z80's "emit JP/JR/CALL/RET, keep the prefix-plane rarities fallback." **A far form that ends the block
  via fallback self-terminates** (the fallback op is `EndsBlock=true`, exits to the dispatcher, which
  re-reads the now-changed CS:IP on the next `Step`) — so far flow is correct, just not chained.

- **(B) Widen the block-cache key to `(CS, IP)` so far flow can emit + chain.** Rejected for PR-D — it
  touches the dispatcher (`JittedCpu.GetOrCompile`, `BlockCache`, `ChainTable`) for EVERY CPU (the 6502/
  Z80/68000 would need a no-op CS=0), a cross-cutting change for the rare far-flow case. **This is the
  documented future option** if a profile ever shows far flow hot (it won't for normal software). Flagged
  for the Coordinator as the one consequential deferral, with the recommendation to keep (A).

- **(C) Emit far flow as an unconditional dynamic exit (set CS:IP, EmitNormalExit, never chain).** A
  middle ground — the far op could emit (set CS + IP) and exit to the dispatcher without chaining. But it
  buys little over fallback (the dispatch round-trip dominates either way for a rare op) and adds the CS
  field-write emit surface. Rejected — (A)'s fallback is simpler and equally correct.

**Recommended call, taken: (A) near-only.** The consequential part (deferring the `(CS,IP)` key widening)
is flagged for the Coordinator.

### DECISION D-2: the static-vs-dynamic chaining split (mirrors Z80 PR-3 / 68000 PR-6)

A control-flow op's successor is either a **compile-time-constant (static) target** — chainable via
`EmitChainOrExit(ctx, staticTargetPc)` — or a **runtime-computed (dynamic) target** — exits via
`EmitNormalExit(ctx)`. The 8086 forms split:

- **STATIC (chain):** Jcc rel8, JMP rel8/rel16, CALL rel16, LOOP/LOOPE/LOOPNE/JCXZ. The target is
  `IP_after_instruction + (signed)rel`, where BOTH `IP_after` (the post-advance IP — a compile-time
  constant the arm knows from `pc + length`) and `rel` (the immediate, read at emit time via
  `M8086CodePhys`) are compile-time constants. So the taken target is a baked `ushort` → `EmitChainOrExit`.
- **DYNAMIC (exit):** RET (the target is the popped stack word — runtime), FF /2 /4 CALL/JMP indirect (the
  target is the r/m operand — runtime). These set IP from a runtime value and `EmitNormalExit`.

- **CONDITIONAL (both edges):** Jcc / LOOP* emit a runtime condition test; the TAKEN edge chains to the
  static target, the NOT-TAKEN edge chains to the static fall-through (`pc + length`). Exactly the Z80
  `EmitZ80JrCc` shape (`BlockCompiler.Z80.cs:1131-1133`): a `Brfalse notTaken` over the taken
  `EmitChainOrExit(target)`, then the not-taken `EmitChainOrExit(fallThrough)`. Both edges are static
  (compile-time constants), so both chain.

**The relative-target base subtlety.** The interpreter computes the target as `IP + rel` where IP has
ALREADY been advanced past the instruction (`Control.cs:11-12`: "the generated Step advances IP by the
length BEFORE dispatch"). The emit arm advances IP in `EmitInstruction` (opcode) + the arm's tail, so at
the point the target is computed `IP == pc + length`. The arm bakes
`staticTarget = (ushort)((pc + length) + (signed)rel)` as the compile-time constant. **It must set the IP
field to that target before chaining** (the chain edge reads the IP field's successor, and `EmitChainOrExit`
takes the static PC as a constant but the IP FIELD must hold it too for a correct dynamic re-dispatch if the
chain is severed). The Z80 arm does exactly this (`EmitZ80Jr` sets PC then `EmitChainOrExit`,
`BlockCompiler.Z80.cs:895-898`).

### DECISION D-3: the 8086 stack — `SS:SP` segmented push/pop

CALL pushes the return IP; RET pops it. The 8086 stack is segmented: `PushWord(v)` does
`SP -= 2; WriteWord(SS:SP, v)` and `PopWord()` does `read = ReadWord(SS:SP); SP += 2` (the interpreter
`PushWord`/`PopWord`, `M8086Cpu.Stack.cs`). The emit form:

- `EmitM8086PushWord(pushValue)` — `SP = (ushort)(SP - 2)`; then write the word at physical
  `(SS<<4) + SP` with the offset-wrap (the high byte at `(SS<<4)+((SP+1)&0xFFFF)`) using PR-B's
  `EmitM8086StoreWordEa`-style offset-wrap store, but with segment = SS and offset = the new SP. `pushValue`
  leaves the word on the stack.
- `EmitM8086PopWord()` — read the word at physical `(SS<<4)+SP` (offset-wrap); `SP = (ushort)(SP + 2)`;
  leave the popped word on the stack.

These reuse PR-B's `EmitM8086PushPhysical` / the offset-wrap byte composition, with SS as the constant
segment register and SP as the runtime offset. **The SMC guard arms for CALL** (it writes the stack RAM,
which could be a code page) — `EmitChainOrExit`'s `dirty.Any` gate is the coarse backstop for the stack
write (the Z80 CALL/RST precedent, `BlockCompiler.cs:523`); no intra-block `mayWriteRam` entry is needed
for the block-ending flow ops (they self-terminate through the chain edge whose `dirty.Any` gate covers
the push).

### DECISION D-4: the dispatch + the gate + the footprint

- **Dispatch:** route under `JitOpClass.Register` + `(TargetIsM8086, control-flow opcode)` →
  `EmitM8086Flow(ctx, pc, d, length)` (needs `length` for the fall-through PC, like `EmitM68kFlow`,
  `BlockCompiler.cs:570`). The control-flow rows are `JitOpClass.Register` (verify against the generated
  table — if a flow row carries a different class, route on that class; the Z80 uses a dedicated
  `Z80Flow` class, but the 8086 generated table classes its flow ops — confirm at implementation; the
  dispatch keys on `(TargetIsM8086, IsM8086FlowOpcode(d.Opcode))` regardless).
- **EndsBlock:** every emitted flow op is `EndsBlock=true` (the descriptor must carry it — the gate-flip
  for flow rows keeps `endsBlock=true`, unlike MOV/ALU which are `endsBlock=false`). The arm
  self-terminates (sets IP, then `EmitChainOrExit` or `EmitNormalExit` + `ret`), exactly like the Z80/68000
  flow arms. So `EmitInstruction` does NOT emit a trailing `EmitBudgetCheck` for an EndsBlock row
  (`BlockCompiler.cs:390-391` already guards on `!d.EndsBlock`).
- **The footprint:** the 8086 flow forms have exact `r.Length` from the decode walk (rel8 = 2-byte instr,
  rel16/CALL rel16 = 3-byte, RET = 1, RET imm16 = 3, FF-group = 2 + ModR/M + disp). The emit arm reads its
  rel/imm/ModR/M at emit time via `M8086CodePhys` and the static target uses `pc + length`. **No footprint
  correction** (the walk's length is already exact — the 68000/8086 footprint model, not the Z80's).
- **The lookahead valve (`CanEmitM8086Flow`):** the in-scope near forms are always emittable; the far forms
  + INT family are NOT in the gate whitelist (stay fallback), so a garbage lookahead decoding as a far flow
  op falls back via the gate (it never reaches `EmitM8086Flow`). The arm default throws (lockstep).

### DECISION D-5: cycles — coarse, data-axis-only (inherited)

Same as PR-B/PR-C: the conditional taken edge charges before chaining so the budget loop never runs away
(the 68000 PR-6 DECISION, `CpuEmitter.cs:4348`); the gate is data-axis (regs + RAM; the flow ops set no
flags, so FLAGS is moot). Coarse `d.BaseCycles`.

## 3. Tasks (literal-code)

### Task 1 — the 8086 stack push/pop emit

**File:** `src/CpuEmulator.Jit/BlockCompiler.M8086.cs` (append to PR-B/PR-C's partial)

```csharp
    /// <summary>M6 PR-D: push a word onto the 8086 SS:SP stack (PushWord, Stack.cs). SP -= 2; write the word at
    /// physical (SS&lt;&lt;4)+SP with the segment-relative offset wrap (hi byte at (SS&lt;&lt;4)+((SP+1)&amp;0xFFFF)).
    /// &lt;paramref name="pushValue"/&gt; leaves the word (int) on the stack.</summary>
    private void EmitM8086PushWord(EmitContext ctx, System.Action pushValue)
    {
        ILGenerator il = ctx.Il;
        // SP = (ushort)(SP - 2)
        il.Emit(OpCodes.Ldarg_0);
        il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, RegField("SP")); il.Emit(OpCodes.Ldc_I4_2); il.Emit(OpCodes.Sub);
        il.Emit(OpCodes.Conv_U2); il.Emit(OpCodes.Stfld, RegField("SP"));
        // seg = SS, offset = SP (the NEW SP) -> survivor pair
        EmitLoadReg16(ctx, "SS"); il.Emit(OpCodes.Stloc, ctx.M8086SegLocal);
        EmitLoadReg16(ctx, "SP"); il.Emit(OpCodes.Stloc, ctx.M8086OffsetLocal);
        pushValue(); il.Emit(OpCodes.Stloc, ctx.DataLocal);   // the word to push
        // write lo at (SS&lt;&lt;4)+SP, hi at (SS&lt;&lt;4)+((SP+1)&amp;0xFFFF) — the PR-B offset-wrap store shape.
        EmitM8086PushPhysical(ctx, offsetPlusOne: false);
        il.Emit(OpCodes.Ldloc, ctx.DataLocal); il.Emit(OpCodes.Conv_U1); EmitStoreByte(ctx);
        EmitM8086PushPhysical(ctx, offsetPlusOne: true);
        il.Emit(OpCodes.Ldloc, ctx.DataLocal); il.Emit(OpCodes.Ldc_I4_8); il.Emit(OpCodes.Shr_Un); il.Emit(OpCodes.Conv_U1); EmitStoreByte(ctx);
    }

    /// <summary>M6 PR-D: pop a word off the 8086 SS:SP stack (PopWord, Stack.cs). Read the word at (SS&lt;&lt;4)+SP
    /// (offset-wrap); SP += 2; leave the popped word (int) on the stack.</summary>
    private void EmitM8086PopWord(EmitContext ctx)
    {
        ILGenerator il = ctx.Il;
        EmitLoadReg16(ctx, "SS"); il.Emit(OpCodes.Stloc, ctx.M8086SegLocal);
        EmitLoadReg16(ctx, "SP"); il.Emit(OpCodes.Stloc, ctx.M8086OffsetLocal);
        // word = lo | hi&lt;&lt;8
        EmitM8086PushPhysical(ctx, offsetPlusOne: false); LoadByteFromBus(ctx); il.Emit(OpCodes.Stloc, ctx.DataLocal);
        EmitM8086PushPhysical(ctx, offsetPlusOne: true); LoadByteFromBus(ctx); il.Emit(OpCodes.Ldc_I4_8); il.Emit(OpCodes.Shl);
        il.Emit(OpCodes.Ldloc, ctx.DataLocal); il.Emit(OpCodes.Or);
        il.Emit(OpCodes.Stloc, ctx.DataLocal);   // stash the popped word (the SP bump clobbers the survivors)
        // SP = (ushort)(SP + 2)
        il.Emit(OpCodes.Ldarg_0);
        il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, RegField("SP")); il.Emit(OpCodes.Ldc_I4_2); il.Emit(OpCodes.Add);
        il.Emit(OpCodes.Conv_U2); il.Emit(OpCodes.Stfld, RegField("SP"));
        il.Emit(OpCodes.Ldloc, ctx.DataLocal);   // leave the popped word on the stack
    }
```

### Task 2 — the Jcc condition emit (the 16-condition matrix)

**File:** `src/CpuEmulator.Jit/BlockCompiler.M8086.cs`

Transcribe `JccTaken` (`Control.cs:26-52`) — push the boolean (int 0/1) onto the stack from the FLAGS bits.
Each condition reads `FLAGS & FlagX` predicates:

```csharp
    /// <summary>M6 PR-D: push the Jcc TAKEN predicate (int 0/1) for opcode 0x70-0x7F (JccTaken, Control.cs:26).
    /// Reads CF/PF/ZF/SF/OF from the FLAGS field. The compound conditions (JBE = cf|zf, JL = sf!=of, etc.) compose
    /// the bit tests inline.</summary>
    private void EmitM8086JccTaken(EmitContext ctx, byte opcode)
    {
        ILGenerator il = ctx.Il;
        // helper: push (FLAGS &amp; mask) != 0 as int 0/1.
        void Flag(int mask) { il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, _m8086FLAGS!); il.Emit(OpCodes.Ldc_I4, mask); il.Emit(OpCodes.And); il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Cgt_Un); }
        void NotFlag(int mask) { Flag(mask); il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Ceq); }
        switch (opcode)
        {
            case 0x70: Flag(M8086FlagOF); return;                                            // JO
            case 0x71: NotFlag(M8086FlagOF); return;                                         // JNO
            case 0x72: Flag(M8086FlagCF); return;                                            // JB/JC
            case 0x73: NotFlag(M8086FlagCF); return;                                         // JAE/JNB
            case 0x74: Flag(M8086FlagZF); return;                                            // JE/JZ
            case 0x75: NotFlag(M8086FlagZF); return;                                         // JNE/JNZ
            case 0x76: Flag(M8086FlagCF); Flag(M8086FlagZF); il.Emit(OpCodes.Or); return;    // JBE: cf|zf
            case 0x77: NotFlag(M8086FlagCF); NotFlag(M8086FlagZF); il.Emit(OpCodes.And); return; // JA: !cf&amp;!zf
            case 0x78: Flag(M8086FlagSF); return;                                            // JS
            case 0x79: NotFlag(M8086FlagSF); return;                                         // JNS
            case 0x7A: Flag(M8086FlagPF); return;                                            // JP/JPE
            case 0x7B: NotFlag(M8086FlagPF); return;                                         // JNP/JPO
            case 0x7C: EmitM8086SfNeOf(ctx); return;                                         // JL: sf!=of
            case 0x7D: EmitM8086SfNeOf(ctx); il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Ceq); return; // JGE: sf==of
            case 0x7E: Flag(M8086FlagZF); EmitM8086SfNeOf(ctx); il.Emit(OpCodes.Or); return; // JLE: zf|(sf!=of)
            default:   // 0x7F JG: !zf &amp; (sf==of)
                NotFlag(M8086FlagZF);
                EmitM8086SfNeOf(ctx); il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Ceq);       // (sf==of)
                il.Emit(OpCodes.And);
                return;
        }
    }

    /// <summary>Push (SF != OF) as int 0/1 — both normalized to 0/1 then compared (Cgt_Un on each, then Ceq==0
    /// for "different"). Used by JL/JGE/JLE/JG.</summary>
    private void EmitM8086SfNeOf(EmitContext ctx)
    {
        ILGenerator il = ctx.Il;
        il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, _m8086FLAGS!); il.Emit(OpCodes.Ldc_I4, M8086FlagSF); il.Emit(OpCodes.And); il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Cgt_Un);
        il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, _m8086FLAGS!); il.Emit(OpCodes.Ldc_I4, M8086FlagOF); il.Emit(OpCodes.And); il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Cgt_Un);
        il.Emit(OpCodes.Ceq); il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Ceq);   // (sf01 == of01) == 0  ⇒  sf != of
    }
```

### Task 3 — the flow emit arm

**File:** `src/CpuEmulator.Jit/BlockCompiler.M8086.cs`

```csharp
    /// <summary>M6 PR-D: emit one 8086 NEAR control-flow instruction (DECISION D-1/D-2). Reached when
    /// TargetIsM8086 &amp;&amp; the row is an in-scope flow opcode. STATIC targets (Jcc/JMP/CALL rel, LOOP*) chain via
    /// EmitChainOrExit (the target is a compile-time constant = (pc+length) + rel); DYNAMIC targets (RET pop,
    /// FF /2 /4 indirect) set IP from a runtime value and EmitNormalExit. Conditional forms chain BOTH the taken
    /// (static) and not-taken (pc+length) edges. The arm self-terminates (sets IP, exits, ret). NO flags. The
    /// default throws (lockstep). &lt;paramref name="length"/&gt; is the walk's exact footprint (the fall-through base).</summary>
    private void EmitM8086Flow(EmitContext ctx, ushort pc, OpcodeDescriptor d, int length)
    {
        ILGenerator il = ctx.Il;
        byte opcode = (byte)d.Opcode;
        int operandPc = pc;   // the byte after the opcode (EmitInstruction advanced PC by 1 already)
        ushort fallThrough = (ushort)(pc + length);   // the static not-taken / next-instruction PC

        // Advance the IP field to the fall-through FIRST (the post-instruction IP = pc+length), so a taken branch
        // adds rel to it and a not-taken / RET / indirect path already has the correct base. EmitInstruction
        // advanced by 1 (opcode); advance the remaining tail here.
        int tail = M8086FlowTailLength(opcode, ctx, ref operandPc, pc, out byte modrm, out uint mod, out uint rm,
                                        out short rel, out ushort imm16);
        if (tail &gt; 0) EmitIncrementPC(ctx, tail);   // IP now == fallThrough

        switch (opcode)
        {
            // ── 70-7F Jcc rel8: conditional, both edges static. ──────────────────────────────────────────────
            case &gt;= 0x70 and &lt;= 0x7F:
            {
                ushort target = (ushort)(fallThrough + rel);   // rel = (sbyte) the rel8
                Label notTaken = il.DefineLabel();
                EmitM8086JccTaken(ctx, opcode);                // push taken? (0/1)
                il.Emit(OpCodes.Brfalse, notTaken);
                EmitM8086SetIp(ctx, target);                   // IP = target
                EmitChainOrExit(ctx, target);                  // STATIC taken edge — chainable
                il.MarkLabel(notTaken);
                // IP already == fallThrough; chain the not-taken edge.
                EmitChainOrExit(ctx, fallThrough);             // STATIC not-taken edge — chainable
                return;
            }

            // ── EB JMP rel8 / E9 JMP rel16: unconditional static. ────────────────────────────────────────────
            case 0xEB: case 0xE9:
            {
                ushort target = (ushort)(fallThrough + rel);   // rel = (sbyte) rel8 for EB, (short) rel16 for E9
                EmitM8086SetIp(ctx, target);
                EmitChainOrExit(ctx, target);
                return;
            }

            // ── E8 CALL rel16: push return IP (== fallThrough), then jump to the static target. ───────────────
            case 0xE8:
            {
                ushort target = (ushort)(fallThrough + rel);
                EmitM8086PushWord(ctx, () =&gt; EmitM8086SetIpValueOnStack(ctx, fallThrough));   // push the return IP
                EmitM8086SetIp(ctx, target);
                EmitChainOrExit(ctx, target);                  // STATIC call entry — chainable (Z80 EmitZ80Call shape)
                return;
            }

            // ── C3 RET / C2 RET imm16: pop IP (dynamic), C2 also adds imm16 to SP. ───────────────────────────
            case 0xC3: case 0xC2:
            {
                EmitM8086PopWord(ctx); EmitM8086SetIpFromStack(ctx);   // IP = pop()
                if (opcode == 0xC2)                                     // SP += imm16
                {
                    il.Emit(OpCodes.Ldarg_0);
                    il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, RegField("SP")); il.Emit(OpCodes.Ldc_I4, (int)imm16); il.Emit(OpCodes.Add);
                    il.Emit(OpCodes.Conv_U2); il.Emit(OpCodes.Stfld, RegField("SP"));
                }
                EmitNormalExit(ctx);                                   // DYNAMIC popped target — NOT chainable
                return;
            }

            // ── E0/E1/E2/E3 LOOP family: CX-conditioned static short jump. ────────────────────────────────────
            case 0xE0: case 0xE1: case 0xE2: case 0xE3:
            {
                ushort target = (ushort)(fallThrough + rel);
                Label notTaken = il.DefineLabel();
                EmitM8086LoopTaken(ctx, opcode);               // push taken? (decrements CX for E0-E2; reads ZF/CX)
                il.Emit(OpCodes.Brfalse, notTaken);
                EmitM8086SetIp(ctx, target); EmitChainOrExit(ctx, target);
                il.MarkLabel(notTaken);
                EmitChainOrExit(ctx, fallThrough);
                return;
            }

            // ── FF /2 CALL r/m16 near indirect (key 0x7FA) / FF /4 JMP r/m16 (key 0x7FC): dynamic target. ─────
            case 0xFF when d.Opcode is 0x7FA or 0x7FC:   // (the gate routes only /2 and /4 here; /3 /5 are far → fallback)
            {
                // target = ReadRmWord(mod, rm, disp) — runtime. For /2 (CALL) push the return IP first.
                if (d.Opcode == 0x7FA)
                    EmitM8086PushWord(ctx, () =&gt; EmitM8086SetIpValueOnStack(ctx, fallThrough));   // push return IP
                EmitM8086LoadRmWordTarget(ctx, mod, rm, modrm, pc);   // push the r/m16 target (reg or memory)
                EmitM8086SetIpFromStack(ctx);                         // IP = target
                EmitNormalExit(ctx);                                  // DYNAMIC indirect target — NOT chainable
                return;
            }

            default:
                throw new EmulationException($"BlockCompiler: no 8086 flow emit branch for opcode 0x{opcode:X2} (key 0x{d.Opcode:X}); a lockstep bug.");
        }
    }

    /// <summary>IP = (ushort)target (a compile-time constant).</summary>
    private void EmitM8086SetIp(EmitContext ctx, ushort target)
    { ctx.Il.Emit(OpCodes.Ldarg_0); ctx.Il.Emit(OpCodes.Ldc_I4, (int)target); ctx.Il.Emit(OpCodes.Conv_U2); ctx.Il.Emit(OpCodes.Stfld, _fpc); }

    /// <summary>IP = (ushort)(the value on the stack).</summary>
    private void EmitM8086SetIpFromStack(EmitContext ctx)
    { ctx.Il.Emit(OpCodes.Conv_U2); ctx.Il.Emit(OpCodes.Stloc, ctx.DataLocal); ctx.Il.Emit(OpCodes.Ldarg_0); ctx.Il.Emit(OpCodes.Ldloc, ctx.DataLocal); ctx.Il.Emit(OpCodes.Stfld, _fpc); }

    /// <summary>Push a constant value (the return IP) onto the IL stack for EmitM8086PushWord's pushValue.</summary>
    private void EmitM8086SetIpValueOnStack(EmitContext ctx, ushort value) { ctx.Il.Emit(OpCodes.Ldc_I4, (int)value); }
```

> **`_fpc` is the IP field** (the ProgramCounterField, resolved in the ctor as `_fpc`,
> `BlockCompiler.cs:104` — for the 8086 it is "IP"). `EmitM8086SetIp` reuses it directly (the same field
> `EmitIncrementPC` writes).
>
> **`EmitM8086LoopTaken`** transcribes the LOOP/LOOPE/LOOPNE/JCXZ predicate (`Control.cs:119-141`):
> decrement CX (for E0/E1/E2, NOT E3), then push the taken condition (`CX!=0` for LOOP; `CX!=0 && ZF` for
> LOOPE; `CX!=0 && !ZF` for LOOPNE; `CX==0` for JCXZ). Builder writes it verbatim against the oracle.
>
> **`EmitM8086LoadRmWordTarget`** reuses PR-B's r/m read: for `mod==3` it loads the 16-bit register; else
> it resolves the EA + reads the word (the offset-wrap `EmitM8086LoadWordEa`). The disp comes from the
> emit-time ModR/M decode (via `M8086CodePhys`).
>
> **`M8086FlowTailLength`** decodes the per-form operand bytes at emit time (reading rel8/rel16/imm16/ModR/M
> via `M8086CodePhys`) and returns the tail length + the decoded `rel`/`imm16`/`modrm`/`mod`/`rm` via `out`
> params — the flow analogue of `M8086MovTailLength`. (rel8 forms: tail 1, rel = (sbyte); rel16/CALL: tail 2,
> rel = (short); RET: tail 0; RET imm16: tail 2, imm16; FF-group: tail 1 + dispLen.)
