## Objective (the ADR §8 PR-2 row)

Make the Z80 **8-bit ALU family** (`ADD`/`ADC`/`SUB`/`SBC`/`AND`/`OR`/`XOR`/`CP`), the **8-bit INC/DEC** family,
and the **16-bit `ADD HL,rr`** form emit real IL instead of falling back to `inner.Step` — reproducing the Z80
**flag model byte-for-byte**: all 8 flags `S Z Y(bit5) H X(bit3) P/V N C` including the undocumented X/Y bits, the
**Q register** ("last flag write") lifecycle, and the **WZ/MEMPTR** update the 16-bit ADD touches. Two halves
(ADR §4 Decision 3):

1. **Generator side** (`CpuEmitter.cs`): extend the PR-1 whitelist `IsEmittableZ80Family` (the gate's first
   family entry) to admit the ALU family rows, in lockstep with the emit arm. **Unlike PR-1, NO `JitBaseCycles`
   fix is required** (recon J-CYC below: the Z80 ALU ops ride `InstructionClass.Z80Alu` → `Z80Cycles`, which is
   already correct for every emitted form — 4/7/7/11/6). The generator change is a *pure whitelist extension*,
   so PR-2 ships an *empty-diff regression gate* on every non-Z80 generated table AND on the Z80 ALU rows'
   `BaseCycles` (they must be unchanged — only `NeedsFallback`/`EndsBlock` flip).
2. **JIT side** (`BlockCompiler.Z80.cs`): add the ALU emit arm `EmitZ80Alu` reading the operand through the
   fastmem split or the register field, computing the **full F flag word inline** (mirroring the generated
   `EmitZ80Alu8`/`EmitZ80IncDec8`/`EmitZ80Add16` oracle one-for-one), writing the result, charging the Z80
   T-states to the (already-correct) descriptor `BaseCycles`, setting **`Q = F`** for flag-writing ops, and
   setting **`WZ = HL + 1`** before the 16-bit ADD. The flag word is emitted via a **shared IL flag-compute
   helper** (the central design decision — DECISION D below) that mirrors the generator's own `EmitZ80FlagWord`
   factoring, so ADD/ADC/SUB/SBC/CP share one helper and AND/OR/XOR + INC/DEC each get their own.

**Why PR-2 (ADR §8):** it owns the Z80 flag model — the per-CPU long pole (§2: "the highest-bug-density code in
the JIT"). ADD/SUB/INC/DEC are ~80% of Z80-W2 (§6). The oracle gate (TomHarte-through-JIT + ZEXALL) is the entire
safety net: a flag that is one undocumented bit wrong is a red test, not a shipped bug.

## What the recon CONFIRMED (file:line — load-bearing, verified against `main` @ `bb60d48`)

### The flag layout (the spec — the bit positions every mask in this plan uses)

`Z80Spec.cs:60` — `FlagLayout Flags = new([new("S",7), new("Z",6), new("Y",5), new("H",4), new("X",3),
new("P",2), new("N",1), new("C",0)])`. So the resolved masks are **S=0x80, Z=0x40, Y=0x20, H=0x10, X=0x08,
P=0x04, N=0x02, C=0x01**. The generated bodies use these literal masks (`EmitZ80Alu8`/`EmitZ80FlagWord`,
`CpuEmitter.cs:2198-2283`, resolve them from `flags.BitOf(...)` — they ARE these values). **The emit arm hard-codes
these eight masks** (the Z80 layout is fixed; PR-1's `EmitZ80SetWZ`/`EmitZ80ClearQ` already hard-code the Z80
field shape — same discipline).

### The ALU descriptor rows (the gate's lockstep target — verified in the generated table)

true, EndsBlock=true** — all-fallback). PR-2 flips ONLY `NeedsFallback`/`EndsBlock` → `false`.

> **CRITICAL operand-source detail (J-SRC).** The 8-bit ALU `Register`-mode rows carry an **empty `RegA`** — the
> source register is NOT in the descriptor. It is the **opcode low 3 bits**: `000=B 001=C 010=D 011=E 100=H 101=L
> 110=(HL) 111=A` (the standard Z80 r-field). So `0x80=B … 0x85=L, 0x86=(HL) [RegisterIndirect], 0x87=A`. The arm
> recovers the source via a `Z80AluSource(opcode)` helper (mirrors PR-1's opcode-keyed `Z80IndirectPair`). INC/DEC
> `Register` rows DO carry `RegA` (the target reg). ADD HL,rr carries both `RegA`/`RegB` (no opcode derivation).

### The cycle source — ALREADY CORRECT (J-CYC — the regression-safety simplifier vs PR-1)

`JitBaseCycles` routes any `Z80Alu`-class row to **`Z80Cycles`** (`CpuEmitter.cs:4198-4204`), which is correct for

| …A,(HL) | `(Z80Alu, _, "RegisterIndirect") => 7` (`:1090`) | 7 |
| …A,n | `(Z80Alu, _, "Immediate") => 7` (`:1091`) | 7 |

tables show an empty diff.

### The flag oracle (the interpreter bodies the IL must match byte-identically)

All from generated `…Z80Cpu.g.cs`. **`Q = F`** is set for every flag-writing ALU op (the new F value IS Q — `Q = F;`
is the last line). Fields: `byte F` (`:31`), `byte Q` (`Z80Cpu.cs:64`), `ushort WZ` (`:52`). PR-1 already cached
`_z80Q`/`_z80WZ` and built `EmitZ80SetWZ`/`EmitZ80ClearQ`. **Parity (P flag) is `(BitOperations.PopCount((uint)res)
& 1) == 0`** — no lookup table; the IL emits `call System.Numerics.BitOperations.PopCount(uint)`.

**The five flag shapes** (verbatim from the oracle — Task 3/4 transcribe these to IL):

**(1) ADD/ADC/SUB/SBC** (`Op80`/`Op88`/`Op90`/`Op98`, e.g. `:4832`):
```csharp
// ADD: cin = 0 ; ADC: cin = ((F & 0x01) != 0 ? 1 : 0)
int cin  = …;
int sum  = A + data + cin;                          // SUB/SBC: int diff = A - data - cin;
int half = (A & 0x0F) + (data & 0x0F) + cin;        // SUB/SBC: (A & 0x0F) - (data & 0x0F) - cin
byte res = unchecked((byte)sum);                    // SUB/SBC: (byte)diff
int ov   = (~(A ^ data) & (A ^ res) & 0x80);        // SUB/SBC/CP: ((A ^ data) & (A ^ res) & 0x80)
F = unchecked((byte)(
      ((res & 0x80) != 0 ? 0x80 : 0x00)             // S  — from result bit7
    | (res == 0          ? 0x40 : 0x00)             // Z
    | ((res & 0x20) != 0 ? 0x20 : 0x00)             // Y  — from result bit5  (CP: from DATA bit5)
    | (((half & 0x10) != 0) ? 0x10 : 0x00)          // H  — half carry/borrow
    | ((res & 0x08) != 0 ? 0x08 : 0x00)             // X  — from result bit3  (CP: from DATA bit3)
    | ((ov != 0) ? 0x04 : 0x00)                     // P/V — overflow
    | 0x00                                          // N  — ADD/ADC: 0x00 ; SUB/SBC/CP: 0x02
    | ((sum > 0xFF) ? 0x01 : 0x00)));               // C  — ADD/ADC: sum>0xFF ; SUB/SBC/CP: diff<0
A = res;                                            // CP: NO write to A
… _cycles += residual; Q = F;
```
**(2) CP** (`OpB8`, `:5976`): identical to SUB **except** X/Y come from **`data`** (the operand), not `res`, AND
**A is not written**:
```csharp
    | ((data & 0x20) != 0 ? 0x20 : 0x00)            // Y from DATA bit5
    | ((data & 0x08) != 0 ? 0x08 : 0x00)            // X from DATA bit3
```
**(3) AND/OR/XOR** (`OpA0`/`OpB0`/`OpA8`, `:5568`): no carry/overflow; H is **1 for AND, 0 for OR/XOR**; P = parity;
N=0; C=0:
```csharp
byte res = unchecked((byte)(A & data));            // OR: A|data ; XOR: A^data
F = unchecked((byte)(
      ((res & 0x80) != 0 ? 0x80 : 0x00)            // S
    | (res == 0          ? 0x40 : 0x00)            // Z
    | ((res & 0x20) != 0 ? 0x20 : 0x00)            // Y from result
    | 0x10                                         // H — AND: 0x10 ; OR/XOR: 0x00
    | ((res & 0x08) != 0 ? 0x08 : 0x00)            // X from result
    | ((System.Numerics.BitOperations.PopCount((uint)res) & 1) == 0 ? 0x04 : 0x00))); // P even parity
A = res;
```
**(4) INC/DEC 8-bit** (`Op04`/`Op05`, `:3788`/`:3932`): **C is PRESERVED** (`F & 0x01`); H from the *before* value;
V from a fixed boundary; N is 0 (INC) / 2 (DEC):
```csharp
byte before = B;                                   // or ReadBus(HL) for (HL)
byte res = unchecked((byte)(before + 1));          // DEC: before - 1
F = unchecked((byte)((F & 0x01)                    // C PRESERVED
    | ((res & 0x80) != 0 ? 0x80 : 0x00)            // S
    | (res == 0          ? 0x40 : 0x00)            // Z
    | ((res & 0x20) != 0 ? 0x20 : 0x00)            // Y from result
    | (((before & 0x0F) == 0x0F) ? 0x10 : 0x00)    // H — INC: before&0xF==0xF ; DEC: before&0xF==0x00
    | ((res & 0x08) != 0 ? 0x08 : 0x00)            // X from result
    | ((before == 0x7F) ? 0x04 : 0x00)             // V — INC: before==0x7F ; DEC: before==0x80
    | 0x00));                                       // N — INC: 0x00 ; DEC: 0x02
```
**(5) ADD HL,rr 16-bit** (`Op09`, `:3648`): **WZ = HL+1 BEFORE the add**; preserves **S/Z/P (`F & 0xC4`)**; H is
the 12-bit carry; X/Y from the **high byte of the result**; N=0:
```csharp
int hl = HL;
WZ = unchecked((ushort)(hl + 1));                  // MEMPTR — BEFORE the add
int rr = BC;                                       // RegB pair
int sum16  = hl + rr;
int half16 = (hl & 0x0FFF) + (rr & 0x0FFF);
ushort res16 = unchecked((ushort)sum16);
F = unchecked((byte)((F & 0xC4)                    // preserve S(0x80) Z(0x40) P(0x04)
    | ((half16 & 0x1000) != 0 ? 0x10 : 0x00)       // H — 12-bit carry
    | (sum16 > 0xFFFF ? 0x01 : 0x00)               // C — 16-bit carry
    | (((res16 >> 8) & 0x20) != 0 ? 0x20 : 0x00)   // Y — result HIGH byte bit5
    | (((res16 >> 8) & 0x08) != 0 ? 0x08 : 0x00)));// X — result HIGH byte bit3
HL = res16; _cycles += 10; Q = F;                  // N is implicitly 0 (not OR'd in)
```

### The Q lifecycle (J-Q — the per-CPU subtlety PR-2 owns)

The generator's `Z80WritesFlags` (`CpuEmitter.cs:989-998`) decides `Q = F` vs `Q = 0`: **`Z80Alu` writes flags
(`Q = F`) EXCEPT `Inc16`/`Dec16`** (16-bit INC rr / DEC rr touch NO flags, so `Q = 0`). For PR-2:
- **ADD/ADC/SUB/SBC/AND/OR/XOR/CP/INC8/DEC8/ADD16** all write flags → **`Q = F`** (emit `cpu.Q = cpu.F` AFTER the F
  write). This is a NEW helper `EmitZ80SetQFromF` (PR-1 only had `EmitZ80ClearQ` for `Q = 0`).
- **INC rr / DEC rr (16-bit, `Inc16`/`Dec16`, 0x03/0x0B/…)** touch no flags and set `Q = 0`. They are **OUT of
  PR-2's flag scope** — see DECISION E (defer to PR-3 or a small follow-up; they are trivial 16-bit +1/−1 with
  `Q = 0`, no flag word, so they belong with the no-flag families, not the flag long pole).

### The gate's two force-points (the lockstep mechanism PR-1 built — PR-2 extends `IsEmittableZ80Family`)

`IsEmittableZ80Family(insn)` (`CpuEmitter.cs:4244-4263`) is consulted in TWO places, both of which un-force a
whitelisted row: `KeyedDescriptorLiteral` (`:4140`, `if (!IsEmittableZ80Family) { fallback=true; endsBlock=true; }`)
AND `ClassifyForJit` (`:4304`, `if (IsEmittableZ80Family) z80 = false;`). **Extending the predicate to admit the ALU

## Task 1 — Extend the generator whitelist to the ALU family (no cycle fix — J-CYC)

**Files:**
- Modify: `src/CpuEmulator.Generators/CpuEmitter.cs` (`IsEmittableZ80Family`, `:4244-4263`)

PR-1's predicate hard-codes `if (insn.Mnemonic != "LD") return false;`. PR-2 generalizes it to a small per-family
allow-set keyed on the **op-kind** (the stable, mode-independent signal — verified against the descriptor rows
above), keeping the base-plane guard (excludes ED `EdAdcSbc16`, all DD/FD-indexed ALU, the prefix planes).

- [ ] **Step 1:** Replace the `Mnemonic == "LD"`-only body with a kind-driven allow-set. The base-plane +
  belt-and-suspenders structure of PR-1 is preserved; only the family test changes.

```csharp
    // M6 PR-1/PR-2: the emittable-Z80-family whitelist (the gate's lockstep target). A BASE-PLANE row is
    // emittable iff its op-kind is in the proven-emittable set (each kind has a matching emit branch in
    // BlockCompiler.Z80.cs — EmitZ80Ld for the LD kinds, EmitZ80Alu for the ALU kinds). The whitelist and the
    // arms MUST stay in lockstep: the arm's default throws if the gate admits a kind with no branch.
    //
    // EXCLUSIONS (all stay JIT fallback — by §2, not yet armed):
    //   • Non-base-plane rows (KeyShape != OpcodeByte OR Prefix != -1): the ED-plane ADC/SBC HL,rr
    //     (EdAdcSbc16 — PrefixedOpcode, DECISION E: a follow-up PR), the ED LD A,I/A,R, EVERY DD/FD-indexed
    //     ALU/LD. The base-plane gate is the real exclusion for the indexed forms (their mode/kind can match).
    //   • 0xF9 LD SP,HL (16-bit Register/Transfer) — no 8-bit arm (PR-1 exclusion, retained).
    //   • Inc16/Dec16 (INC rr / DEC rr, 0x03/0x0B/...): they touch NO flags and set Q=0 (Z80WritesFlags=false);
    //     they are NOT in PR-2's flag scope (DECISION E) — they ride a later no-flag PR.
    // Extended family-by-family in PR-3+.
    private static bool IsEmittableZ80Family(InstructionModel insn)
    {
        // Base plane only — exclude ED / DD / FD prefixed forms (their mode/kind can match the sets below).
        if (insn.KeyShape != KeyShape.OpcodeByte || insn.Prefix != -1) return false;
        if (insn.Opcode == 0xF9) return false;                  // LD SP,HL (16-bit transfer) — no 8-bit arm.

        string kind = insn.Ops.Length > 0 ? insn.Ops[0].Kind : string.Empty;

        // ── M6 PR-1: the LD family ──
        if (insn.Mnemonic == "LD")
        {
            bool ldModeOk = insn.Mode is "Register" or "Immediate" or "RegisterIndirect"
                                       or "ExtendedAddress" or "ImmediateExtended";
            if (!ldModeOk) return false;
            if (kind is "EdLdIaRa") return false;               // belt-and-suspenders (base-plane-excluded already)
            return true;
        }

        // ── M6 PR-2: the ALU + INC/DEC + 16-bit-ADD family (all base-plane Z80Alu, JitOpClass.Register) ──
        // 8-bit ALU (ADD/ADC/SUB/SBC/AND/OR/XOR/CP) over Register / RegisterIndirect(HL) / Immediate.
        // 8-bit INC/DEC over Register and (HL). 16-bit ADD HL,rr. NO Inc16/Dec16 (no flags, DECISION E).
        if (kind is "Add8" or "Adc8" or "Sub8" or "Sbc8" or "And8" or "Or8" or "Xor8" or "Cp8"
                  or "IncReg" or "DecReg" or "IncMem8" or "DecMem8"
                  or "Add16")
            return true;

        return false;
```

**DECISION D — a SHARED IL flag-compute helper, mirroring the generator's `EmitZ80FlagWord` factoring (NOT inline
per-op).** The oracle (`EmitZ80Alu8`/`EmitZ80FlagWord`, `CpuEmitter.cs:2198-2283`) itself factors the flag word into

- [ ] **Step 5:** `EmitZ80AddSubFlags` — the shared ADD/ADC/SUB/SBC/CP flag word (shape 1+2). Contract: the arm
  pre-stages `A` (the original accumulator, int) in `ctx.NibLocal`, `data` (operand, int) in `ctx.DataLocal`, the
  signed `sum`/`diff` (int) in `ctx.SumLocal`, the `half` (int) in `ctx.TmpInt`, and `res` (byte-as-int) in
  `ctx.LoLocal` (reusing the existing int/uint scratch locals; see Task 4 for the staging). The helper takes flags
  `(bool subtract, bool xyFromData)` and emits the eight-way OR into F. `ov` is recomputed inside from A/data/res
  (it is cheap and keeps the helper self-contained):

```csharp
    // M6 PR-2: emit the Z80 add/sub-shaped F flag word (ADD/ADC/SUB/SBC/CP). Mirrors EmitZ80FlagWord
    // (CpuEmitter.cs:2269-2283) one-for-one. Pre-staged by the caller:
    //   ctx.NibLocal = A (original accumulator, int)   ctx.DataLocal = data (operand, int)
    //   ctx.SumLocal = sum/diff (SIGNED int)           ctx.TmpInt    = half (SIGNED int)
    //   ctx.LoLocal  = res = (byte)(sum/diff) (int 0..255)
    // subtract: false=ADD/ADC (N=0, ov=~(A^data)&(A^res), C=sum>0xFF), true=SUB/SBC/CP (N=1, ov=(A^data)&(A^res),
    // C=diff<0). xyFromData: false=Y/X from res (ADD/ADC/SUB/SBC), true=from data (CP — the operand-XY quirk).
    private void EmitZ80AddSubFlags(EmitContext ctx, bool subtract, bool xyFromData)
    {
        ILGenerator il = ctx.Il;
        // xy source local: res (LoLocal) for ADD/ADC/SUB/SBC, data (DataLocal) for CP (the operand-XY quirk).
        LocalBuilder xyLoc = xyFromData ? ctx.DataLocal : ctx.LoLocal;
        // Build F = S|Z|Y|H|X|P/V|N|C by OR-ing int terms on the stack, then Stfld via EmitStoreF.
        // S: (res & 0x80)
        il.Emit(OpCodes.Ldloc, ctx.LoLocal); il.Emit(OpCodes.Ldc_I4, 0x80); il.Emit(OpCodes.And);
        // Z: (res == 0) ? 0x40 : 0
        EmitSelectMask(ctx, () => { il.Emit(OpCodes.Ldloc, ctx.LoLocal); il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Ceq); }, 0x40);
        il.Emit(OpCodes.Or);
        // Y: (xy & 0x20)   — xy = res (LoLocal) or data (DataLocal); the bit position equals the Y flag bit.
        il.Emit(OpCodes.Ldloc, xyLoc); il.Emit(OpCodes.Ldc_I4, 0x20); il.Emit(OpCodes.And); il.Emit(OpCodes.Or);
        // H: ((half & 0x10) != 0) ? 0x10 : 0
        il.Emit(OpCodes.Ldloc, ctx.TmpInt); il.Emit(OpCodes.Ldc_I4, 0x10); il.Emit(OpCodes.And); il.Emit(OpCodes.Or);
        // X: ((xy & 0x08) != 0) ? 0x08 : 0
        il.Emit(OpCodes.Ldloc, xyLoc); il.Emit(OpCodes.Ldc_I4, 0x08); il.Emit(OpCodes.And); il.Emit(OpCodes.Or);
        // P/V: overflow — ov = (subtract ? (A^data) : ~(A^data)) & (A^res) & 0x80
        EmitZ80Overflow(ctx, subtract);                       // pushes 0x04 or 0x00
        il.Emit(OpCodes.Or);
        // N: subtract ? 0x02 : 0x00
        if (subtract) { il.Emit(OpCodes.Ldc_I4, 0x02); il.Emit(OpCodes.Or); }
        // C: subtract ? (diff < 0) : (sum > 0xFF)  → 0x01
        il.Emit(OpCodes.Ldloc, ctx.SumLocal);
        if (subtract) { il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Clt); }                 // diff < 0
        else          { il.Emit(OpCodes.Ldc_I4, 0xFF); il.Emit(OpCodes.Cgt); }             // sum > 0xFF
        il.Emit(OpCodes.Ldc_I4_1); il.Emit(OpCodes.And);                                    // bool→{1,0}; *0x01
        il.Emit(OpCodes.Or);
        // F = (byte)(accumulated OR)
        EmitStoreF(ctx);                                       // Conv_U1 + Stfld _z80F
    }
```

> **Builder note — the IL stack discipline above is the load-bearing detail.** The helper accumulates the eight
> flag terms by repeated `Or` on the stack. Each term must push exactly one int. The `S` term `(res & 0x80)` is
> already 0 or 0x80 — no select needed (the mask value EQUALS the flag bit, the Z80 layout's gift: S=bit7=0x80,
> Y=bit5=0x20, H=bit4=0x10, X=bit3=0x08 all line up so `value & mask` IS the flag contribution). **Verify this
> alignment per bit** — it holds for S(0x80)/Y(0x20)/H(0x10 via half&0x10)/X(0x08) because the result/half bit
> position equals the flag bit position. Z/P/V/N/C need an explicit select (`Ceq`/`Clt`/`Cgt` → multiply by the
> mask) because their *condition* bit doesn't sit at the flag position. `EmitSelectMask`/`EmitZ80Overflow`/
> `EmitStoreF` are small helpers (Step 6); a clean alternative is to compute each term into a local and OR at the
> end — the Builder may restructure as long as the final F byte equals the oracle for all 256×256 input pairs
> (the TomHarte sweep, Task 6, proves it exhaustively).

```csharp

    private void EmitSelectMask(EmitContext ctx, Action emitCond, int mask)
    {
        emitCond();                              // 1 or 0 (int)
        ctx.Il.Emit(OpCodes.Ldc_I4, mask);
        ctx.Il.Emit(OpCodes.Mul);                // (1|0) * mask
    }

    // push the P/V term (0x04 or 0x00): ov = (subtract ? (A^data) : ~(A^data)) & (A^res) & 0x80; term = ov!=0 ? 0x04:0.
    // Reads ctx.NibLocal=A, ctx.DataLocal=data, ctx.LoLocal=res (all int).
    private void EmitZ80Overflow(EmitContext ctx, bool subtract)
    {
        ILGenerator il = ctx.Il;
        il.Emit(OpCodes.Ldloc, ctx.NibLocal); il.Emit(OpCodes.Ldloc, ctx.DataLocal); il.Emit(OpCodes.Xor); // A^data
        if (!subtract) { il.Emit(OpCodes.Ldc_I4_M1); il.Emit(OpCodes.Xor); }                                // ~(A^data)
        il.Emit(OpCodes.Ldloc, ctx.NibLocal); il.Emit(OpCodes.Ldloc, ctx.LoLocal); il.Emit(OpCodes.Xor);    // A^res
        il.Emit(OpCodes.And);
        il.Emit(OpCodes.Ldc_I4, 0x80); il.Emit(OpCodes.And);    // & 0x80
        il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Cgt_Un);     // ov != 0 → 1/0  (Cgt_Un: any nonzero > 0)
        il.Emit(OpCodes.Ldc_I4, 0x04); il.Emit(OpCodes.Mul);    // * 0x04 (P bit)
    }

    private void EmitStoreF(EmitContext ctx)
    {

        ctx.Il.Emit(OpCodes.Ldloc, ctx.TmpInt);
        ctx.Il.Emit(OpCodes.Conv_U1);
        ctx.Il.Emit(OpCodes.Stfld, _z80F!);
    }
```

```csharp
                break;
            case "IncReg": case "DecReg": case "IncMem8": case "DecMem8":
                EmitZ80IncDec(ctx, d, op);
                break;
            case "Add16":
                EmitZ80Add16(ctx, d, op);
                break;
            default:
                throw new EmulationException(
                    $"EmitZ80Alu: unhandled ALU kind '{op.Kind}' (opcode=0x{d.Opcode:X2}). The whitelist "
                  + "(IsEmittableZ80Family) admitted a kind with no emit branch — keep it fallback until armed.");
        }
    }
```

- [ ] **Step 2:** `EmitZ80Alu8` — read the operand into `ctx.DataLocal` (int), stage `A` into `ctx.NibLocal`,
  compute the binary sum/diff into `ctx.SumLocal` and the half into `ctx.TmpInt`, then `res` into `ctx.LoLocal`,
  call the shared flag helper, write A (unless CP), `Q = F`, charge the residual:

```csharp
    private void EmitZ80Alu8(EmitContext ctx, OpcodeDescriptor d, JitOp op)
    {
        ILGenerator il = ctx.Il;
        bool isAdd = op.Kind is "Add8" or "Adc8";
        bool isLogic = op.Kind is "And8" or "Or8" or "Xor8";
        bool isCp = op.Kind == "Cp8";
        bool carryIn = op.Kind is "Adc8" or "Sbc8";

        // 1) data → ctx.DataLocal (int), and charge the operand-access cycle where applicable.
        int residual;
        switch (d.Mode)
        {
            case JitMode.Register:                                     // ADD A,r — source = opcode low 3 bits
                il.Emit(OpCodes.Ldarg_0);
                il.Emit(OpCodes.Ldfld, RegField(Z80AluSource(d.Opcode)));
                il.Emit(OpCodes.Stloc, ctx.DataLocal);
                residual = 3;                                          // 4 T = fetch 1 + 3
                break;
            case JitMode.RegisterIndirect:                            // ADD A,(HL)
                EmitLoadReg16(ctx, "HL"); il.Emit(OpCodes.Conv_U4);
                LoadByteFromBus(ctx);                                  // charges 1
                il.Emit(OpCodes.Stloc, ctx.DataLocal);
                residual = 5;                                          // 7 T = fetch 1 + read 1 + 5
                break;
            case JitMode.Immediate:                                   // ADD A,n
                EmitLoadPC(ctx); il.Emit(OpCodes.Conv_U4);
                LoadByteFromBus(ctx);                                  // charges 1
                il.Emit(OpCodes.Stloc, ctx.DataLocal);
                EmitIncrementPC(ctx, 1);
                residual = 5;                                          // 7 T = fetch 1 + imm 1 + 5
                break;
            default:
                throw new EmulationException($"EmitZ80Alu8: bad mode {d.Mode} for 0x{d.Opcode:X2}");
        }

        // 2) A → ctx.NibLocal (int, the original accumulator the flag math + write-back read).
        il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, RegField("A")); il.Emit(OpCodes.Stloc, ctx.NibLocal);

        if (isLogic)
        {
            // res = A op data → ctx.LoLocal
            il.Emit(OpCodes.Ldloc, ctx.NibLocal); il.Emit(OpCodes.Ldloc, ctx.DataLocal);
            il.Emit(op.Kind == "And8" ? OpCodes.And : op.Kind == "Or8" ? OpCodes.Or : OpCodes.Xor);
            il.Emit(OpCodes.Ldc_I4, 0xFF); il.Emit(OpCodes.And);              // (byte)
            il.Emit(OpCodes.Stloc, ctx.LoLocal);
            EmitZ80LogicFlags(ctx, isAnd: op.Kind == "And8");
            // A = res
            il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldloc, ctx.LoLocal); il.Emit(OpCodes.Conv_U1);
            il.Emit(OpCodes.Stfld, RegField("A"));
        }
        else
        {
            bool subtract = op.Kind is "Sub8" or "Sbc8" or "Cp8";
            // cin (int) on stack for sum/diff and half.
            // sum/diff = A ± data ± cin → ctx.SumLocal (SIGNED int)
            il.Emit(OpCodes.Ldloc, ctx.NibLocal); il.Emit(OpCodes.Ldloc, ctx.DataLocal);
            il.Emit(subtract ? OpCodes.Sub : OpCodes.Add);
            EmitZ80CarryIn(ctx, carryIn, subtract);                          // ± cin (or nothing)
            il.Emit(OpCodes.Stloc, ctx.SumLocal);
            // half = (A & 0x0F) ± (data & 0x0F) ± cin → ctx.TmpInt
            il.Emit(OpCodes.Ldloc, ctx.NibLocal); il.Emit(OpCodes.Ldc_I4, 0x0F); il.Emit(OpCodes.And);
            il.Emit(OpCodes.Ldloc, ctx.DataLocal); il.Emit(OpCodes.Ldc_I4, 0x0F); il.Emit(OpCodes.And);
            il.Emit(subtract ? OpCodes.Sub : OpCodes.Add);
            EmitZ80CarryIn(ctx, carryIn, subtract);
            il.Emit(OpCodes.Stloc, ctx.TmpInt);
            // res = (byte)(sum/diff) → ctx.LoLocal
            il.Emit(OpCodes.Ldloc, ctx.SumLocal); il.Emit(OpCodes.Ldc_I4, 0xFF); il.Emit(OpCodes.And);
            il.Emit(OpCodes.Stloc, ctx.LoLocal);
            EmitZ80AddSubFlags(ctx, subtract, xyFromData: isCp);
            if (!isCp)                                                       // CP writes NO result
            {
                il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldloc, ctx.LoLocal); il.Emit(OpCodes.Conv_U1);
                il.Emit(OpCodes.Stfld, RegField("A"));
            }
        }

        EmitZ80SetQFromF(ctx);
        EmitChargeCycles(ctx, residual);
    }

    // push and apply ± cin: ADC/SBC read the OLD C flag (cpu.F & 0x01); ADD/SUB add/sub nothing. The op (Add/Sub)
    // matches the running accumulation's direction (cin is ADDED for ADC, SUBTRACTED for SBC — same sign as data).
    private void EmitZ80CarryIn(EmitContext ctx, bool carryIn, bool subtract)
    {
        if (!carryIn) return;
        ILGenerator il = ctx.Il;
        il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, _z80F!); il.Emit(OpCodes.Ldc_I4_1); il.Emit(OpCodes.And); // cin
        il.Emit(subtract ? OpCodes.Sub : OpCodes.Add);
    }
```

> **Builder note — `cin` read timing.** ADC/SBC read the carry from the OLD `cpu.F` (before this op writes F). The
> staging above reads `cpu.F & 1` while computing sum/diff/half — all BEFORE `EmitZ80AddSubFlags` writes the new F.
> Confirm no intervening F write. (The oracle reads `cin` first, computes, then writes F last — same order.)

- [ ] **Step 3:** `EmitZ80IncDec` — read `before` (`RegField(op.RegA)` for IncReg/DecReg; `ReadBus(HL)` for
  IncMem8/DecMem8) into `ctx.DataLocal`, compute `res`→`ctx.LoLocal`, call `EmitZ80IncDecFlags`, write back (reg or
  `(HL)`), `Q = F`, residual:

```csharp
    private void EmitZ80IncDec(EmitContext ctx, OpcodeDescriptor d, JitOp op)
    {
        ILGenerator il = ctx.Il;
        bool increment = op.Kind is "IncReg" or "IncMem8";
        bool isMem = op.Kind is "IncMem8" or "DecMem8";

        if (isMem)
        {
            // before = ReadBus(HL) → DataLocal ; res = (byte)(before ± 1) → LoLocal ; flags ; WriteBus(HL,res)
            EmitLoadReg16(ctx, "HL"); il.Emit(OpCodes.Conv_U4); LoadByteFromBus(ctx);   // charges 1
            il.Emit(OpCodes.Stloc, ctx.DataLocal);
            il.Emit(OpCodes.Ldloc, ctx.DataLocal); il.Emit(increment ? OpCodes.Ldc_I4_1 : OpCodes.Ldc_I4_M1);
            il.Emit(OpCodes.Add); il.Emit(OpCodes.Ldc_I4, 0xFF); il.Emit(OpCodes.And);
            il.Emit(OpCodes.Stloc, ctx.LoLocal);
            EmitZ80IncDecFlags(ctx, increment);
            // WriteBus(HL, res)
            EmitLoadReg16(ctx, "HL"); il.Emit(OpCodes.Conv_U4);
            il.Emit(OpCodes.Ldloc, ctx.LoLocal); il.Emit(OpCodes.Conv_U1);
            EmitStoreByte(ctx);                                                         // charges 1; marks dirty
            EmitZ80SetQFromF(ctx);
            EmitChargeCycles(ctx, 8);                                                   // 11 T = fetch1 + read1 + write1 + 8
        }
        else
        {
            // before = reg → DataLocal ; res = (byte)(before ± 1) → LoLocal ; flags ; reg = res
            il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, RegField(op.RegA)); il.Emit(OpCodes.Stloc, ctx.DataLocal);
            il.Emit(OpCodes.Ldloc, ctx.DataLocal); il.Emit(increment ? OpCodes.Ldc_I4_1 : OpCodes.Ldc_I4_M1);
            il.Emit(OpCodes.Add); il.Emit(OpCodes.Ldc_I4, 0xFF); il.Emit(OpCodes.And);
            il.Emit(OpCodes.Stloc, ctx.LoLocal);
            EmitZ80IncDecFlags(ctx, increment);
            il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldloc, ctx.LoLocal); il.Emit(OpCodes.Conv_U1);
            il.Emit(OpCodes.Stfld, RegField(op.RegA));
            EmitZ80SetQFromF(ctx);
            EmitChargeCycles(ctx, 3);                                                   // 4 T = fetch1 + 3
        }
    }
```

- [ ] **Step 4:** `EmitZ80Add16` — `WZ = HL+1` FIRST, then `sum16`/`half16`/`res16`, the partial flag word
  (preserve S/Z/P via `F & 0xC4`, set H/C/Y/X), `HL = res16`, `Q = F`, residual 10. The pair is `op.RegB`:

```csharp
    private void EmitZ80Add16(EmitContext ctx, OpcodeDescriptor d, JitOp op)
    {
        ILGenerator il = ctx.Il;
        // WZ = (ushort)(HL + 1)  — MEMPTR, set BEFORE the add (oracle Op09).
        EmitLoadReg16(ctx, "HL"); il.Emit(OpCodes.Ldc_I4_1); il.Emit(OpCodes.Add);
        EmitZ80SetWZ(ctx);                                                  // PR-1 helper
        // hl → NibLocal (int), rr → DataLocal (int)
        EmitLoadReg16(ctx, "HL"); il.Emit(OpCodes.Stloc, ctx.NibLocal);
        EmitLoadReg16(ctx, op.RegB); il.Emit(OpCodes.Stloc, ctx.DataLocal);
        // sum16 = hl + rr → SumLocal ; res16 = (ushort)sum16 → LoLocal ; half16 = (hl&0xFFF)+(rr&0xFFF) → TmpInt
        il.Emit(OpCodes.Ldloc, ctx.NibLocal); il.Emit(OpCodes.Ldloc, ctx.DataLocal); il.Emit(OpCodes.Add);
        il.Emit(OpCodes.Stloc, ctx.SumLocal);
        il.Emit(OpCodes.Ldloc, ctx.SumLocal); il.Emit(OpCodes.Ldc_I4, 0xFFFF); il.Emit(OpCodes.And);
        il.Emit(OpCodes.Stloc, ctx.LoLocal);                                // res16
        il.Emit(OpCodes.Ldloc, ctx.NibLocal); il.Emit(OpCodes.Ldc_I4, 0x0FFF); il.Emit(OpCodes.And);
        il.Emit(OpCodes.Ldloc, ctx.DataLocal); il.Emit(OpCodes.Ldc_I4, 0x0FFF); il.Emit(OpCodes.And);
        il.Emit(OpCodes.Add); il.Emit(OpCodes.Stloc, ctx.TmpInt);           // half16
        // F = (oldF & 0xC4) | H | C | Y | X  (S/Z/P preserved; N implicitly 0)
        il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, _z80F!); il.Emit(OpCodes.Ldc_I4, 0xC4); il.Emit(OpCodes.And);
        EmitSelectMask(ctx, () => { il.Emit(OpCodes.Ldloc, ctx.TmpInt); il.Emit(OpCodes.Ldc_I4, 0x1000); il.Emit(OpCodes.And); il.Emit(OpCodes.Ldc_I4_0); il.Emit(OpCodes.Cgt_Un); }, 0x10); il.Emit(OpCodes.Or); // H
        EmitSelectMask(ctx, () => { il.Emit(OpCodes.Ldloc, ctx.SumLocal); il.Emit(OpCodes.Ldc_I4, 0xFFFF); il.Emit(OpCodes.Cgt); }, 0x01); il.Emit(OpCodes.Or); // C: sum16 > 0xFFFF
        // Y/X from res16 high byte: ((res16 >> 8) & 0x20) and ((res16 >> 8) & 0x08)
        il.Emit(OpCodes.Ldloc, ctx.LoLocal); il.Emit(OpCodes.Ldc_I4_8); il.Emit(OpCodes.Shr_Un); il.Emit(OpCodes.Ldc_I4, 0x20); il.Emit(OpCodes.And); il.Emit(OpCodes.Or); // Y
        il.Emit(OpCodes.Ldloc, ctx.LoLocal); il.Emit(OpCodes.Ldc_I4_8); il.Emit(OpCodes.Shr_Un); il.Emit(OpCodes.Ldc_I4, 0x08); il.Emit(OpCodes.And); il.Emit(OpCodes.Or); // X
        EmitStoreF(ctx);
        // HL = res16
        il.Emit(OpCodes.Ldloc, ctx.LoLocal);
        EmitStoreReg16(ctx, "HL");
        EmitZ80SetQFromF(ctx);
        EmitChargeCycles(ctx, 10);                                          // 11 T = fetch1 + 10
    }
```

> **Builder note — `op.RegA` is "HL" for ADD HL,rr; use `op.RegB` for the addend pair** (the descriptor carries
> `Add16("HL","BC")` → RegA="HL", RegB="BC"; verified `[0x09u]`/`[0x19u]`). `EmitStoreReg16(ctx, "HL")` must take the
> int value off the stack — confirm its contract matches PR-1's `LD HL,(nn)` usage (value-on-stack → pair). The
> `(hl & 0x0FFF) + (rr & 0x0FFF)` half16 and `sum16 > 0xFFFF` carry are computed in unsigned-safe int (both pairs
> are ≤ 0xFFFF, sum ≤ 0x1FFFE — fits int; no overflow). Cross-check the final F against the oracle Op09 (`:3648`).

## Design decisions surfaced for the owner (Coordinator) — confirm before / during implementation

- **DECISION D — shared IL flag-compute helper vs inline per-op (RESOLVED: shared).** The flag word is the
  highest-bug-density code (§2). The generator's own oracle factors it (`EmitZ80FlagWord` for add/sub, a logic path,
  an inc/dec path — `CpuEmitter.cs:2269`). The emit arm mirrors that: ONE `EmitZ80AddSubFlags` (ADD/ADC/SUB/SBC/CP,
  parameterized by subtract/xy-source), ONE `EmitZ80LogicFlags`, ONE `EmitZ80IncDecFlags`. **Rationale:** a flag bug
  is fixed once; the helper is diffed against the generator's factored body; the exhaustive TomHarte sweep proves
  all three helpers at once. Inline-per-op would duplicate the eight-term OR 8× (ADD/ADC/SUB/SBC/AND/OR/XOR/CP) with
  8× the bug surface. **This is the recommended shape; owner can object if a flatter inline arm is preferred for
  IL-debuggability.**
- **DECISION E — split the 16-bit ALU sub-families out of PR-2 (RECOMMENDED).** PR-2 emits **ADD HL,rr** (base-plane
  `Z80Alu`, in the natural flag scope) but DEFERS: (1) **ADC HL,rr / SBC HL,rr** — these are **ED-plane** (`Z80EdOp`,
  `EdAdcSbc16`, KeyShape.PrefixedOpcode, 15 T); admitting them needs a different gate path (the ED prefix, not the
  base plane) and a separate emit branch, and they are a distinct §6 ROI item; and (2) **INC rr / DEC rr** (16-bit
  `Inc16`/`Dec16`) — they touch NO flags and set `Q = 0`, so they belong with the no-flag families (PR-3 or a small
  follow-up), not the flag long pole. **Recommendation: PR-2 = the 8-bit ALU + 8-bit INC/DEC + ADD HL,rr; a tight
  follow-up "PR-2b" adds ED ADC/SBC HL,rr (the ED gate path) + the no-flag Inc16/Dec16.** This keeps PR-2 focused on
  the flag model on ONE gate path (the base plane PR-1 already proved) and isolates the ED-prefix gate work.
  **Owner's call: fold ED ADC/SBC HL,rr into PR-2 (one more gate path), or split to PR-2b (recommended)?**
