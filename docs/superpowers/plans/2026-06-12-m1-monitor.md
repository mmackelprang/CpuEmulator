# M1 Chunk 5: Machine-Language Monitor + Generated Single-Instruction Assembler — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** spec §9 item 5 — the per-CPU machine-language monitor as the automated-acceptance
surface, plus generated artifact ⑤ (spec §5): the **single-instruction assembler**, the
inverse of the disassembler, from the same spec table. User requirement (decision 2026-06-12):
*"Load code, Save memory, Disassemble memory, Modify memory, Assemble single instructions at
an address"* + registers + step/run — enabling extensive automated acceptance tests. Four
fronts: (1) Core surface **`IMonitorSupport`**, generator-implemented per CPU (disassemble /
instruction length / assemble / interrupt-pending), discharging both 3b-ii closeout intake
items; (2) the generated **`TryAssemble`** — mnemonic + canonical operand text → opcode
bytes, the operand's *shape and hex-digit width* selecting the mode; (3) the CPU-agnostic
**`CpuEmulator.Monitor`** project: `MonitorEngine` (programmatic API first) + `MonitorRepl`
(text in/out — tests drive strings today, the §9-item-7 host embeds stdio); (4) the
**roundtrip keystone** — `assemble(disassemble(x)) == x` for all 151 opcodes — plus
monitor-driven UAT sessions. PR #7 of Milestone 1 (branch `feat/m1-monitor`, base `main`,
branched at `2efa7d2`).

**Architecture:** the "one spec → generated artifacts" list grows its fifth live member.
`IMonitorSupport` lives in `CpuEmulator.Core`; the generated CPU class implements it —
`Disassemble`/`InstructionLength`/`TryAssemble` emitted as public statics (today's
`Disassemble` posture) with explicit interface implementations delegating to them, and
`InterruptPending` as a **generated partial property** implemented by the hand-written
partial — the same compiler-enforced seam as `TryServiceInterrupt` (a missing implementation
is a build error naming the member). `MonitorEngine` is CPU-agnostic over
`(ICpuCore, IAddressSpace, IMonitorSupport)`; the 6502 satisfies all three as
`(cpu, space, cpu)`. `MonitorRepl` is a thin line parser over the engine, console-free.
Nothing in the interpreter, spec table, or importer changes; the emitter only *adds* members.

**Tech stack:** unchanged (net10.0, Roslyn 4.12.0, xUnit 2.9.3) + one new project:
`src/CpuEmulator.Monitor` (net10.0, `IsAotCompatible`, Core-only reference). The generated
`InterruptPending` uses C# 13 partial properties — repo `LangVersion=latest`,
`GeneratorTestHost` parses `Latest`.

**Plan series:** 1–3b-ii ✅ (PRs #1–#6) · **monitor: this plan (PR #7)** ·
datasheet-extraction runbook (§9 item 6) · peripherals + host (§9 item 7).

**NOT in scope:**
- **Symbolic labels, expressions, multi-line assembly** — artifact ⑤ is single-instruction by
  design. Recorded as monitor-v2 backlog.
- **Breakpoints / watchpoints** — monitor-v2 backlog; `RunUntil(pc, maxCycles)` is the M1
  acceptance-test substitute (and detects the trap idiom for free).
- **Host stdio wiring** — chunk §9 item 7 embeds `MonitorRepl` over the console; this PR proves
  it over StringReader/StringWriter only.
- **Side-effect-free memory access (peek/poke)** — the monitor reads/writes through
  `IAddressSpace.Read8/Write8`; once MMIO peripherals exist (§9 item 7) a dump over a device
  page would perturb it. Monitor-v2 item to land WITH peripherals; harmless today (RAM only).
- **Illegal/undocumented opcodes** — the generated tables cover the 151 documented rows;
  undefined opcodes disassemble as `"???"` and walk as length 1 (documented below).
- **Interrupt-line REPL commands** — lines are host/peripheral domain; tests drive
  `SetIrqLine` directly on the CPU to assert the interrupt-aware step report.
- **Scheduler-aware run** *(recorded by the Tasks-4–6 review)* — `MonitorEngine.Run`/`RunUntil`
  drive the bare `ICpuCore`, not `Machine.Run`: once §9 item 7 lands scheduled peripherals,
  `g` through the monitor will not tick them. To land WITH the host embedding (engine accepts
  a run delegate, or the host wires the monitor over `Machine`). Harmless today — no
  scheduled peripherals exist.

**Recorded deviations/departures this plan makes deliberately:**
- **`TryAssemble` keeps the brief's address-free signature**, so branch-target resolution
  (`BNE $0202` → relative offset) **cannot** live inside it — the offset depends on the
  assembly address, which the signature does not carry. The generated grammar's Relative form
  is therefore `*+d`/`*-d` (exactly what `Disassemble` emits — required by the roundtrip
  identity anyway); the `$hhhh`-target convenience lives in `MonitorEngine.TryAssembleAt`,
  which knows the address (fixed-point retry per candidate length — Task 5 literal).
- **`IMonitorSupport` carries two members beyond the brief's four:** `ProgramCounterName` and
  `RegisterBits(name)` — a CPU-agnostic engine must read/set the PC and format registers at
  natural width; both are spec-table knowledge the generated half owns. `ICpuCore` stays frozen.
- **`InterruptPending` ripples into every hand-written partial** (3b-ii precedent):
  `ValidSpecSource` + both `ImporterEndToEndTests` embedded partials gain one-line stubs, in
  the SAME commit as the emitter change (missing implementation is a build error in
  compilations that assert zero errors).
- **No new CPUGEN002 reserved local names.** That rule exists because opcode bodies reference
  registers BY NAME (`data = data;` corruption); the new generated members never reference a
  register, so no collision can corrupt emitted code. Reasoned, recorded; `opcode` was already
  reserved.
- **The REPL `a` command requires a `$`-prefixed address** (`a $0200 LDX #$05`): mnemonics
  like `ADC` are valid bare hex — irrecoverably ambiguous. Elsewhere `$` is optional.
- **`g`'s cycle budget is decimal** while addresses/counts/bytes are hex — budgets compare
  against `CycleCount`, which the suite prints in decimal. Stated in the command table.
- **`InterruptPending` gains a contract clause** the brief implies: true *exactly when* the
  next `Step` services an interrupt (the 6502 uses `TryServiceInterrupt`'s own gate; pinned
  by test, Task 1 Step 6).

- **Canonical-text caveat (the honest grain of artifact ⑤):** `Disassemble` writes zero-page
  operands as exactly 2 hex digits and absolute as exactly 4, so the assembler picks the MODE
  FROM TEXT WIDTH: **2 hex = zero-page family, 4 = absolute family, 1/3 digits = error — no
  silent promotion.** The width rule makes `assemble ∘ disassemble` an identity, not a
  heuristic.
- 151 documented opcodes; 13 modes; mode → instruction length (= the importer dataset's
  `bytes` column, derivable from mode alone): Implied/Accumulator → 1; Immediate,
  ZeroPage(X/Y), IndirectX, IndirectY, Relative → 2; Absolute(X/Y), Indirect → 3. **BRK is
  length 1** (mode Implied; dataset `bytes: 1`) — the padding byte is a runtime artifact;
  conventional disassemblers walk BRK as 1 byte.
- UAT countdown program (Task 7): **34 cycles exactly** — LDX 2 + STX abs 4 + 5×DEX 10 +
  4×BNE-taken-same-page 12 + BNE-not-taken 2 + STX abs 4. Asserted verbatim in the session
  output (the monitor surfaces the cycle-exact interpreter).

## Ground truth A — `IMonitorSupport` (full literal; this is the contract)

```csharp
namespace CpuEmulator.Core;

/// <summary>
/// Per-CPU monitor adapter. Implementations are GENERATED from the ISA spec table (the same
/// table that generates the interpreter and disassembler), so the monitor's assembler,
/// disassembler, and length table can never drift from the executing CPU. The generated CPU
/// class implements this interface; a 6502 monitor is built over (cpu, bus, cpu).
/// </summary>
public interface IMonitorSupport
{
    /// <summary>Format one instruction as canonical assembly text (e.g. "LDA #$42",
    /// "BNE *-4"; "???" for undefined opcodes). Extra operand bytes are ignored.</summary>
    string Disassemble(byte opcode, byte operandLo, byte operandHi);

    /// <summary>Total instruction length in bytes (1-3), from the addressing mode.
    /// Undefined opcodes return 1 so a disassembly walk always advances.</summary>
    int InstructionLength(byte opcode);

    /// <summary>Assemble one instruction: mnemonic + canonical operand text → opcode bytes
    /// (the inverse of <see cref="Disassemble"/> — see the grammar table in the plan/docs).
    /// The operand's SHAPE selects the addressing mode; its hex-digit WIDTH selects
    /// zero-page (2 digits) vs absolute (4) — never promoted. A mnemonic+mode pair either
    /// exists in the spec table or assembly fails with a diagnostic in
    /// <paramref name="error"/>. Mnemonics/hex are case-insensitive; whitespace ignored.</summary>
    bool TryAssemble(string mnemonic, string operandText, out byte[] bytes, out string? error);

    /// <summary>True exactly when the next <see cref="ICpuCore.Step"/> will service a
    /// pending interrupt instead of executing the instruction at PC (monitor displays must
    /// say so). The hand-written CPU partial implements this with the same predicate its
    /// interrupt-service hook gates on.</summary>
    bool InterruptPending { get; }

    /// <summary>Name of the ProgramCounter-role register in
    /// <see cref="ICpuCore.RegisterNames"/>.</summary>
    string ProgramCounterName { get; }

    /// <summary>Architectural width in bits of a named register (display formatting).</summary>
    /// <exception cref="System.ArgumentException">The name is not a register.</exception>
    int RegisterBits(string name);
}
```

## Ground truth B — assembler operand grammar (canonical text, after whitespace strip + uppercase)

| Operand form | Mode | Operand bytes | Notes |
|---|---|---|---|
| *(empty)* | Implied, falling back to Accumulator | — | bare `ASL` = `ASL A`; a mnemonic never has both rows |
| `A` | Accumulator | — | as `Disassemble` writes it |
| `#$hh` | Immediate | lo | exactly 2 digits; `#$hhhh` → error (immediates are one byte) |
| `$hh` | ZeroPage | lo | exactly 2 hex digits |
| `$hh,X` | ZeroPageX | lo | |
| `$hh,Y` | ZeroPageY | lo | |
| `$hhhh` | Absolute | lo, hi | exactly 4 hex digits |
| `$hhhh,X` | AbsoluteX | lo, hi | |
| `$hhhh,Y` | AbsoluteY | lo, hi | |
| `($hh,X)` | IndirectX | lo | |
| `($hh),Y` | IndirectY | lo | |
| `($hhhh)` | Indirect | lo, hi | |
| `*+d` / `*-d` | Relative | offset byte | DECIMAL, −128..+127; raw-offset semantics = the disassembler's (relative to the post-operand PC) |
| `$hhhh` *(branch mnemonics)* | Relative, via `MonitorEngine.TryAssembleAt` ONLY | offset byte | engine resolves `target − (address + length)` per candidate length and takes the fixed point; NOT part of generated `TryAssemble` |

**Width rule (no silent promotion):** 1- or 3-digit hex operands are errors naming the rule.
Ambiguities are resolved by the spec table: a mnemonic+mode pair either exists or assembly
fails (`"no LDA + ZeroPageY form in the instruction table"`, `"unknown mnemonic 'XYZ'"`).

## Ground truth C — REPL command table (`MonitorRepl`; one command per line; `?` prints this)

All ADDR/COUNT/LEN/VALUE/byte arguments are **hex**, `$` optional — except `a`'s address
(`$` **required**: mnemonics like `ADC` are valid bare hex) and `g`'s BUDGET (**decimal
cycles**). Errors print one line starting with `? `.

| Syntax | Action |
|---|---|
| `m ADDR [COUNT]` | hex-dump COUNT bytes (default $40) |
| `m ADDR: BB BB ...` | write bytes at ADDR, then echo the dump of what landed |
| `d ADDR [COUNT]` | disassemble COUNT instructions (default 8), walking via InstructionLength |
| `a $ADDR INSTR` | assemble INSTR at $ADDR; echo the encoded line; set the assembly cursor past it |
| `a INSTR` | assemble at the cursor (error if no prior `a $ADDR ...`) |
| `r` | print the registers line |
| `r NAME=VALUE` | set a register, then print the registers line |
| `s [N]` | step N instructions (default 1), printing each step report |
| `g [$ADDR] [until $TARGET] [BUDGET]` | optionally set PC; run until TARGET reached / PC traps (parks) / BUDGET cycles (default 1,000,000) exhausted; print the stop line |
| `l ADDR PATH` | load a raw binary file at ADDR (PATH = rest of line; may contain spaces) |
| `w ADDR LEN PATH` | save LEN bytes from ADDR to a raw binary file |
| `?` | print this command table |
| `q` | quit (EOF also quits); blank lines are ignored |

## Ground truth D — output format contracts (tests assert these verbatim)

- **Registers line:** `A=00 X=05 Y=00 S=FD P=B0 PC=0202 CYC=42` — every `RegisterNames` entry
  in order, hex at `RegisterBits/4` digits, then `CYC=` decimal `CycleCount`.
- **Disassembly line:** `{addr:X4}: {bytes,-8}  {text}` — bytes hex space-separated,
  left-aligned field of 8, two spaces, the disassembly: `0206: D0 FD     BNE *-3`,
  `0202: 8E 00 03  STX $0300`.
- **Hex-dump line:** `{addr:X4}: {hex,-47} |{ascii}|` — 16 bytes/line, `XX` space-separated
  (47 chars full, space-padded partial); ascii `.` outside 0x20–0x7E: `0300: 05 00` … `|..|`.
- **Step report (REPL `s`):** two lines — `{pc:X4}: {disassembly}` then the registers line;
  on interrupt service: `{pc:X4}: (interrupt serviced)`.
- **`g` stop line:** `target $020B reached after 34 cycles` / `trapped at $1234 after N cycles`
  / `budget exhausted at $ABCD after N cycles`.
- **`l`/`w` confirmations:** `loaded $10000 bytes at $0000` / `wrote $0100 bytes from $0200`.
- Addresses print at `(AddressBits+3)/4` hex digits (4 for the 6502); all monitor address
  arithmetic masks with the space's address mask (the bus wraps, monitor arithmetic too).

```csharp
    /// selects zero-page (2 digits) vs absolute (4) — never promoted.</summary>
    public static bool TryAssemble(string mnemonic, string operandText, out byte[] bytes, out string? error)
    {
        bytes = System.Array.Empty<byte>();
        if (!TryParseOperand(operandText, out string mode, out byte lo, out byte hi, out error))
            return false;
        string m = mnemonic.Trim().ToUpperInvariant();
        int opcode = AssembleOpcode(m, mode);
        if (opcode < 0 && mode == "Implied")
            opcode = AssembleOpcode(m, "Accumulator"); // bare 'ASL' means the accumulator form
        if (opcode < 0)
        {
            error = KnownMnemonic(m)
                ? $"no {m} + {mode} form in the instruction table"
                : $"unknown mnemonic '{m}'";
            return false;
        }
        bytes = mode switch
        {
            "Implied" or "Accumulator" => new byte[] { (byte)opcode },
            "Absolute" or "AbsoluteX" or "AbsoluteY" or "Indirect" => new byte[] { (byte)opcode, lo, hi },
            _ => new byte[] { (byte)opcode, lo },
        };
        error = null;
        return true;
    }

    /// <summary>(mnemonic, mode) → opcode, or -1. Generated from the instruction table —
    /// the spec table arbitrates every mnemonic+mode ambiguity.</summary>
    private static int AssembleOpcode(string mnemonic, string mode) => (mnemonic, mode) switch
    {
        ("BRK", "Implied") => 0x00,
        ("ORA", "IndirectX") => 0x01,
        // ... one arm per instruction row, in opcode order ...
        ("INC", "AbsoluteX") => 0xFE,
        _ => -1,
    };

    private static bool KnownMnemonic(string mnemonic) => mnemonic switch
    {
        "ADC" or "AND" or /* ... every distinct mnemonic ... */ or "TYA" => true,
        _ => false,
    };

    /// <summary>Parse canonical operand text into (mode, lo, hi). Whitespace is stripped,
    /// hex is case-insensitive. Exactly 2 hex digits = zero-page family; exactly 4 =
    /// absolute family; 1/3 digits are errors — the disassembler always writes 2 or 4,
    /// which is what makes assemble∘disassemble an identity.</summary>
    private static bool TryParseOperand(string text, out string mode, out byte lo, out byte hi, out string? error)
    {
        mode = "Implied"; lo = 0; hi = 0; error = null;
        string t = text.Replace(" ", string.Empty).Replace("\t", string.Empty).ToUpperInvariant();
        if (t.Length == 0)
            return true; // Implied (TryAssemble falls back to Accumulator)
        if (t == "A")
        {
            mode = "Accumulator";
            return true;
        }
        if (t[0] == '*')
        {
            if (t.Length >= 3 && (t[1] == '+' || t[1] == '-')
                && int.TryParse(t.Substring(1), System.Globalization.NumberStyles.AllowLeadingSign,
                       System.Globalization.CultureInfo.InvariantCulture, out int rel)
                && rel >= -128 && rel <= 127)
            {
                mode = "Relative";
                lo = unchecked((byte)rel);
                return true;
            }
            error = $"malformed relative operand '{text}' (expected *+d or *-d, decimal, -128..+127)";
            return false;
        }
        if (t[0] == '#')
        {
            if (t.Length == 4 && t[1] == '$' && TryHexByte(t.Substring(2), out lo))
            {
                mode = "Immediate";
                return true;
            }
            error = $"malformed immediate operand '{text}' (expected #$hh — immediates are one byte)";
            return false;
        }
        if (t[0] == '(')
        {
            // Three arms, ALL length 7 — "($12,X)", "($12),Y", "($1234)" — disambiguated by
            // suffix, checked in that order (",X)", then "),Y", then bare ')'): IndirectX/
            // IndirectY via TryHexByte(t.Substring(2, 2)), Indirect via
            // TryHexWord(t.Substring(2, 4)). Anything else:
            // error = $"malformed indirect operand '{text}' (expected ($hh,X), ($hh),Y or ($hhhh))".
            // [Each arm has the exact shape of the '#' arm above; the rejection rows pin it.]
            ...
        }
        if (t[0] == '$')
        {
            string digits = t.Substring(1);
            string suffix = string.Empty;
            int comma = digits.IndexOf(',');
            if (comma >= 0)
            {
                suffix = digits.Substring(comma);
                digits = digits.Substring(0, comma);
            }
            if (suffix != string.Empty && suffix != ",X" && suffix != ",Y")
            {
                error = $"malformed index suffix in '{text}' (expected ,X or ,Y)";
                return false;
            }
            if (digits.Length == 2 && TryHexByte(digits, out lo))
            {
                mode = suffix == string.Empty ? "ZeroPage" : suffix == ",X" ? "ZeroPageX" : "ZeroPageY";
                return true;
            }
            if (digits.Length == 4 && TryHexWord(digits, out lo, out hi))
            {
                mode = suffix == string.Empty ? "Absolute" : suffix == ",X" ? "AbsoluteX" : "AbsoluteY";
                return true;
            }
            error = $"'{text}': write exactly 2 hex digits ($hh, zero page) or exactly 4 ($hhhh, absolute) — no promotion";
            return false;
        }
        error = $"unrecognised operand '{text}'";
        return false;
    }

    private static bool TryHexByte(string s, out byte value)
    {
        value = 0;
        return s.Length == 2 && byte.TryParse(s, System.Globalization.NumberStyles.HexNumber,
            System.Globalization.CultureInfo.InvariantCulture, out value);
    }

    private static bool TryHexWord(string s, out byte lo, out byte hi)
    {
        lo = 0; hi = 0;
        if (s.Length != 4 || !ushort.TryParse(s, System.Globalization.NumberStyles.HexNumber,
                System.Globalization.CultureInfo.InvariantCulture, out ushort v))
            return false;
        lo = unchecked((byte)v);
        hi = unchecked((byte)(v >> 8));
        return true;
    }
```

```csharp
    /// IMonitorSupport.InterruptPending is sampled BEFORE stepping: when true, the CPU's
```

```csharp
    /// <summary>Assemble one instruction at an address and write its bytes to memory.
    /// One address-aware convenience over IMonitorSupport.TryAssemble: a '$hhhh' operand
    /// the table rejects (e.g. 'BNE $0205' — branches take relative offsets) is retried
    /// as offset = target - (address + L) per candidate length L; the first L whose
    /// assembled instruction is exactly L bytes is the fixed point. Offsets that wrap
    /// the address space are not resolved (out-of-range error).</summary>
    public bool TryAssembleAt(uint address, string instruction, out byte[] bytes, out string? error)
    {
        address &= _addressMask;
        string text = instruction.Trim();
        int space = text.IndexOf(' ');
        string mnemonic = space < 0 ? text : text.Substring(0, space);
        string operand = space < 0 ? string.Empty : text.Substring(space + 1);

        if (!_support.TryAssemble(mnemonic, operand, out bytes, out error)
            && TryParseAbsoluteTarget(operand, out uint target))
        {
            for (int length = 2; length <= 3; length++)
            {
                int offset = (int)target - (int)((address + (uint)length) & _addressMask);
                if (offset < -128 || offset > 127)
                    continue;
                string relative = "*" + (offset >= 0 ? "+" : string.Empty)
                    + offset.ToString(System.Globalization.CultureInfo.InvariantCulture);
                if (_support.TryAssemble(mnemonic, relative, out byte[] candidate, out _)
                    && candidate.Length == length)
                {
                    bytes = candidate;
                    error = null;
                    break;
                }
            }
        }
        if (error != null)
            return false;
        for (int i = 0; i < bytes.Length; i++)
            _memory.Write8((address + (uint)i) & _addressMask, bytes[i]);
        return true;
    }
```
