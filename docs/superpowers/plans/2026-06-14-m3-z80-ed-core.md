# M3.4c: The Z80 ED Prefix Plane (core, 0x40–0x7F) + the WZ/MEMPTR Completion — TomHarte-Green

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** bring the Z80 **0xED prefix plane core (the 64 opcodes 0x40–0x7F)** from the M3.4a
`// TODO(semantics)` skeleton to a **flag-correct, cycle-correct, port-correct, interrupt-state-correct,
TomHarte-green** interpreter, AND **complete the WZ/MEMPTR model + retire the runner's `checkInternal`
scoping** so the runner checks final Q AND final WZ across the WHOLE Z80 (base + CB + ED). This re-validates
the entire existing Z80 at the tighter bar and is REQUIRED for ZEXALL (M3.5) to ever pass.

**Architecture:** M3.4a/b already shipped the machine the ED plane reuses: the algorithmic per-opcode
semantics generator pattern (`Z80BaseSemantics.cs`/`Z80CbSemantics.cs` — ED adds `Z80EdSemantics.cs`), the
composable Z80 flag-word emitter (`EmitZ80FlagWord`/`EmitZ80Alu8`/`EmitZ80Add16`), the prefix decode walk
(`EmitStructuredDecodeWalk` keys `(0xED << 8) | op`; 0xED is ALREADY in `Decode.Prefixes`), the cross-
instruction Q lifecycle (`Z80WritesFlags` + the Step epilogue `Q = F`/`Q = 0`), the WZ register (ALREADY
declared — `Z80Spec.cs:41`), and the Z80 TomHarte harness (`Z80TomHarteRunner`/`Z80TomHarteCase`, which
ALREADY parses `i`/`r`/`im`/`iff1`/`iff2`/`wz`/`q`/`ports`). M3.4c is **additive and analogous**: a new
`Z80EdSemantics` generator emits the ED-core rows from the octal `y/z/p/q` fields, new ED emit arms reuse the
existing flag/16-bit helpers, the importer routes `Prefix == "0xED"` rows through `Z80EdSemantics`, and the
runner's Q/WZ check goes **universal** (every Z80 op now models its WZ writes + Q, so `checkInternal` is
retired). Every 6502 artifact stays byte-identical.

**Tech Stack:** C# (.NET 10), a Roslyn incremental source generator (`CpuEmulator.Generators`), a console
spec importer (`CpuEmulator.SpecImporter`) that regenerates `Z80Spec.cs` from `z80-opcodes.json` +
`z80-semantics.json`, and xUnit + the SingleStepTests/z80 vectors (TomHarte).

## Scope

This PR ships **TWO coherent pieces** (recon confirmed they belong together — see the scope note at the end):

**Piece A — Complete the WZ/MEMPTR model + retire `checkInternal`.** M3.4b scoped the runner's final-Q/WZ
checks to the CB surface because base-plane ops genuinely WRITE WZ (e.g. `cd.json` CALL nn: init.wz !=
final.wz) and shared 6502-class base ops (LD r,r' = `Register` class) don't maintain Q. Now: model WZ
writes for EVERY base+CB op that sets it, extend the Q-write to the shared 6502-shaped classes too, and
retire `checkInternal` so the runner checks final Q AND final WZ across the WHOLE Z80. **Done FIRST** so the
ED ops inherit a working WZ discipline + the tight gate.

**Piece B — The ED-core opcodes 0x40–0x7F (64 of them).** IN r,(C)/OUT (C),r (+ undoc IN (C)/OUT (C),0);
16-bit ADC/SBC HL,rp; LD (nn),rp / LD rp,(nn); NEG (+ undoc duplicates); RETN/RETI (IFF1←IFF2); IM 0/1/2;
LD I,A / R,A / A,I / A,R; RRD/RLD; the undoc ED NOPs (0x77/0x7F).

**IN scope (the ED-core comes alive end-to-end):**

1. **The 64 ED-core opcodes 0x40–0x7F.** Octal `01 yyy zzz`: x=1 always; `y=(op>>3)&7`; `z=op&7`;
   `p=y>>1`; `q=y&1`. `r[y]` = B C D E H L (—) A ; `rp[p]` = BC DE HL SP.
   - **z=0 — IN r[y],(C):** read port (BC) → r[y] (y=6 → IN (C), discard value, set flags only). Flags
     S/Z/P from the input byte, H=0, N=0, C preserved; X/Y from the byte. **WZ = BC+1.** 12 T.
   - **z=1 — OUT (C),r[y]:** write r[y] → port (BC) (y=6 → OUT (C),0). No flags. **WZ = BC+1.** 12 T.
   - **z=2 — q=0 SBC HL,rp[p]; q=1 ADC HL,rp[p]:** 16-bit. S/Z from result; H from bit 11; P/V overflow;
     N=1(SBC)/0(ADC); C from bit 16; X/Y from result high byte. **WZ = HL+1 (pre-op).** 15 T.
   - **z=3 — q=0 LD (nn),rp[p]; q=1 LD rp[p],(nn):** 16-bit store/load. **WZ = nn+1.** 20 T.
   - **z=4 — NEG** (0x44 canonical; 0x4C/54/5C/64/6C/74/7C undoc dups, identical): A = 0 − A. 8 T.
     (NEG does NOT write WZ.)
   - **z=5 — RETN/RETI:** 0x4D = RETI; 0x45/55/5D/65/6D/75/7D = RETN. Pop PC; **IFF1 = IFF2**;
     **WZ = popped PC.** 14 T.
   - **z=6 — IM:** set interrupt mode from y (table baked in Group B). No flags. 8 T.
   - **z=7 — misc:** 0x47 LD I,A; 0x4F LD R,A (no flags); 0x57 LD A,I; 0x5F LD A,R (S/Z from value, H=0,
     N=0, **P/V = IFF2**, X/Y from value, C preserved); 0x67 RRD; 0x6F RLD (nibble rotate between A low and
     (HL); S/Z/P from A, H=0, N=0, C preserved, **WZ = HL+1**); 0x77/0x7F NOP (undoc, no effect).
2. **WZ/MEMPTR completion** — model the base-plane + CB + ED WZ writes; retire `checkInternal`.
3. **The Q lifecycle extended to the shared 6502-shaped classes** — base-plane `LD r,r'` etc. now set Q=0.
4. **An `Im` field** on the Z80 CPU (the interrupt mode 0/1/2), set/checked by the runner.
5. **The TomHarte ED gate** — a `CoveredEdPlaneOpcodes` theory loading `ed {op:x2}.json`, plus the
   universal Q/WZ regression over base + CB.

**OUT of scope (each is a later PR — do NOT reach for it):**

- **The 16 ED block ops (0xA0–0xBB):** LDI/LDD/LDIR/LDDR, CPI/CPD/CPIR/CPDR, INI/IND/INIR/INDR,
  OUTI/OUTD/OTIR/OTDR = the NEXT PR.
- **The DD/FD/DDCB/FDCB planes** (IX/IY `(IX+d)`, the two-deep compound-prefix decoder) = after.
- **The Z80 through the JIT (M3.5)** — the ED rows emit as JIT fallbacks (the descriptor table must be
  well-formed) but the JIT never emits IL for them; the Z80 runs interpreter-only.
- **Actual interrupt SERVICING** — the CPU responding to an IRQ/NMI in a given IM mode is NOT single-step-
  vector-testable and is M3.5 / a dedicated interrupt UAT. This PR implements IM-mode SETTING and IFF1/IFF2
  STATE manipulation (RETN/RETI/LD A,I/R read/restore IFF2), **not** servicing. `TryServiceInterrupt`
  stays `=> false`.

> **The honest one-liner for M3.4c's close-state:** the Z80 base plane, CB plane, AND the 64 ED-core
> opcodes run and are TomHarte-green (per-instruction registers incl. F's X/Y, I/R, IM, IFF1/IFF2, WZ, Q,
> memory, ports, AND per-T-state bus trace); the WZ/MEMPTR model is complete and the runner checks final Q
> AND WZ across the WHOLE Z80 (the `checkInternal` scoping is retired). The 16 ED block ops + DD/FD/DDCB/
> FDCB remain `// TODO` skeleton; interrupt servicing + the JIT are unimplemented for the Z80. "TomHarte-
> green" is asserted over the 64 ED-core opcodes (64,000 cases) + the re-validated base (252k) + CB (256k),
> enumerated honestly in the closeout.

### RECON FINDINGS that contradict / refine the prose (the code/vectors WIN — flagged)

> These were discovered during the write-time recon by reading the dataset + sampling the vectors. The
> implementer MUST re-confirm each at Task 0 and treat the vector as ground truth.

- **F1 — The dataset is MISSING 22 of the 64 ED-core rows.** `z80-opcodes.json` has only **42** ED-core
  rows (0x40–0x7F); it has **58** ED rows total (42 core + 16 block). The 22 missing core opcodes are the
  undocumented duplicates + the y=6 I/O forms + the two ED NOPs:
  - **NEG dups (z=4):** 0x4C, 0x54, 0x5C, 0x64, 0x6C, 0x74, 0x7C (7)
  - **RETN dups (z=5):** 0x55, 0x5D, 0x65, 0x6D, 0x75, 0x7D (6)
  - **IM dups (z=6):** 0x4E (IM 0/1), 0x66 (IM 0), 0x6E (IM 0/1), 0x76 (IM 1), 0x7E (IM 2) (5)
  - **y=6 I/O:** 0x70 (IN (C) — read+discard, set flags), 0x71 (OUT (C),0) (2)
  - **ED NOP undoc (z=7,y=6/7):** 0x77, 0x7F (2)

  All 64 `ed 40.json`…`ed 7f.json` vector files EXIST. **Group B Task (dataset) must ADD these 22 rows**
  (the SLL-gap lesson from M3.4b — check the dataset's ED-core row count vs 64 and add the missing).
- **F2 — No new AddrMode is needed.** Unlike the CB plane (which added `Bit`), the ED-core ops all use
  modes ALREADY in `SupportedModes` + the disassembler: `Implied` (NEG/RETN/RETI/IM/LD I,A.../NOP),
  `Register` (IN/OUT/ADC/SBC — the operand register/pair is opcode-encoded), `ExtendedAddress`
  (LD (nn),rp), `RegisterIndirect` (RRD/RLD). The dataset already labels them so (CONFIRMED: 0x40 IN
  Register, 0x42 SBC Register, 0x43 LD ExtendedAddress, 0x44 NEG Implied, 0x67 RRD RegisterIndirect). **The
  22 new rows must use the matching existing modes** (IN/OUT → Register; IM/NEG/RETN/RETI/NOP → Implied).
- **F3 — `NEG` currently maps to `[]` in `z80-semantics.json`** (the per-mnemonic map), which is why
  ED:0x44 emitted empty ops. Once `Prefix == "0xED"` routes through `Z80EdSemantics`, the per-mnemonic map
  is BYPASSED for ED rows — `Z80EdSemantics.OpsFor(0x44)` returns the real NEG op. (Leave the `NEG → []`
  map entry; it is dead for ED rows now but removing it is out of scope and would churn the diff.)
- **F4 — The runner does NOT set/check `Im`.** `RunCase` sets PC/SP/A/F/.../I/R/WZ/Iff1/Iff2/Q but never
  `cpu.SetRegister("Im", …)` (there is no `Im` register) nor checks final `Im`. The IM ops change `im`, so
  Group B must add an `Im` field + the runner must set it from `s.Im` and check `f.Im`.
- **F5 — Iff1/Iff2 are ALREADY checked unconditionally** (`Z80TomHarteRunner.cs:74-75`), so the base/CB
  sweeps already enforce IFF1/IFF2. RETN/RETI's `IFF1 = IFF2` and LD A,I/R's IFF2-read are therefore gated
  the moment those ops emit. (CONFIRMED `ed 45` RETN: init iff1=1,iff2=0 → final iff1=0,iff2=0; `ed 4d`
  RETI: init iff1=0,iff2=1 → final iff1=1,iff2=1 — BOTH do IFF1←IFF2.)
- **F6 — WZ rules CONFIRMED against the vectors** (the oracle; re-derive each, do NOT trust the prose):
  `ed 40` IN B,(C): final.wz = BC+1 (BC=0x4381 → wz=0x4382). `ed 41` OUT (C),B: wz = BC+1 (BC=0x981C →
  wz=0x981D). `ed 42` SBC HL,BC: wz = HL+1 (pre-op). `ed 43` LD (nn),BC: wz = nn+1. `ed 67` RRD: wz = HL+1
  (HL=0x098F → wz=0x0990). `ed 47` LD I,A / `ed 57` LD A,I / `ed 46` IM 0: **wz UNCHANGED** (NEG also
  leaves wz unchanged — `ed 44` init.wz==final.wz). Port transactions land in the `ports` array (load-
  bearing here, unlike CB).
- **F7 — IM-mode table CONFIRMED** against the vectors' final `im`: 0x46→0, 0x4E→0, 0x56→1, 0x5E→2,
  0x66→0, 0x6E→0, 0x76→1, 0x7E→2. I.e. `im = {0,0,1,2,0,0,1,2}[y]` (y=0/4→IM0, y=1/5→IM0 (undoc 0/1 treated
  as 0), y=2/6→IM1, y=3/7→IM2). Re-derive from the vectors at Task 0.
- **F8 — Q lifecycle CONFIRMED:** IN r,(C) (writes flags) → final.q = final.f; OUT/LD I,A/RETN/RETI/IM/NOP
  (no flags) → final.q = 0; ADC/SBC HL/NEG/LD A,I/RRD/RLD → final.q = final.f. `Z80WritesFlags` must
  classify the new ED op kinds accordingly.

## Group A — The WZ/MEMPTR completion + retire `checkInternal`

> Model WZ writes for EVERY base+CB op that sets it, extend the Q-write to the shared 6502-shaped classes,
> and make the runner check final Q AND WZ universally. Done FIRST so the ED ops (Group B) inherit a working
> WZ discipline + the tight gate. The work is gated by the base+CB TomHarte sweeps re-running at the tighter
> bar — any mismodeled WZ FAILS there, so Piece A is exhaustively self-checking.

**Design decision (recorded):** WZ writes are emitted INSIDE each existing Z80 emit arm (Flow/Ld/Alu16/
Exchange/Port/Misc), keyed by the op kind — NOT a separate pass. Each arm already knows the op's operands;
it appends a `WZ = …;` assignment per the MEMPTR rule. A small `EmitWz(sb, expr)` helper centralises the
`WZ = unchecked((ushort)(…));` boilerplate. The Q-write epilogue already fires for `isZ80` classes; Group A
A-Task 2 extends the Q-write (NOT the cycle path) to the shared 6502-shaped classes the base plane reuses
(`Register`/`Load`/`Store`/`Jump`/`Alu`/`Rmw`/`Stack`/`Flow`/`Port`) so `LD r,r'` etc. set Q=0. **CRITICAL:**
that Q-extension must NOT change the 6502 (which shares those classes). The guard is the per-CPU
`structured` flag (`model.Decode is not null` — `CpuEmitter.cs:260`), true only for a structured CPU (the
Z80; the 6502 has no `Decode`). It is ALREADY in scope at the epilogue (the same flag `EmitLoadBody`
consumes). So the epilogue changes from `if (isZ80)` to `if (structured)`, writing `Q = F`/`Q = 0` for
every class on a structured CPU. **WATCH-POINT (Q1):** a synthetic structured test spec MUST then declare a
`Q` field (the CB synthetic specs already add `public byte Q;` once a Z80 op writes Q; any Group-A/B
synthetic spec that exercises a shared-class row needs the same). Confirm the existing structured synthetic
fixtures still compile after the `if (structured)` flip (the `Z80*Tests` partials all carry `Q` post-CB);
if a fixture lacks `Q`, add it. The `Z80WritesFlags` predicate already returns `false` for shared classes
(its `_ => false` arm), so they get `Q = 0` — correct (LD r,r' writes no flags).

**Design decision (recorded — the class/op shape):** the ED-core families map to these op records, grouped
into **two** new instruction classes to keep the dispatch small (mirroring how `Z80Rot`/`Z80Bit` split the
CB plane):

- **`Z80EdIo`** (mode `Register`): `EdIn(string Target)` (IN r,(C); Target ∈ "B".."A" or "(none)" for
  IN (C)), `EdOut(string Source)` (OUT (C),r; Source ∈ "B".."A" or "(zero)" for OUT (C),0).
- **`Z80EdOp`** (modes `Register`/`ExtendedAddress`/`RegisterIndirect`/`Implied`) — the catch-all for the
  rest, discriminated by the op record:
  - `EdAdcSbc16(string Op, string Pair)` — Op ∈ "ADC"/"SBC", Pair ∈ "BC"/"DE"/"HL"/"SP" (mode `Register`).
  - `EdLdNnRp(string Op, string Pair)` — Op ∈ "STORE"/"LOAD", Pair ∈ "BC"/"DE"/"HL"/"SP" (mode
    `ExtendedAddress`).
  - `EdNeg()` — NEG (mode `Implied`).
  - `EdRetn(bool IsReti)` — RETN/RETI (mode `Implied`).
  - `EdIm(int Mode)` — IM, Mode ∈ 0/1/2 (mode `Implied`).
  - `EdLdIaRa(string Op)` — Op ∈ "I_A"/"R_A"/"A_I"/"A_R" (LD I,A / R,A / A,I / A,R; mode `Implied`).
  - `EdRrdRld(bool IsRld)` — RRD/RLD (mode `RegisterIndirect`).
  - `EdNop()` — the undoc ED NOP (mode `Implied`).

  > **Why two classes, not one or eight:** `Z80EdIo` is split out because IN/OUT touch the I/O bus + the
  > ports array (a distinct concern), and its mode is always `Register`. Everything else is `Z80EdOp` with
  > a per-op-record switch in the emitter — the same shape as `EmitZ80MiscBody`'s `switch (kind)`. This
  > keeps `ClassifyOps`/`ValidateModeForClass` to two new arms. (Alternative considered: reuse `Z80Alu`
  > for ADC/SBC HL,rp and `Z80Ld` for LD (nn),rp — REJECTED because their cycle counts + WZ rules + the
  > 16-bit ADC/SBC flag model differ from the base forms, and overloading the existing classes' mode-
  > legality would entangle the base plane. A clean new class is DRYer at the gate.)

```csharp
namespace CpuEmulator.SpecImporter;

/// <summary>
/// Computes the micro-op text for a Z80 ED-PLANE CORE opcode (0x40–0x7F) ALGORITHMICALLY from the
/// second byte (M3.4c), the ED analogue of <see cref="Z80CbSemantics"/>. The ED core is the octal
/// encoding x=1 (y = bits 5-3, z = bits 2-0, p = y&gt;&gt;1, q = y&amp;1): z selects the family
/// (0 IN r,(C); 1 OUT (C),r; 2 ADC/SBC HL,rp; 3 LD (nn),rp/rp,(nn); 4 NEG; 5 RETN/RETI; 6 IM;
/// 7 misc LD I/R/A + RRD/RLD + NOP). Returns the ops-text for an ED-core opcode, or null for an ED
/// opcode OUTSIDE the 0x40–0x7F core (the block ops 0xA0–0xBB are a later PR; the caller defers them).
/// </summary>
public static class Z80EdSemantics
{
    private static readonly string[] Reg8 = ["B", "C", "D", "E", "H", "L", "(HL)", "A"];
    private static readonly string[] RpSp = ["BC", "DE", "HL", "SP"];
    // im[y] — the interrupt mode each IM opcode sets (the undoc 0/1 forms map to 0). Confirmed against
    // the vectors (RECON FINDING F7): 0x46->0 0x4E->0 0x56->1 0x5E->2 0x66->0 0x6E->0 0x76->1 0x7E->2.
    private static readonly int[] ImMode = [0, 0, 1, 2, 0, 0, 1, 2];

    /// <summary>Ops-text for an ED-core opcode (0x40–0x7F), or null if outside the core.</summary>
    public static string? OpsFor(int opcode)
    {
        if (opcode is < 0x40 or > 0x7F) return null;   // block ops + low ED are out of scope here
        int y = (opcode >> 3) & 0x07;
        int z = opcode & 0x07;
        int p = y >> 1;
        bool q = (y & 1) != 0;
        return z switch
        {
            0 => $"[EdIn(\"{(y == 6 ? "none" : Reg8[y])}\")]",     // IN r,(C) ; y=6 IN (C) (discard)
            1 => $"[EdOut(\"{(y == 6 ? "zero" : Reg8[y])}\")]",    // OUT (C),r ; y=6 OUT (C),0
            2 => $"[EdAdcSbc16(\"{(q ? "ADC" : "SBC")}\",\"{RpSp[p]}\")]",
            3 => $"[EdLdNnRp(\"{(q ? "LOAD" : "STORE")}\",\"{RpSp[p]}\")]",
            4 => "[EdNeg()]",                                       // NEG (canonical + undoc dups)
            5 => opcode == 0x4D ? "[EdRetn(true)]" : "[EdRetn(false)]",  // 0x4D RETI ; else RETN
            6 => $"[EdIm({ImMode[y]})]",
            _ => MiscZ7(y),                                         // z=7
        };
    }

    private static string MiscZ7(int y) => y switch
    {
        0 => "[EdLdIaRa(\"I_A\")]",   // 0x47 LD I,A
        1 => "[EdLdIaRa(\"R_A\")]",   // 0x4F LD R,A
        2 => "[EdLdIaRa(\"A_I\")]",   // 0x57 LD A,I
        3 => "[EdLdIaRa(\"A_R\")]",   // 0x5F LD A,R
        4 => "[EdRrdRld(false)]",     // 0x67 RRD
        5 => "[EdRrdRld(true)]",      // 0x6F RLD
        _ => "[EdNop()]",             // 0x77 / 0x7F undoc NOP
    };
}
```

    private static void EmitZ80EdIoBody(
        StringBuilder sb, InstructionModel insn, string pc, string? statusReg, FlagBitMap flags)
    {
        string f = statusReg ?? "F";
        string kind = insn.Ops[0].Kind;
        string operand = Unquote(insn.Ops[0].Args[0]);   // "B".."A" / "none" / "zero"
        sb.AppendLine("        WZ = unchecked((ushort)(BC + 1));");   // both IN and OUT: WZ = BC+1

        if (kind == "EdIn")
        {
            string sMask = $"0x{(byte)(1 << flags.BitOf("S")):X2}";
            string zMask = $"0x{(byte)(1 << flags.BitOf("Z")):X2}";
            string yMask = $"0x{(byte)(1 << flags.BitOf("Y")):X2}";
            string xMask = $"0x{(byte)(1 << flags.BitOf("X")):X2}";
            string pMask = $"0x{(byte)(1 << flags.BitOf("P")):X2}";
            string cMask = $"0x{(byte)(1 << flags.BitOf("C")):X2}";
            sb.AppendLine("        byte inp = ReadIo(BC);");
            if (operand != "none")
                sb.AppendLine($"        {operand} = inp;");          // y!=6: store into r[y]
            // Flags: S/Z/P from inp, H=0, N=0, C preserved, X/Y from inp.

            sb.AppendLine($"            | ((inp & 0x80) != 0 ? {sMask} : 0x00)");
            sb.AppendLine($"            | (inp == 0 ? {zMask} : 0x00)");
            sb.AppendLine($"            | ((inp & 0x20) != 0 ? {yMask} : 0x00)");
            sb.AppendLine($"            | ((inp & 0x08) != 0 ? {xMask} : 0x00)");
            sb.AppendLine($"            | ((System.Numerics.BitOperations.PopCount((uint)inp) & 1) == 0 ? {pMask} : 0x00)));");
        }
        else // EdOut

            string value = operand == "zero" ? "(byte)0" : operand;  // y=6: OUT (C),0
            sb.AppendLine($"        WriteIo(BC, unchecked((byte)({value})));");
        }
        // Cycles: 12 T. Step charged 2 (key bytes); the ReadIo/WriteIo charges 1. +9 internal.
        sb.AppendLine($"        _cycles += {12 - 2 - 1};   // IN/OUT (C) = 12 T-states");

    /// from value, H=0, N=0, P/V = IFF2, X/Y from value, C preserved. Cycles 9. No WZ write.</summary>
    private static void EmitZ80EdLdIaRa(StringBuilder sb, InstructionModel insn, string f, FlagBitMap flags)
    {
        string op = Unquote(insn.Ops[0].Args[0]);   // "I_A"/"R_A"/"A_I"/"A_R"
        switch (op)
        {
            case "I_A": sb.AppendLine("        I = A;"); break;
            case "R_A": sb.AppendLine("        R = A;"); break;
            case "A_I":
            case "A_R":
            {
                string src = op == "A_I" ? "I" : "R";
                string sMask = $"0x{(byte)(1 << flags.BitOf("S")):X2}";
                string zMask = $"0x{(byte)(1 << flags.BitOf("Z")):X2}";
                string yMask = $"0x{(byte)(1 << flags.BitOf("Y")):X2}";
                string xMask = $"0x{(byte)(1 << flags.BitOf("X")):X2}";
                string pMask = $"0x{(byte)(1 << flags.BitOf("P")):X2}";
                string cMask = $"0x{(byte)(1 << flags.BitOf("C")):X2}";
                sb.AppendLine($"        byte v = {src};");
                sb.AppendLine("        A = v;");
                sb.AppendLine($"        {f} = unchecked((byte)(({f} & {cMask})");   // C preserved
                sb.AppendLine($"            | ((v & 0x80) != 0 ? {sMask} : 0x00)");
                sb.AppendLine($"            | (v == 0 ? {zMask} : 0x00)");
                sb.AppendLine($"            | ((v & 0x20) != 0 ? {yMask} : 0x00)");
                sb.AppendLine($"            | ((v & 0x08) != 0 ? {xMask} : 0x00)");
                sb.AppendLine($"            | (_iff2 ? {pMask} : 0x00)));");          // P/V = IFF2
                break;
            }
            default:
                throw new System.InvalidOperationException($"EdLdIaRa: unknown op '{op}'");
        }
        sb.AppendLine($"        _cycles += {9 - 2};   // LD I,A/R,A/A,I/A,R = 9 T-states");

    /// C preserved, X/Y from A. WZ = HL+1. Cycles 18.</summary>
    private static void EmitZ80EdRrdRld(StringBuilder sb, InstructionModel insn, string f, FlagBitMap flags)
    {
        bool rld = ((insn.Ops[0]) is { } o) && Unquote(o.Args[0]) == "true";   // EdRrdRld(IsRld)
        string sMask = $"0x{(byte)(1 << flags.BitOf("S")):X2}";
        string zMask = $"0x{(byte)(1 << flags.BitOf("Z")):X2}";
        string yMask = $"0x{(byte)(1 << flags.BitOf("Y")):X2}";
        string xMask = $"0x{(byte)(1 << flags.BitOf("X")):X2}";
        string pMask = $"0x{(byte)(1 << flags.BitOf("P")):X2}";
        string cMask = $"0x{(byte)(1 << flags.BitOf("C")):X2}";
        sb.AppendLine("        byte m = ReadBus(HL);");
        sb.AppendLine("        int alo = A & 0x0F;");
        if (rld)
        {
            // RLD: (HL) = ((m << 4) | alo) & 0xFF ; A = (A & 0xF0) | (m >> 4)
            sb.AppendLine("        byte newM = unchecked((byte)((m << 4) | alo));");
            sb.AppendLine("        A = unchecked((byte)((A & 0xF0) | (m >> 4)));");
        }
        else
        {
            // RRD: (HL) = ((alo << 4) | (m >> 4)) ; A = (A & 0xF0) | (m & 0x0F)
            sb.AppendLine("        byte newM = unchecked((byte)((alo << 4) | (m >> 4)));");
            sb.AppendLine("        A = unchecked((byte)((A & 0xF0) | (m & 0x0F)));");
        }
        sb.AppendLine("        WriteBus(HL, newM);");
        sb.AppendLine("        WZ = unchecked((ushort)(HL + 1));");
        // Flags from the NEW A: S/Z/P, H=0, N=0, C preserved, X/Y from A.
        sb.AppendLine($"        {f} = unchecked((byte)(({f} & {cMask})");
        sb.AppendLine($"            | ((A & 0x80) != 0 ? {sMask} : 0x00)");
        sb.AppendLine($"            | (A == 0 ? {zMask} : 0x00)");
        sb.AppendLine($"            | ((A & 0x20) != 0 ? {yMask} : 0x00)");

        sb.AppendLine($"            | ((System.Numerics.BitOperations.PopCount((uint)A) & 1) == 0 ? {pMask} : 0x00)));");
        sb.AppendLine($"        _cycles += {18 - 2 - 1 - 1};   // RRD/RLD = 18 T (2 key + 1 read + 1 write)");
