## Ground-truth additions (bus patterns and flag rules)

Cycle 1 is always the opcode fetch in `Step` (for hardware interrupts there is no fetch — the service sequence replaces it). Sources: 64doc interrupt/BRK cycle tables; TomHarte `00.json`/`40.json` are the per-cycle oracle for BRK/RTI (10,000 cases each). The IRQ/NMI service sequence has **no TomHarte vectors** (SingleStepTests covers instructions only) — the hand-written trace tests in Task 5 pin it from 64doc, stated here as the contract:

| Sequence | Cycles | Bus pattern (after any opcode fetch) |
|---|---|---|
| **BRK** (0x00) | 7 | fetch 0x00 (PC++); **read padding byte at PC (PC++ — BRK is 2 bytes)**; W `$0100+S`=PCH, S−−; W =PCL, S−−; W =**P\|0x30** (stacked B=1 marks BRK/PHP), S−−; R `$FFFE`→PCL; R `$FFFF`→PCH; **I:=1** (D untouched — NMOS) |
| **RTI** (0x40) | 6 | fetch 0x40 (PC++); **dummy read at PC (no increment)**; **dummy read at `$0100+S` (old S)**; S++, R → **P via `(pulled \| 0x20) & 0xEF`** (bit5 forced 1, bit4 forced 0 — same rule PLP trued in 3b-i); S++, R →PCL; S++, R →PCH. **No PC increment, no dummy read at the new PC** (the RTS-only cycles) |
| **IRQ service** | 7 | **two dummy reads at PC (no increment — the discarded opcode fetch and its successor, per 64doc)**; W PCH, S−−; W PCL, S−−; W **`(P \| 0x20) & 0xEF`** (stacked **B=0** distinguishes hardware interrupts from BRK), S−−; R `$FFFE`; R `$FFFF`; I:=1 |
| **NMI service** | 7 | identical shape; vectors **`$FFFA`/`$FFFB`** |

Interrupt policy (hand-written, Task 5): NMI is **edge-triggered** — a rising edge of `SetNmiLine` sets an internal pending latch; the latch clears when serviced and on `Reset`; a held-high line never re-fires until released and re-asserted. IRQ is **level-sensitive** — serviced at a boundary whenever the line is high AND the I flag is clear. **NMI beats IRQ** when both are pending. Servicing pushes the PC of the *next unexecuted instruction* (no decrement — unlike BRK there is no padding byte). The service sets I, so a still-held IRQ line is masked until software clears I (or RTI restores a P with I clear).

Decimal-mode flag rules (NMOS, 64doc algorithm; TomHarte D-set vectors are the final arbiter — on any disagreement fix the implementation/test row from the vector diff, never the differ). Cycle counts are **unchanged** — decimal mode alters datapath results only:

| Op (D=1) | Result byte | C | V | N | Z |
|---|---|---|---|---|---|
| `Adc()` | BCD-corrected sum (lo-nibble adjust +6, hi adjust +0x60) | corrected sum ≥ 0x100 | overflow formula over the **intermediate** sum (pre-+0x60) | bit 7 of the **intermediate** sum | **from the BINARY sum** (the headline NMOS quirk: `$50+$50` gives A=`$00` with **Z=0**) |
| `Sbc()` | BCD-corrected difference (lo adjust −6, hi adjust −0x60) | binary | binary | binary | binary — **all four flags are the binary-mode flags; only A differs** |

64doc reference algorithm (the emitted code is a direct transcription):

```
ADC: lo = (A & $0F) + (d & $0F) + C;  if lo >= $0A: lo = ((lo + $06) & $0F) + $10
     sum = (A & $F0) + (d & $F0) + lo            [N, V taken HERE; Z from binary A+d+C]
     if sum >= $A0: sum += $60                   [C := sum >= $100];  A = sum & $FF
SBC: lo = (A & $0F) - (d & $0F) + C - 1;  if lo < 0: lo = ((lo - $06) & $0F) - $10
     sum = (A & $F0) - (d & $F0) + lo;  if sum < 0: sum -= $60;  A = sum & $FF
     [ALL flags from the binary A + (d^$FF) + C]
```

```csharp
    {
        byte data = ReadBus(PC);

        int temp = A + data + (P & 0x01);
        if ((P & 0x08) != 0)
        {

            // intermediate BCD sum (before the +0x60 correction); C from the corrected sum.

            if (lo >= 0x0A)

                | ((temp & 0xFF) == 0 ? 0x02 : 0x00)));
            if (sum >= 0xA0)
                sum += 0x60;
            P = unchecked((byte)((P & 0xFE) | (sum >= 0x100 ? 0x01 : 0x00)));
            A = unchecked((byte)sum);
        }
        else
        {
            P = unchecked((byte)((P & 0xBE)
                | (temp > 0xFF ? 0x01 : 0x00)
                | ((~(A ^ data) & (A ^ temp) & 0x80) != 0 ? 0x40 : 0x00)));
            A = unchecked((byte)temp);
            P = unchecked((byte)((P & 0x7D) | (A == 0 ? 0x02 : 0x00) | (A & 0x80)));
        }
    }
```

```csharp
        uint hi = ReadBus(0xFFFF);
        P = unchecked((byte)(P | 0x04)); // I set; D untouched (NMOS — CLD-on-BRK is 65C02)
        PC = unchecked((ushort)(lo | (hi << 8)));
    }

    /// <summary>0x40 RTI Implied — 6 cycles.</summary>
    private void Op40()
    {
        _ = ReadBus(PC); // dummy read at PC (no increment)
        _ = ReadBus(0x100u + S); // dummy read at old S (increment cycle)
        S = unchecked((byte)(S + 1));
        P = unchecked((byte)((ReadBus(0x100u + S) | 0x20) & 0xEF)); // phantom bits: 5=1, 4=0
        S = unchecked((byte)(S + 1));
        uint lo = ReadBus(0x100u + S);
        S = unchecked((byte)(S + 1));
        uint hi = ReadBus(0x100u + S);
        PC = unchecked((ushort)(lo | (hi << 8))); // no increment, no dummy at new PC (≠ RTS)
    }
```

```csharp
    private bool _irqLine;
    private bool _nmiLine;
    private bool _nmiPending;

    /// <summary>IRQ is level-sensitive: the line is sampled at every instruction boundary
    /// and serviced when high and the I flag is clear.</summary>
    public void SetIrqLine(bool asserted) => _irqLine = asserted;

    /// <summary>NMI is edge-triggered: a rising edge sets the pending latch; the latch
    /// clears when serviced and on Reset. A held-high line never re-fires until released
    /// and re-asserted.</summary>
    public void SetNmiLine(bool asserted)
    {
        if (asserted && !_nmiLine)
            _nmiPending = true;
        _nmiLine = asserted;
    }

    /// <summary>Instruction-boundary interrupt service (generated Step calls this before
    /// the opcode fetch). NMI beats IRQ. The 7-cycle sequence mirrors 64doc: two dummy
    /// reads at PC (the discarded fetch), push PCH/PCL, push P with B clear
    /// ((P | 0x20) &amp; 0xEF — bit 4 clear distinguishes hardware interrupts from BRK),
    /// vector fetch ($FFFA/$FFFB for NMI, $FFFE/$FFFF for IRQ), I set.
    /// Mid-instruction sampling quirks (CLI/SEI/PLP delay, branch polling, BRK hijacking)
    /// are a recorded M1 deviation — see spec §6.</summary>
    private partial bool TryServiceInterrupt()
    {
        bool nmi = _nmiPending;
        if (!nmi && (!_irqLine || (P & 0x04) != 0))
            return false;
        if (nmi)
            _nmiPending = false;

        _ = ReadBus(PC); // dummy opcode fetch (discarded, PC not incremented)
        _ = ReadBus(PC); // second dummy read at PC
        WriteBus(0x100u + S, unchecked((byte)(PC >> 8)));
        S = unchecked((byte)(S - 1));
        WriteBus(0x100u + S, unchecked((byte)PC));
        S = unchecked((byte)(S - 1));
        WriteBus(0x100u + S, unchecked((byte)((P | 0x20) & 0xEF))); // stacked B=0
        S = unchecked((byte)(S - 1));
        uint vector = nmi ? 0xFFFAu : 0xFFFEu;
        uint lo = ReadBus(vector);
        uint hi = ReadBus(vector + 1);
        P = unchecked((byte)(P | 0x04));
        PC = unchecked((ushort)(lo | (hi << 8)));
        return true;
    }
```
