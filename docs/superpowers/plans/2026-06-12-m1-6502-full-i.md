# M1 Chunk 3b-i: Full 6502 Vocabulary + TomHarte Harness — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Grow the 6502 from the 11-opcode proving subset to **149 of 151 documented opcodes** (everything except BRK and RTI), cycle-exact: all 13 addressing modes, the ALU/RMW/stack/flag/flow micro-op vocabulary, the importer promoted to live-spec source (`Mos6502Spec.cs` becomes committed tool output), and the TomHarte/SingleStepTests harness as the per-opcode ground-truth oracle and pre-merge UAT gate. PR #5 of Milestone 1 (branch `feat/m1-6502-full-i`, base `main`).

**Architecture:** unchanged in kind — every new addressing mode is a fixed cycle-by-cycle bus-pattern template in `CpuEmitter` (spec-§5 "modes are micro-op templates"), every bus access goes through `ReadBus`/`WriteBus` (one cycle each), dummy reads **and dummy writes** included, so the interpreter stays cycle-true by construction. New micro-ops are new closed-vocabulary records + `Spec` factories + parser signatures + emitter applications. The structural change this chunk makes first (Task 1): instruction classification happens ONCE, in `SpecParser`, and is carried on `InstructionModel` — the emitter's parallel classifier is deleted, ending the parser/emitter drift hazard recorded in the 2b review.

**Tech stack:** unchanged (net10.0, Roslyn 4.12.0, xUnit 2.9.3). New test-side dependency: none — the TomHarte loader uses `System.Text.Json` from the BCL; vector acquisition is a git sparse-checkout script, vectors are never vendored (spec §8).

**Plan series:** 1 ✅ (PR #1) · 2a ✅ (PR #2) · 2b ✅ (PR #3) · 3a ✅ (PR #4) · **3b-i: this plan (PR #5)** · 3b-ii (BCD + BRK/RTI + interrupts + full-151 green + Klaus) · 4 peripherals + host.

**NOT in scope (3b-ii):** decimal-mode ADC/SBC; BRK; IRQ/NMI servicing + latched-line reset semantics; RTI; true P phantom-bit push/pull conventions; full-151 green; Klaus functional test.

**Recorded deviations this plan makes deliberately:**
- **ADC/SBC are binary-only.** When the D flag is set, behavior is still binary — a documented deviation until 3b-ii lands BCD. Consequence for the TomHarte gate: vector cases for ADC/SBC opcodes whose initial P has D set are **skipped with a per-opcode count** (printed in failure/summary output). The brief's "UAT runs ALL cases" is therefore qualified for exactly these 16 opcodes — recorded here, not silently.
- **P phantom bits — trued in Task 9:** PHP pushes `P | 0x30` (bit5=1, bit4=1 always, which is the hardware B-flag-in-stacked convention). PLP forces **bit5=1, bit4=0** in the live P register (real hardware: bit5 always reads 1, bit4/B is not a live flag). TomHarte vectors confirm this (probed Task 9 Step 7; pre-authorized amendment applied). The verbatim 3b-i deviation is closed — PLP is now hardware-true. 3b-ii note: no further PLP phantom-bit work needed.
- **Index registers are resolved by NAME.** X-indexed modes (`ZeroPageX`/`AbsoluteX`/`IndirectX`) emit against the register literally named `X`; Y-indexed modes against `Y`. The parser enforces the names exist (CPUGEN010). Likewise the stack/flow templates hard-code the 6502's `$0100` stack page and use the StackPointer-role register. These are 6502 conventions baked into 6502-shaped templates — the M3 Z80 spec defines its own classes/templates, so this is recorded as acceptable coupling, revisited then.
- **`Mos6502Spec.cs` becomes committed tool output** (auto-generated header, opcode-ordered rows, two TODO comments for BRK/RTI). The hand-grouped 11-row table disappears as a hand-maintained artifact; the importer + dataset + semantics map are the source of truth from Task 8 onward. The hand-written partial (`Mos6502Cpu.cs`) is untouched.

**Carry-forwards landed here** (recorded in the 2b plan's Task-6 blockquote and the 3a plan's out-of-scope list, items "6–10 of the 2b final review"):
1. **Classify once in the parser** — new `InstructionClass` enum carried on `InstructionModel`; `CpuEmitter.ClassifyInstruction` deleted (Task 1).

3. **Emitted-local-name collisions prevented at parse time** — `data, addr, lo, hi, ea, offset, target, opcode, before, value, ptr, temp` are reserved register names → CPUGEN002 (Task 1).

## The addressing-mode cycle templates (ground truth)

Cycle 1 is always the opcode fetch (in `Step`). Existing templates (Implied / Immediate / ZeroPage / Absolute r/w/jump / Relative) are unchanged from the 2b plan. New templates — every bus access listed, dummies marked. "X" stands for the index register the mode names (X or Y); zero-page index arithmetic wraps in page 0; `wrong = (hi << 8) | ((lo + X) & 0xFF)` is the not-yet-fixed-up address the real chip drives.

| Mode | Class | Cycles after fetch | Bus pattern |
|---|---|---|---|
| ZeroPageX / ZeroPageY | read (load/alu) | 3 | fetch zp; **dummy read at zp (unindexed)**; read data at `(zp+X)&0xFF` |
| ZeroPageX / ZeroPageY | write (store) | 3 | fetch zp; **dummy read at zp**; write at `(zp+X)&0xFF` |
| AbsoluteX / AbsoluteY | read (load/alu) | 3 (+1 cross) | fetch lo; fetch hi; read at `wrong` — if `lo+X ≤ 0xFF` that IS the data; else **that read was a wrong-address dummy**, re-read at `ea` |
| AbsoluteX / AbsoluteY | write (store) | 4 | fetch lo; fetch hi; **dummy read at `wrong` (always — right or wrong address)**; write at `ea` |
| IndirectX `(zp,X)` | read (load/alu) | 5 | fetch ptr; **dummy read at ptr (unindexed)**; read lo at `(ptr+X)&0xFF`; read hi at `(ptr+X+1)&0xFF`; read data at `ea` |
| IndirectX `(zp,X)` | write (store) | 5 | same first four; write at `ea` |
| IndirectY `(zp),Y` | read (load/alu) | 4 (+1 cross) | fetch ptr; read lo at `ptr`; read hi at `(ptr+1)&0xFF`; read at `wrong` (with Y) — data if no cross, else **dummy**, re-read at `ea` |
| IndirectY `(zp),Y` | write (store) | 5 | fetch ptr; read lo; read hi; **dummy read at `wrong` (always)**; write at `ea` |
| ZeroPage | rmw | 4 | fetch zp; read `value`; **dummy write of the UNMODIFIED value**; write modified |
| ZeroPageX | rmw | 5 | fetch zp; **dummy read at zp**; read `value` at `(zp+X)&0xFF`; **dummy write unmodified**; write modified |
| Absolute | rmw | 5 | fetch lo; fetch hi; read `value`; **dummy write unmodified**; write modified |
| AbsoluteX | rmw | 6 | fetch lo; fetch hi; **dummy read at `wrong` (ALWAYS, cross or not)**; read `value` at `ea`; **dummy write unmodified**; write modified |
| Accumulator | rmw | 1 | **dummy read at PC (no increment)**; operate on A |
| Indirect | jump (JMP) | 4 | fetch ptr-lo; fetch ptr-hi; read PCL at `ptr`; read PCH at `(ptr & 0xFF00) \| ((ptr+1) & 0xFF)` — **the page-wrap bug: a pointer at `$xxFF` takes its high byte from `$xx00`** |
| Implied | stack push | 2 | **dummy read at PC (no increment)**; write reg at `$0100+S`; `S--` |
| Implied | stack pull | 3 | **dummy read at PC**; **dummy read at `$0100+S` (old S — this is the "increment S" cycle, and it IS on the bus)**; `S++`; read reg at `$0100+S` |
| Absolute | flow JSR | 5 | fetch lo (PC++); **dummy read at `$0100+S`**; write PCH at `$0100+S`, `S--`; write PCL at `$0100+S`, `S--`; fetch hi at PC (PC still points at the hi byte — the pushed PC is return−1); `PC = hi:lo` |
| Implied | flow RTS | 5 | **dummy read at PC**; **dummy read at `$0100+S` (old S)**; `S++`; read PCL at `$0100+S`; `S++`; read PCH at `$0100+S`; **dummy read at new PC**; `PC++` |

(The brief's open question on pull timing is resolved here from the 64doc cycle tables, corroborated by TomHarte's 4-entry cycle arrays for PLA/PLP: fetch, dummy at PC, dummy stack read at old S, real stack read at S+1 — 4 cycles, all on the bus.)

Instruction classes after this chunk (validated by CPUGEN010 in the parser, carried as `InstructionClass`):

| Class | Op shape | Allowed modes |
|---|---|---|
| register | only Transfer/Increment/Decrement/SetNZ/SetFlag (or empty) | Implied |
| load | `Load(target)` first, then register ops | Immediate, ZeroPage, ZeroPageX, ZeroPageY, Absolute, AbsoluteX, AbsoluteY, IndirectX, IndirectY |
| alu | exactly one of Adc/Sbc/And/Ora/Eor/Compare/Bit | same nine as load |
| store | exactly one `Store(source)` | ZeroPage, ZeroPageX, ZeroPageY, Absolute, AbsoluteX, AbsoluteY, IndirectX, IndirectY |
| rmw | exactly one of ShiftLeft/ShiftRight/RotateLeft/RotateRight/IncrementMem/DecrementMem | ZeroPage, ZeroPageX, Absolute, AbsoluteX, Accumulator |
| jump | exactly one `Jump()` | Absolute, Indirect |
| branch | exactly one `BranchIf(flag, when)` | Relative |
| stack | exactly one of Push/Pull/PushP/PullP | Implied |
| flow | exactly one `Jsr()` / `Rts()` | Jsr: Absolute; Rts: Implied |

Additional parse-time requirements (CPUGEN010 with a human reason): X-indexed modes require a register named `X`; Y-indexed modes require `Y`; rmw memory modes, stack, and flow require a StackPointer-role register only where they touch the stack (stack + flow classes); alu/rmw/stack classes require a Status register. The matrix is per-CLASS — per-mnemonic legality (e.g. LDX has no ZeroPageX row) is the dataset's business, not the parser's.

## Micro-op flag semantics (the contract for Tasks 5–7)

`r` = result byte, `m` = memory/accumulator operand before the op, `d` = data read. Flag bits: C=0x01, Z=0x02, I=0x04, D=0x08, V=0x40, N=0x80 (mirrors `Flag`).

| Op | Effect | C | V | N | Z |
|---|---|---|---|---|---|
| `Adc()` | `A = A + d + C` (binary, even when D set — 3b-i deviation) | carry out (sum > 0xFF) | `(~(A^d) & (A^r) & 0x80) != 0` | r bit7 | r == 0 |
| `Sbc()` | `A = A + (d^0xFF) + C` | NOT borrow (sum > 0xFF) | `((A^d) & (A^r) & 0x80) != 0` | r bit7 | r == 0 |
| `And()` / `Ora()` / `Eor()` | `A = A op d` | — | — | r bit7 | r == 0 |
| `Compare(reg)` | none (computes `reg − d`) | `reg >= d` | — | (reg−d) bit7 | reg == d |
| `Bit()` | none | — | d bit6 | d bit7 | `(A & d) == 0` |
| `ShiftLeft()` | `r = m << 1` | m bit7 | — | r bit7 | r == 0 |
| `ShiftRight()` | `r = m >> 1` | m bit0 | — | 0 (always) | r == 0 |
| `RotateLeft()` | `r = (m << 1) \| C` | m bit7 | — | r bit7 | r == 0 |
| `RotateRight()` | `r = (m >> 1) \| (C << 7)` | m bit0 | — | r bit7 | r == 0 |
| `IncrementMem()` / `DecrementMem()` | `r = m ± 1` | — | — | r bit7 | r == 0 |
| `Decrement(reg)` | `reg = reg − 1` (flags via trailing `SetNZ`) | — | — | — | — |
| `Push(reg)` | pushes reg; no flags | | | | |
| `Pull(reg)` | `reg = pulled`; **NZ baked into the op** (stack class allows no trailing ops) | — | — | r bit7 | r == 0 |
| `PushP()` | pushes `P \| 0x30` | | | | |
| `PullP()` | `P = pulled` verbatim (bits 5/4 as stored — 3b-i convention, trued in 3b-ii) | | | | |
| `SetFlag(f, b)` | sets/clears one P bit; no other effect | | | | |
| `Jsr()` / `Rts()` | PC flow per the template table; no flags | | | | |

```csharp
internal sealed record TomHarteCycle(uint Address, byte Value, bool IsRead)

internal sealed record TomHarteState(
    ushort Pc, byte S, byte A, byte X, byte Y, byte P, TomHarteRam[] Ram);
internal sealed record TomHarteCase(
    string Name, TomHarteState Initial, TomHarteState Final, TomHarteCycle[] Cycles);

internal static class TomHarteLoader
{
    public static List<TomHarteCase> LoadFile(string path)
    {
        using var stream = File.OpenRead(path);
        using var doc = JsonDocument.Parse(stream);
        var cases = new List<TomHarteCase>(10_000);
        foreach (var element in doc.RootElement.EnumerateArray())
        {
            cases.Add(new TomHarteCase(
                element.GetProperty("name").GetString()!,
                ReadState(element.GetProperty("initial")),
                ReadState(element.GetProperty("final")),
                [.. element.GetProperty("cycles").EnumerateArray().Select(ReadCycle)]));
        }
        return cases;
    }

    private static TomHarteState ReadState(JsonElement element) => new(
        (ushort)element.GetProperty("pc").GetUInt32(),
        element.GetProperty("s").GetByte(),
        element.GetProperty("a").GetByte(),
        element.GetProperty("x").GetByte(),
        element.GetProperty("y").GetByte(),
        element.GetProperty("p").GetByte(),
        [.. element.GetProperty("ram").EnumerateArray().Select(static pair =>
        {
            using var items = pair.EnumerateArray();
            items.MoveNext(); ushort address = (ushort)items.Current.GetUInt32();
            items.MoveNext(); byte value = items.Current.GetByte();
            return new TomHarteRam(address, value);
        })]);

    private static TomHarteCycle ReadCycle(JsonElement triple)
    {
        using var items = triple.EnumerateArray();
        items.MoveNext(); uint address = items.Current.GetUInt32();
        items.MoveNext(); byte value = items.Current.GetByte();
        items.MoveNext(); bool isRead = items.Current.GetString() == "read";
        return new TomHarteCycle(address, value, isRead);
    }
```

```csharp
internal static class TomHarteRunner
{
    /// <summary>Executes one vector case against a fresh CPU + full-64KiB RAM with a
    /// tracing bus. Returns null on pass, or a multi-line failure report with the
    /// disassembled instruction and a cycle-by-cycle expected/actual table.</summary>
    public static string? RunCase(TomHarteCase testCase)
    {
        var inner = new AddressSpace(AddressSpaceKind.Program, addressBits: 16);
        inner.MapMemory(0x0000, new byte[0x10000], writable: true);
        foreach (var entry in testCase.Initial.Ram)
            inner.Write8(entry.Address, entry.Value);

        var bus = new TracingAddressSpace(inner);
        var cpu = new Mos6502Cpu(bus);
        cpu.SetRegister("PC", testCase.Initial.Pc);
        cpu.SetRegister("S", testCase.Initial.S);
        cpu.SetRegister("A", testCase.Initial.A);
        cpu.SetRegister("X", testCase.Initial.X);
        cpu.SetRegister("Y", testCase.Initial.Y);
        cpu.SetRegister("P", testCase.Initial.P);

        cpu.Step();

        var problems = new List<string>();
        CheckRegister(problems, cpu, "PC", testCase.Final.Pc);
        CheckRegister(problems, cpu, "S", testCase.Final.S);
        CheckRegister(problems, cpu, "A", testCase.Final.A);
        CheckRegister(problems, cpu, "X", testCase.Final.X);
        CheckRegister(problems, cpu, "Y", testCase.Final.Y);
        CheckRegister(problems, cpu, "P", testCase.Final.P);

        foreach (var entry in testCase.Final.Ram)
        {
            byte actual = inner.Read8(entry.Address);
            if (actual != entry.Value)
                problems.Add($"RAM[{entry.Address:X4}]: expected {entry.Value:X2}, got {actual:X2}");
        }

        if (cpu.CycleCount != testCase.Cycles.Length)
            problems.Add($"cycle count: expected {testCase.Cycles.Length}, got {cpu.CycleCount}");
        for (int i = 0; i < Math.Min(bus.Trace.Count, testCase.Cycles.Length); i++)
        {
            var expected = testCase.Cycles[i];
            var actual = bus.Trace[i];
            if (actual.Address != expected.Address || actual.Value != expected.Value
                || actual.IsRead != expected.IsRead)
            {
                problems.Add($"bus trace diverges at cycle {i + 1} (table below)");
                break;
            }
        }

        return problems.Count == 0 ? null : Format(testCase, bus, problems);
    }

    private static void CheckRegister(List<string> problems, Mos6502Cpu cpu, string name, ulong expected)
    {
        ulong actual = cpu.GetRegister(name);
        if (actual != expected)
            problems.Add($"{name}: expected {expected:X2}, got {actual:X2}");
    }

    private static string Format(TomHarteCase testCase, TracingAddressSpace bus, List<string> problems)
    {
        byte ByteAt(ushort address) =>
            testCase.Initial.Ram.FirstOrDefault(r => r.Address == address)?.Value ?? 0;

        ushort pc = testCase.Initial.Pc;
        string disassembly = Mos6502Cpu.Disassemble(
            ByteAt(pc), ByteAt((ushort)(pc + 1)), ByteAt((ushort)(pc + 2)));

        var sb = new StringBuilder();
        sb.AppendLine($"case '{testCase.Name}' — {disassembly}");
        foreach (string problem in problems)
            sb.AppendLine($"  {problem}");
        sb.AppendLine($"  {"cycle",5}  {"expected",-14}  actual");
        for (int i = 0; i < Math.Max(testCase.Cycles.Length, bus.Trace.Count); i++)
        {
            string expected = i < testCase.Cycles.Length ? testCase.Cycles[i].ToString() : "—";
            string actual = i < bus.Trace.Count ? bus.Trace[i].ToString() : "—";
            sb.AppendLine($"  {i + 1,5}  {expected,-14}  {actual}");
        }
        return sb.ToString();
    }
}
```
