## Objective (the ADR §8 PR-1 row)

Make the Z80 8-bit + 16-bit **`LD` family** emit real IL instead of falling back to `inner.Step`. Two halves
(ADR §4 Decision 3):

1. **Generator side** (`CpuEmitter.cs`): TWO edits. (1a) NARROW the unconditional `fallback = true;
   endsBlock = true;` gate at `CpuEmitter.cs:4131-4132` so the whitelisted `LD` rows (incl. the 16-bit-absolute
   `LD (nn),HL`/`LD HL,(nn)` — Decision B) are emitted with `NeedsFallback = false, EndsBlock = false` (the gate
   stays forced for every other structured-CPU op). This is the generator's **first family whitelist entry** —
   the mechanism §4 describes as "un-forcing the gate one family at a time." (1b — **Decision A**) FIX the
   descriptor cycle source: `JitBaseCycles` (`CpuEmitter.cs:4163`) currently returns the generic
   `ComputeCycles("Immediate") = 2` for the Z80 `LD r,n` rows (they are classified generic `Load`, missing the
   Z80 branch); correct it to **7 T** at the generation source, scoped so the shared 6502/68000 `ComputeCycles`
   path and their committed numbers are provably untouched (Task 1b carries the regression-safety gate).
2. **JIT side** (`BlockCompiler.*`): add a Z80 `LD` emit arm that reads the operand through the **fastmem
   split**, writes the destination register (via the existing 8-bit idiom or PR-0's `EmitStoreReg16`), charges
   the **Z80 T-state residual to reach the (now-corrected) descriptor `BaseCycles`** (fetch + per-access + the
   residual; the arm owns NO private cycle table after Decision A), replicates the `Q = 0` side-effect, and
   replicates the `WZ` (MEMPTR) side-effects the `(nn)` forms set — including the two-byte EA + `WZ = ea+1` of
   the 16-bit-absolute forms (Decision B). `LD` touches **no flags** (the easiest flag arm — deliberately
   first), so this PR proves the structured-CPU IL-emit path end-to-end **without paying the Q/MEMPTR-flag tax**
   (that is PR-2's ALU + flag core).

**Why PR-1 (ADR §8):** highest ROI (one third of all Z80 instructions), lowest risk (no-flag family), on the
best-validated non-6502 core (ZEXALL green), and it **proves the cross-ISA thesis** — a *second* CPU emitting
IL is the real M6 test (the 6502 already emits; the design stands or falls on the second core). PR-1 is the
first emit PR and the headline checkpoint after which the owner is asked to confirm OQ1/OQ2 before the full sweep.

### The Z80 `LD` oracle (the interpreter bodies the IL must match byte-identically)

All from generated `…Z80Cpu.g.cs`. `Step()` (`:1766-1781`) charges the fetch bytes (`_cycles += __r.Length`)
and advances PC; each `OpXX` body adds the REMAINING T-states via `_cycles += N`, sets `Q = 0`, and (for
`(nn)` forms) sets `WZ`. **Cycle total = fetch bytes + body `_cycles += N`.**

| Form | Example op | Body (verbatim) | T-states | Flags |
|---|---|---|---|---|
| `LD r,r'` (Register) | Op41 `LD B,C` | `B = C; _cycles += 3; Q = 0;` | 4 | none |
| `LD r,r` (same) | Op40 `LD B,B` | `_ = B; _cycles += 3; Q = 0;` | 4 | none |
| `LD r,n` (Immediate) | Op06 `LD B,n` | `byte data=ReadBus(PC); PC=(ushort)(PC+1); B=data; _cycles += 5; Q = 0;` | 7 | none |
| `LD r,(HL)` (RegIndirect) | Op46 `LD B,(HL)` | `byte data=ReadBus(HL); B=data; _cycles += 5; Q = 0;` | 7 | none |
| `LD (HL),r` (RegIndirect) | Op70 `LD (HL),B` | `WriteBus(HL,B); _cycles += 5; Q = 0;` | 7 | none |
| `LD (HL),n` (Immediate) | Op36 | reads imm, `WriteBus(HL,data); _cycles += 7;` | 10 | none |
| `LD A,(BC)` / `(DE)` | Op0A / Op1A | `byte data=ReadBus(BC); A=data; _cycles += 5; Q=0;` | 7 | none |
| `LD (BC),A` / `(DE),A` | Op02 / Op12 | `WriteBus(BC,A); _cycles += 5; Q=0;` | 7 | none |
| `LD A,(nn)` (Extended) | Op3A | `al=ReadBus(PC);PC++; ah=ReadBus(PC);PC++; data=ReadBus(al\|ah<<8); WZ=(ushort)((al\|ah<<8)+1); A=data; _cycles += 9; Q=0;` | 13 | none, **sets WZ** |
| `LD (nn),A` (Extended) | Op32 | `al=ReadBus(PC);PC++; ah=ReadBus(PC);PC++; ea=al\|ah<<8; WZ=(ushort)((A<<8)\|((ea+1)&0xFF)); WriteBus(ea,A); _cycles += 9; Q=0;` | 13 | none, **sets WZ (the A-high quirk)** |
| `LD rr,nn` (ImmExtended) | Op01 `LD BC,nn` | `lo=ReadBus(PC);PC++; hi=ReadBus(PC);PC++; BC=(ushort)(lo\|hi<<8); _cycles += 7; Q=0;` | 10 | none |
| `LD (nn),HL` (Extended) | Op22 | 16-bit store to `(nn)` | 16 | none, sets WZ |
| `LD HL,(nn)` (Extended) | Op2A | 16-bit load from `(nn)` | 16 | none, sets WZ |
| `LD SP,HL` | OpF9 | `SP = HL; _cycles += 5;` | 6 | none |

> **CRITICAL cycle discrepancy (G-cyc) — OWNER DECISION A: FIX IT IN THE GENERATOR.** The descriptor
> `BaseCycles` for the 8-bit `LD r,n` / `LD r,(HL)` / `LD (HL),r` / `LD r,r'` / `LD A,(BC)/(DE)` /
> `LD (BC)/(DE),A` / `LD A,(nn)` / `LD (nn),A` forms is computed by **`JitBaseCycles` (`CpuEmitter.cs:4163`),
> the descriptor-table generation site** — the value it returns is written into the `{baseCycles}` slot of the
> keyed descriptor literal at **`CpuEmitter.cs:4150`** (call at `:4118`). The bug: those 8-bit LD rows are
> classified as the **GENERIC** `InstructionClass.Load`/`Store`/`Register` (the importer does NOT give the
> base-plane 8-bit LDs a `Z80Ld` class — only the 16-bit + `LD (HL),n` rows ride `Z80Ld`, G3/§oracle). So in
> `JitBaseCycles` they MISS the Z80 branch (`:4171-4177`, which would call `Z80Cycles`) and fall through to
> **`ComputeCycles(insn.Mode, cls)`** (`:4196`) — and `ComputeCycles("Immediate", _) => 2` (`CpuEmitter.cs:1026`)
> returns the generic 2-cycle immediate template. Result: the emitted `LD r,n` descriptor carries **`BaseCycles
> = 2`** when the true Z80 cost is **7 T**.
>
> **Why this was latent (the regression-safety key fact):** while Z80 was all-fallback (`NeedsFallback=true`),
> the descriptor `BaseCycles` was **never read for Z80 execution** — the interpreter `Step` computed cycles from
> the op body's `_cycles += N`, and the JIT charged nothing because it never emitted the row. The wrong `2` sat
> unused. **Correcting it can only move the now-enabled Z80 JIT path** (PR-1), which is exactly what the
> TomHarte-through-JIT cycle-parity gate validates. See **Task 1b** for the scoped fix + the
> regression-safety gate that proves 6502/68000 committed numbers don't move.
>
> **The blast radius is ONE cycle value (verified row-by-row against `ComputeCycles` `:1020-1075`).** The
> generic-class Z80 LD rows that route through `ComputeCycles` are ALREADY CORRECT for every form EXCEPT the
> immediate one:
>
> | Form | Mode/Class | `ComputeCycles` entry | Value | Correct? |
> |---|---|---|---|---|
> | `LD r,r'` | `(Register, Register)` | `:1070` | 4 | ✓ |
> | **`LD r,n`** | `(Immediate, _)` | `:1026` | **2** | **✗ — want 7** |
> | `LD r,(HL)` | `(RegisterIndirect, Load)` | `:1065` | 7 | ✓ |
> | `LD (HL),r` | `(RegisterIndirect, Store)` | `:1066` | 7 | ✓ |
> | `LD A,(BC)/(DE)` | `(RegisterIndirect, Load)` | `:1065` | 7 | ✓ |
> | `LD (BC)/(DE),A` | `(RegisterIndirect, Store)` | `:1066` | 7 | ✓ |
> | `LD A,(nn)` | `(ExtendedAddress, Load)` | `:1067` | 13 | ✓ |
> | `LD (nn),A` | `(ExtendedAddress, Store)` | `:1068` | 13 | ✓ |
>
> ALREADY-CORRECT via `Z80Cycles` (the `Z80Ld`-class rows, `CpuEmitter.cs:1093-1096`): `LD (HL),n`=10 ✓,
> `LD rr,nn`=10 ✓, `LD (nn),HL`/`HL,(nn)`=16 ✓.
>
> **So Decision A's actual fix is: correct the single wrong value — Z80 `LD r,n` immediate (the 7 opcodes
> `0x06/0x0E/0x16/0x1E/0x26/0x2E/0x3E`) from 2 → 7.** The danger is that `("Immediate", _) => 2` (`:1026`) is
> the **SHARED** generic immediate template — the **6502's `LDA/LDX/LDY #imm` ride the exact same line and ARE
> genuinely 2 cycles**. Editing line 1026 would WRONGLY move the committed 6502 immediate-load numbers. The fix
> MUST therefore disambiguate the Z80 `LD r,n` WITHOUT touching `ComputeCycles` — see Task 1b.
>
> **After Decision A, the emit arm (Task 3) does NOT own a cycle table — it charges by the same total the
> (now-corrected) descriptor `BaseCycles` carries**, via the fetch + per-access + residual model. The
> residual = `BaseCycles − (1 fetch) − (per-access charges)`. So the generator fix and the emit arm are two
> halves of ONE corrected number, cross-checked by the cycle-parity gate.

## Task 1b — Fix the generator's `JitBaseCycles` so Z80 `LD r,n` carries 7 T (Decision A) + the regression gate

**Files:**
- Modify: `src/CpuEmulator.Generators/CpuEmitter.cs` (`JitBaseCycles`, `:4163`)
- Modify (test): `tests/CpuEmulator.Tests/Jit/` — a descriptor-cycle assertion for the corrected rows

**The pinned generation site.** The descriptor `BaseCycles` field is produced by **`JitBaseCycles(insn, cls)`
at `CpuEmitter.cs:4163-4197`**, whose return value is written into the keyed descriptor literal at
**`CpuEmitter.cs:4150`** (call site `:4118`, inside `KeyedDescriptorLiteral`). There is a SECOND caller —
`DescriptorLiteral` at **`:4095`** — but that is the NON-keyed (6502/legacy) table path; the Z80 only goes
through the keyed path (it is a structured CPU, `model.Decode is not null`, so its table is emitted via
`KeyedDescriptorLiteral`, `:4083`). **Pinning this matters for the safety argument below.**

**The exact bug (verified row-by-row, §G-cyc table).** In `JitBaseCycles` the Z80-class branch (`:4171-4177`)
calls `Z80Cycles` for rows whose `InstructionClass` is a `Z80*` class. But the base-plane 8-bit `LD r,n`
immediate rows are classified **generic `InstructionClass.Load`** (the importer does not give them `Z80Ld`), so
they MISS that branch and fall through to `ComputeCycles(insn.Mode, cls)` (`:4196`) → `("Immediate", _) => 2`
(`:1026`). The other generic-class 8-bit LD forms (`LD r,r'`, `LD r,(HL)`, `LD (HL),r`, `LD A,(BC)/(DE)`,
`LD (BC)/(DE),A`, `LD A,(nn)`, `LD (nn),A`) ALREADY get the right value from `ComputeCycles` (`:1065-1070`),
and the `Z80Ld`-class rows (`LD (HL),n`, `LD rr,nn`, `LD (nn),HL`, `LD HL,(nn)`) already get the right value
from `Z80Cycles` (`:1093-1096`). **So the ONLY wrong value is the immediate `LD r,n` = 2 (want 7).**

**The regression danger.** `("Immediate", _) => 2` (`:1026`) is the SHARED generic immediate template — the
**6502's `LDA/LDX/LDY #imm` (and any 68000 generic immediate) ride the exact same `ComputeCycles` line and are
genuinely 2 cycles.** The fix MUST NOT edit `ComputeCycles` and MUST NOT change the value any non-Z80 row
resolves. The fix is therefore scoped INSIDE `JitBaseCycles`, gated on a Z80-only signal, applied BEFORE the
`ComputeCycles` fallthrough.

- [ ] **Step 1:** Thread a Z80-discriminating signal into `JitBaseCycles`. The cleanest stable signal is the
  instruction's mnemonic + the fact that the base-plane Z80 `LD r,n` rows carry `InstructionClass.Load` with
  `JitMode.Immediate` AND a single-byte register target — but to avoid collision with a hypothetical future
  6502 `Immediate`+`Load`+`"LD"` (the 6502 has no `LD` mnemonic; its loads are `LDA`/`LDX`/`LDY`), key on the
  **mnemonic being exactly `"LD"`**. `JitBaseCycles` already receives `insn` (which carries `Mnemonic`), so no
  signature change is needed:

```csharp
    // CpuEmitter.cs:4163 — JitBaseCycles. Insert the Z80 LD r,n correction BEFORE the ComputeCycles
    // fallthrough. The 6502/68000 never name the "LD" mnemonic (their loads are LDA/LDX/LDY etc.), so this
    // branch is unreachable for them — their ComputeCycles("Immediate") => 2 path is provably untouched.
    private static int JitBaseCycles(InstructionModel insn, InstructionClass cls)
    {
        if (cls == InstructionClass.Branch)
            return 2;

        string firstKind = insn.Ops.Length > 0 ? insn.Ops[0].Kind : string.Empty;

        // M6 PR-1 (DECISION A): the base-plane Z80 LD r,n immediate is classified GENERIC Load (not Z80Ld),
        // so without this it would fall to ComputeCycles("Immediate") => 2. The true Z80 cost is 7 T. Keyed
        // on the "LD" mnemonic (6502/68000 have no LD mnemonic — LDA/LDX/LDY are distinct), so non-Z80 rows
        // are unreachable here and their ComputeCycles path is unchanged. The other generic-class 8-bit LD
        // forms already resolve correctly via ComputeCycles (RegisterIndirect=7, ExtendedAddress=13,
        // Register=4); the Z80Ld-class rows already resolve via Z80Cycles below — this corrects ONLY the
        // immediate-load row. (LD A,I / LD A,R are Z80EdOp / ImmediateExtended-keyed, not this generic
        // Immediate+Load shape, so they are not caught here.)
        if (insn.Mnemonic == "LD" && insn.Mode == "Immediate" && cls == InstructionClass.Load)
            return 7;

        // M3.4a: Z80 classes get their base T-state count from the Z80 cycle table ...
        if (cls is InstructionClass.Z80Alu or InstructionClass.Z80Ld or InstructionClass.Z80Stack
            or InstructionClass.Z80Exchange or InstructionClass.Z80Flow or InstructionClass.Z80Misc
            or InstructionClass.Z80Rot or InstructionClass.Z80Bit
            or InstructionClass.Z80EdIo or InstructionClass.Z80EdOp
            or InstructionClass.Z80EdBlock or InstructionClass.Z80Indexed
            or InstructionClass.Z80DdCb)
            return Z80Cycles(insn.Mode, cls, firstKind);

        // ... (Stack / Flow / ComputeCycles fallthrough unchanged) ...
    }
```

## Task 3 — The Z80 `LD` emit arm (operand read, register write, T-states, Q, WZ)

**Files:**
- Create: `src/CpuEmulator.Jit/BlockCompiler.Z80.cs` (a new per-CPU partial — mirrors `.Decimal.cs` as a
  CPU-specific arm file)

The arm switches on `(d.Mode, d.Ops[0].Kind)` and emits the right IL per LD form. It reuses the proven shared
helpers: `LoadByteFromBus` / `EmitStoreByte` (the fastmem split, each charging its own access cycle), the
8-bit `RegField` read/write idiom, and PR-0's `EmitLoadReg16`/`EmitStoreReg16` for pair operands. It charges
the **remaining** T-states (beyond the up-front fetch cycle + each bus access already charged) via a new
batch-charge helper, and sets `Q = 0` + `WZ` where the oracle does.

- [ ] **Step 1:** Add a batch cycle-charge helper to `BlockCompiler.cs` (beside `EmitChargeOneCycle`, `:312`):

```csharp
    // M6 PR-1: charge N cycles in one shot (cpu.AdvanceCycles(N) + budget -= N). EmitChargeOneCycle is the
    // N==1 special case; the Z80 LD arm charges the residual T-states (the interpreter body's `_cycles += N`)
    // after the up-front fetch + the per-access charges. N must be >= 0; N==0 is a no-op.
    private void EmitChargeCycles(EmitContext ctx, int n)
    {
        if (n <= 0) return;
        ILGenerator il = ctx.Il;
        // cpu.AdvanceCycles(n)
        il.Emit(OpCodes.Ldarg_0);
        il.Emit(OpCodes.Ldc_I4, n);
        il.Emit(OpCodes.Conv_I8);
        il.Emit(OpCodes.Call, _mAdvance);
        // budget -= n
        il.Emit(OpCodes.Ldarg_S, ArgBudget);
        il.Emit(OpCodes.Dup);
        il.Emit(OpCodes.Ldind_I8);
        il.Emit(OpCodes.Ldc_I4, n);
        il.Emit(OpCodes.Conv_I8);
        il.Emit(OpCodes.Sub);
        il.Emit(OpCodes.Stind_I8);
    }
```

- [ ] **Step 3:** The arm itself. Each branch mirrors its oracle body exactly. **Cycle accounting model:**
  the up-front fetch charges 1 (EmitInstruction, Z4); each `LoadByteFromBus`/`EmitStoreByte` charges 1
  (Z3); the arm charges the residual to reach the table total. Worked example — `LD r,n` (7 T): fetch(1) +
  immediate `LoadByteFromBus`(1) + residual `EmitChargeCycles(ctx, 5)` = 7. `LD r,(HL)` (7 T): fetch(1) +
  `LoadByteFromBus(HL)`(1) + residual 5 = 7. `LD r,r'` (4 T): fetch(1) + no bus access + residual 3 = 4.

```csharp
namespace CpuEmulator.Jit;

using System.Reflection;
using System.Reflection.Emit;
using CpuEmulator.Core.Jit;

internal sealed partial class BlockCompiler<TCpu>
{
    // M6 PR-1: the Z80 LD-family emit arm. Mirrors the generated Op-body oracle one-for-one:
    // operands through the fastmem split, register writes via the 8-bit idiom or PR-0's 16-bit helper,
    // the Z80 T-state residual charged after the fetch + per-access charges, Q=0 always, WZ set on (nn) forms.
    // NO flags (LD touches none) — that is PR-2.
    // DECISION A: the descriptor's BaseCycles is now CORRECT for every LD form (Task 1b fixed LD r,n 2→7), so
    // this arm charges the residual to reach `d.BaseCycles` — it does NOT own a private cycle table. The
    // per-form residual constants below (3/5/7/9/11) are `d.BaseCycles − 1 fetch − (per-access charges)`; they
    // MUST equal the totals the corrected descriptor carries (cross-checked by the cycle-parity gate, Task 4).
    // DECISION B: the 16-bit-absolute LD (nn),HL / LD HL,(nn) (16 T) have their own branches here (no longer
    // deferred); the gate (IsEmittableZ80Family) admits them in lockstep.
    private void EmitZ80Ld(EmitContext ctx, OpcodeDescriptor d)
    {
        ILGenerator il = ctx.Il;
        JitOp op = d.Ops[0];

        switch (d.Mode, op.Kind)
        {
            // LD r,r'  (Register, Transfer source->target) — 4 T (fetch 1 + residual 3)
            case (JitMode.Register, "Transfer"):
                il.Emit(OpCodes.Ldarg_0);
                il.Emit(OpCodes.Ldarg_0);
                il.Emit(OpCodes.Ldfld, RegField(op.RegA));   // source byte
                il.Emit(OpCodes.Stfld, RegField(op.RegB));   // target = source
                EmitChargeCycles(ctx, 3);
                EmitZ80ClearQ(ctx);
                break;

            // LD r,n  (Immediate, Load target) — 7 T (fetch 1 + imm read 1 + residual 5)
            case (JitMode.Immediate, "Load"):
                EmitLoadPC(ctx);                             // address = PC (the immediate byte)
                il.Emit(OpCodes.Conv_U4);
                LoadByteFromBus(ctx);                        // data on stack; charges 1; advances nothing
                il.Emit(OpCodes.Stloc, ctx.DataLocal);
                EmitIncrementPC(ctx, 1);                     // consume the immediate byte
                il.Emit(OpCodes.Ldarg_0);
                il.Emit(OpCodes.Ldloc, ctx.DataLocal);
                il.Emit(OpCodes.Conv_U1);
                il.Emit(OpCodes.Stfld, RegField(op.RegA));   // target = data
                EmitChargeCycles(ctx, 5);
                EmitZ80ClearQ(ctx);
                break;

            // LD r,(HL) / LD A,(BC) / LD A,(DE)  (RegisterIndirect, Load target) — 7 T (fetch 1 + read 1 + 5)
            case (JitMode.RegisterIndirect, "Load"):
                EmitLoadReg16(ctx, Z80IndirectPair(d));      // HL / BC / DE address on stack (int)
                il.Emit(OpCodes.Conv_U4);
                LoadByteFromBus(ctx);                        // data; charges 1
                il.Emit(OpCodes.Stloc, ctx.DataLocal);
                il.Emit(OpCodes.Ldarg_0);
                il.Emit(OpCodes.Ldloc, ctx.DataLocal);
                il.Emit(OpCodes.Conv_U1);
                il.Emit(OpCodes.Stfld, RegField(op.RegA));   // target = (pair)
                EmitChargeCycles(ctx, 5);
                EmitZ80ClearQ(ctx);
                break;

            // LD (HL),r / LD (BC),A / LD (DE),A  (RegisterIndirect, Store source) — 7 T (fetch 1 + write 1 + 5)
            case (JitMode.RegisterIndirect, "Store"):
                EmitLoadReg16(ctx, Z80IndirectPair(d));      // address on stack
                il.Emit(OpCodes.Conv_U4);
                il.Emit(OpCodes.Ldarg_0);
                il.Emit(OpCodes.Ldfld, RegField(op.RegA));   // source byte (A for BC/DE forms; r for (HL))
                EmitStoreByte(ctx);                          // writes (fastmem/bus), charges 1, marks dirty
                EmitChargeCycles(ctx, 5);
                EmitZ80ClearQ(ctx);
                break;

            // LD (HL),n  (Immediate, StoreImm8) — 10 T (fetch 1 + imm read 1 + write 1 + residual 7)
            case (JitMode.Immediate, "StoreImm8"):
                EmitLoadReg16(ctx, "HL");                    // address
                il.Emit(OpCodes.Conv_U4);
                EmitLoadPC(ctx);                             // immediate byte address
                il.Emit(OpCodes.Conv_U4);
                LoadByteFromBus(ctx);                        // data; charges 1
                EmitIncrementPC(ctx, 1);
                EmitStoreByte(ctx);                          // address,data on stack -> write; charges 1
                EmitChargeCycles(ctx, 7);
                EmitZ80ClearQ(ctx);
                break;

            // LD rr,nn  (ImmediateExtended, Load16 pair) — 10 T (fetch 1 + lo read 1 + hi read 1 + residual 7)
            case (JitMode.ImmediateExtended, "Load16"):
                // value = lo | (hi << 8)
                EmitLoadPC(ctx); il.Emit(OpCodes.Conv_U4); LoadByteFromBus(ctx);   // lo (charges 1)
                EmitIncrementPC(ctx, 1);
                il.Emit(OpCodes.Stloc, ctx.LoLocal);
                EmitLoadPC(ctx); il.Emit(OpCodes.Conv_U4); LoadByteFromBus(ctx);   // hi (charges 1)
                EmitIncrementPC(ctx, 1);
                il.Emit(OpCodes.Ldc_I4_8); il.Emit(OpCodes.Shl);
                il.Emit(OpCodes.Ldloc, ctx.LoLocal); il.Emit(OpCodes.Or);          // hi<<8 | lo
                EmitStoreReg16(ctx, op.RegA);                                      // BC/DE/HL/SP = value
                EmitChargeCycles(ctx, 7);
                EmitZ80ClearQ(ctx);
                break;

            // LD A,(nn)  (ExtendedAddress, Load A) — 13 T (fetch 1 + 2 addr reads + 1 data read + residual 9)
            case (JitMode.ExtendedAddress, "Load"):
                EmitZ80ReadAbsEa(ctx);                       // ea (int) -> EaLocal; charges 2 (lo+hi)
                // WZ = ea + 1
                il.Emit(OpCodes.Ldloc, ctx.EaLocal); il.Emit(OpCodes.Ldc_I4_1); il.Emit(OpCodes.Add);
                EmitZ80SetWZ(ctx);
                il.Emit(OpCodes.Ldloc, ctx.EaLocal); il.Emit(OpCodes.Conv_U4);
                LoadByteFromBus(ctx);                        // data (charges 1)
                il.Emit(OpCodes.Stloc, ctx.DataLocal);
                il.Emit(OpCodes.Ldarg_0);
                il.Emit(OpCodes.Ldloc, ctx.DataLocal); il.Emit(OpCodes.Conv_U1);
                il.Emit(OpCodes.Stfld, RegField("A"));       // A = (nn)
                EmitChargeCycles(ctx, 9);
                EmitZ80ClearQ(ctx);
                break;

            // LD (nn),A  (ExtendedAddress, Store A) — 13 T; WZ = (A<<8) | ((ea+1) & 0xFF)  (the A-high quirk)
            case (JitMode.ExtendedAddress, "Store"):
                EmitZ80ReadAbsEa(ctx);                       // ea -> EaLocal; charges 2
                // WZ = (A<<8) | ((ea+1) & 0xFF)
                il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, RegField("A"));
                il.Emit(OpCodes.Ldc_I4_8); il.Emit(OpCodes.Shl);
                il.Emit(OpCodes.Ldloc, ctx.EaLocal); il.Emit(OpCodes.Ldc_I4_1); il.Emit(OpCodes.Add);
                il.Emit(OpCodes.Ldc_I4, 0xFF); il.Emit(OpCodes.And);
                il.Emit(OpCodes.Or);
                EmitZ80SetWZ(ctx);
                il.Emit(OpCodes.Ldloc, ctx.EaLocal); il.Emit(OpCodes.Conv_U4);
                il.Emit(OpCodes.Ldarg_0); il.Emit(OpCodes.Ldfld, RegField("A"));
                EmitStoreByte(ctx);                          // (ea) = A; charges 1
                EmitChargeCycles(ctx, 9);
                EmitZ80ClearQ(ctx);
                break;

            // LD (nn),HL  (ExtendedAddress, Store16) — 16 T; WZ = ea+1 (DECISION B — firmly IN PR-1).
            // Oracle Op22 (…Z80Cpu.g.cs:4175-4187): read 2-byte ea, WZ=ea+1, write lo=(byte)HL @ ea,
            // write hi=(byte)(HL>>8) @ ea+1, _cycles += 11. Total 16 = fetch 1 + 2 ea + 2 writes + residual 11.
            case (JitMode.ExtendedAddress, "Store16"):
                EmitZ80ReadAbsEa(ctx);                       // ea -> EaLocal; charges 2 (lo+hi)
                il.Emit(OpCodes.Ldloc, ctx.EaLocal); il.Emit(OpCodes.Ldc_I4_1); il.Emit(OpCodes.Add);
                EmitZ80SetWZ(ctx);                           // WZ = ea + 1
                // WriteBus(ea, (byte)HL)  — low byte of the pair
                il.Emit(OpCodes.Ldloc, ctx.EaLocal); il.Emit(OpCodes.Conv_U4);
                EmitLoadReg16(ctx, op.RegA);                 // HL (int) on stack
                il.Emit(OpCodes.Conv_U1);                    // (byte)HL = low
                EmitStoreByte(ctx);                          // (ea) = lo; charges 1
                // WriteBus((ea+1)&0xFFFF, (byte)(HL>>8)) — high byte
                il.Emit(OpCodes.Ldloc, ctx.EaLocal); il.Emit(OpCodes.Ldc_I4_1); il.Emit(OpCodes.Add);
                il.Emit(OpCodes.Ldc_I4, 0xFFFF); il.Emit(OpCodes.And); il.Emit(OpCodes.Conv_U4);
                EmitLoadReg16(ctx, op.RegA);
                il.Emit(OpCodes.Ldc_I4_8); il.Emit(OpCodes.Shr_Un);
                il.Emit(OpCodes.Conv_U1);                    // (byte)(HL>>8) = high
                EmitStoreByte(ctx);                          // (ea+1) = hi; charges 1
                EmitChargeCycles(ctx, 11);                   // residual to reach 16 T
                EmitZ80ClearQ(ctx);
                break;

            // LD HL,(nn)  (ExtendedAddress, LoadMem16) — 16 T; WZ = ea+1 (DECISION B — firmly IN PR-1).
            // Oracle Op2A (…Z80Cpu.g.cs:4224-4237): read 2-byte ea, WZ=ea+1, vlo=ReadBus(ea),
            // vhi=ReadBus(ea+1), HL = vlo | vhi<<8, _cycles += 11. Total 16 = fetch 1 + 2 ea + 2 reads + 11.
            case (JitMode.ExtendedAddress, "LoadMem16"):
                EmitZ80ReadAbsEa(ctx);                       // ea -> EaLocal; charges 2
                il.Emit(OpCodes.Ldloc, ctx.EaLocal); il.Emit(OpCodes.Ldc_I4_1); il.Emit(OpCodes.Add);
                EmitZ80SetWZ(ctx);                           // WZ = ea + 1
                // vlo = ReadBus(ea)
                il.Emit(OpCodes.Ldloc, ctx.EaLocal); il.Emit(OpCodes.Conv_U4);
                LoadByteFromBus(ctx);                        // vlo; charges 1
                il.Emit(OpCodes.Stloc, ctx.LoLocal);
                // vhi = ReadBus((ea+1)&0xFFFF)
                il.Emit(OpCodes.Ldloc, ctx.EaLocal); il.Emit(OpCodes.Ldc_I4_1); il.Emit(OpCodes.Add);
                il.Emit(OpCodes.Ldc_I4, 0xFFFF); il.Emit(OpCodes.And); il.Emit(OpCodes.Conv_U4);
                LoadByteFromBus(ctx);                        // vhi; charges 1
                // HL = vlo | (vhi << 8)
                il.Emit(OpCodes.Ldc_I4_8); il.Emit(OpCodes.Shl);
                il.Emit(OpCodes.Ldloc, ctx.LoLocal); il.Emit(OpCodes.Or);
                EmitStoreReg16(ctx, op.RegA);                // HL = vlo | vhi<<8 (PR-0 helper)
                EmitChargeCycles(ctx, 11);                   // residual to reach 16 T
                EmitZ80ClearQ(ctx);
                break;

            default:
                throw new EmulationException(
                    $"EmitZ80Ld: unhandled LD form (mode={d.Mode}, kind={op.Kind}, opcode=0x{d.Opcode:X2}). "
                  + "The whitelist (IsEmittableZ80Family) admitted a row with no emit branch — keep it in "
                  + "the gate's fallback set until an arm exists.");
        }
    }

    // The indirect pair a RegisterIndirect LD addresses: (HL) for LD r,(HL)/LD (HL),r; (BC)/(DE) for the
    // accumulator forms. Recover it from the descriptor — the importer encodes it; verify the carrier field.
    private static string Z80IndirectPair(OpcodeDescriptor d)
    {
        // Opcodes 0x02 (LD (BC),A) / 0x0A (LD A,(BC)) -> BC; 0x12/0x1A -> DE; everything else (the 0x46-block
        // LD r,(HL) and 0x70-block LD (HL),r) -> HL. Keyed on the raw opcode (unambiguous on the base plane).
        return d.Opcode switch
        {
            0x02 or 0x0A => "BC",
            0x12 or 0x1A => "DE",
            _ => "HL",
        };
    }

    // Read a 2-byte little-endian absolute address from PC into ctx.EaLocal; charges 2 cycles (lo + hi reads).
    private void EmitZ80ReadAbsEa(EmitContext ctx)
    {
        ILGenerator il = ctx.Il;
        EmitLoadPC(ctx); il.Emit(OpCodes.Conv_U4); LoadByteFromBus(ctx);   // lo (charges 1)
        EmitIncrementPC(ctx, 1);
        il.Emit(OpCodes.Stloc, ctx.LoLocal);
        EmitLoadPC(ctx); il.Emit(OpCodes.Conv_U4); LoadByteFromBus(ctx);   // hi (charges 1)
        EmitIncrementPC(ctx, 1);
        il.Emit(OpCodes.Ldc_I4_8); il.Emit(OpCodes.Shl);
        il.Emit(OpCodes.Ldloc, ctx.LoLocal); il.Emit(OpCodes.Or);          // ea = lo | hi<<8
        il.Emit(OpCodes.Stloc, ctx.EaLocal);
    }
}
```

> **Builder note — the 16-bit-absolute LD (`Store16`/`LoadMem16`, 16 T) — DECISION B, FIRMLY IN PR-1.** The
> two branches above are transcribed directly from the oracle bodies Op22 (`…Z80Cpu.g.cs:4175-4187`) and Op2A
> (`:4224-4237`) — **the recon read both bodies verbatim**: each reads the 2-byte EA (charges 2), sets
> `WZ = ea + 1` (the SIMPLE WZ — note these forms do NOT use the A-high quirk that `LD (nn),A` does), does two
> byte accesses (charges 2), and `_cycles += 11` (residual to total 16 = fetch 1 + 2 ea + 2 data + 11). They
> are inlined into `EmitZ80Ld` (no separate `EmitZ80Store16Abs`/`EmitZ80Load16Abs` helpers needed) and reuse
> `EmitZ80ReadAbsEa` / `EmitZ80SetWZ` / `EmitLoadReg16` / `EmitStoreReg16` / `LoadByteFromBus` / `EmitStoreByte`.
> **These forms are NOT deferred** — the gate (`IsEmittableZ80Family`, Task 1) admits `0x22`/`0x2A` and these
> arms emit them in lockstep; the parity sweep (Task 4) covers them. Before committing, re-confirm the byte
> order + the `ea+1` wraparound `& 0xFFFF` against Op22/Op2A (the recon pinned both; this is a belt-and-braces
