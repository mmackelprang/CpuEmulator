# M3.4b: The Z80 CB Prefix Plane — Rotate/Shift, BIT/RES/SET, TomHarte-Green

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** bring the Z80 **0xCB prefix plane** (all 256 second-byte opcodes — RLC/RRC/RL/RR/SLA/SRA/SLL/SRL,
BIT, RES, SET) plus the four deferred base-plane **rotate-accumulators** (RLCA 0x07, RRCA 0x0F, RLA
0x17, RRA 0x1F) from the M3.4a `// TODO(semantics)` skeleton to a **flag-correct, cycle-correct,
TomHarte-green** interpreter, retiring the M3.4a Q-seeding crutch with a real cross-instruction Q
lifecycle and adding the WZ/MEMPTR register that `BIT n,(HL)` needs for its X/Y flags.

**Architecture:** The M3.4a base plane already shipped the whole machine the CB plane reuses: the
algorithmic per-opcode semantics generator (`Z80BaseSemantics.cs`), the per-spec flag-bit map
(`FlagBitMap`), the composable Z80 flag-word emitter (`EmitZ80FlagWord`/`EmitZ80Alu8`), the prefix
decode walk (`EmitStructuredDecodeWalk` keys `(0xCB << 8) | op`), and the Z80 TomHarte harness
(`Z80TomHarteRunner`/`Z80TomHarteLoader`). M3.4b is **additive and analogous**: a new `Z80CbSemantics`
generator emits the CB rows from the octal `x/y/z` fields, a new `Bit` AddrMode + a `Z80Bit`
instruction class carry them, a new `EmitZ80CbBody` arm emits the rotate/BIT/RES/SET bodies reusing the
existing flag helpers, and the harness grows a CB theory that loads `cb {op:x2}.json`. Every 6502
artifact stays byte-identical; the base plane stays green.

**Tech Stack:** C# (.NET 10), a Roslyn incremental source generator (`CpuEmulator.Generators`), a
console spec importer (`CpuEmulator.SpecImporter`) that regenerates `Z80Spec.cs` from
`z80-opcodes.json` + `z80-semantics.json`, and xUnit + the SingleStepTests/z80 vectors (TomHarte).

## Scope

**IN scope (the CB plane comes alive end-to-end):**

1. **The 0xCB prefix plane — all 256 second-byte opcodes.** Octal `xx yyy zzz`:
   - **x=0 — rotate/shift**, `rot[y]`: 0 RLC, 1 RRC, 2 RL, 3 RR, 4 SLA, 5 SRA, **6 SLL** (undocumented),
     7 SRL — on `reg[z]`, result written back. `reg[z]` = B C D E H L (HL) A.
   - **x=1 — BIT y,reg[z]** — test bit y, not written back; `(HL)` X/Y come from **W** (WZ high byte).
   - **x=2 — RES y,reg[z]** — clear bit y, written back.
   - **x=3 — SET y,reg[z]** — set bit y, written back.
2. **The four base-plane rotate-accumulators** RLCA/RRCA/RLA/RRA (0x07/0x0F/0x17/0x1F) — they share the
   rotate logic but PRESERVE S/Z/P-V (CB rotates compute them).
3. **WZ/MEMPTR** internal register — needed for `BIT n,(HL)` X/Y.
4. **The cross-instruction Q lifecycle** — every executed instruction sets `Q = F` if it wrote flags,
   else `Q = 0`; retires the M3.4a runner Q-seeding-only crutch (the runner still seeds the INITIAL Q as
   legitimate pre-state, but now the generated `Step` MAINTAINS Q and the runner CHECKS the final Q).
5. **The TomHarte CB gate** — a `CoveredCbPlaneOpcodes` theory loading `cb {op:x2}.json`, plus the four
   rotate-accumulators now covered by the existing base-plane theory.

**OUT of scope (each is a later PR — do NOT reach for it):**

- **The ED plane (M3.4c)** — block ops (LDIR/LDDR/CPIR/CPDR/INIR/OTIR/…), 16-bit ADC/SBC HL,rr,
  IM 0/1/2, NMI/IFF servicing, RETI/RETN, RRD/RLD, `(C)`-indexed I/O (`IN r,(C)`/`OUT (C),r`),
  `LD A,I`/`LD A,R`, NEG.
- **The DD/FD/DDCB/FDCB planes (M3.4d)** — IX/IY indexed `(IX+d)`/`(IY+d)`, the two-deep
  compound-prefix decoder extension, the HL→IX/IY re-interpretation.
- **The Z80 through the JIT (M3.5)** — the CB rows are emitted as JIT fallbacks (the descriptor table
  must be well-formed) but the JIT never emits IL for them; the Z80 runs interpreter-only.

> **The honest one-liner for M3.4b's close-state:** the Z80 base plane AND CB plane run and are
> TomHarte-green (per-instruction registers incl. F's X/Y bits, WZ, Q, memory, AND per-T-state bus
> trace); the four rotate-accumulators are live; the ED/DD/FD planes remain `// TODO` skeleton; the Z80
> still runs interpreter-only. "TomHarte-green" is asserted over the 256 CB opcodes + the 4
> rotate-accumulators, enumerated honestly in the closeout.

### CB-plane semantics reference (bake these in; TomHarte is the final oracle)

Second byte fields: `x = (op>>6)&3`, `y = (op>>3)&7`, `z = op&7`. `reg[z]` = B C D E H L (HL) A.

- **x=0 rotate/shift** (op = `rot[y]`): operate on `reg[z]`, write result back.
  Flags: S,Z from result; H=0; N=0; P/V = parity(result); C = the bit shifted out; X = result bit3,
  Y = result bit5. The eight ops:
  - RLC: `r = (r<<1) | (r>>7)`; C = old bit7.
  - RRC: `r = (r>>1) | (r<<7)`; C = old bit0.
  - RL:  `r = (r<<1) | oldC`; C = old bit7.
  - RR:  `r = (r>>1) | (oldC<<7)`; C = old bit0.
  - SLA: `r = r<<1`; C = old bit7; bit0 = 0.
  - SRA: `r = (r>>1) | (r & 0x80)`; C = old bit0 (arithmetic — bit7 preserved).
  - SLL: `r = (r<<1) | 1`; C = old bit7 (UNDOCUMENTED — bit0 forced to 1).
  - SRL: `r = r>>1`; C = old bit0; bit7 = 0.
- **x=1 BIT y,reg[z]**: `Z = (bit == 0)`; P/V = Z; H = 1; N = 0; S = (y==7 && bit set) ? 1 : 0;
  C unaffected (preserved). NOT written back. X/Y: for a REGISTER operand, from the operand's bits 3/5;
  for **(HL)**, X/Y come from **W** (WZ high byte) bits 3/5. Cycles: reg 8T, (HL) 12T.
- **x=2 RES y,reg[z]**: `reg[z] &= ~(1<<y)`. No flag changes. Written back. Cycles: reg 8T, (HL) 15T.
- **x=3 SET y,reg[z]**: `reg[z] |= (1<<y)`. No flag changes. Written back. Cycles: reg 8T, (HL) 15T.
- **Rotate/shift cycles:** reg 8T; (HL) 15T.

**Rotate-accumulators (base plane, 1 byte, 4T each)** — same rotate math, DIFFERENT flags: set ONLY
H=0, N=0, C, and X/Y from the new A; **S, Z, P/V are PRESERVED**. RLCA=07 (left circular, C←old A bit7);
RRCA=0F (right circular, C←old A bit0); RLA=17 (left through carry); RRA=1F (right through carry).

### Findings from reading the shipped code + dataset + vectors (the code/vectors WIN over the prose)

- **The dataset is MISSING the 8 SLL rows.** `z80-opcodes.json` has **248** CB rows, not 256 — opcodes
  `0xCB:0x30`..`0xCB:0x37` (SLL/SLI on B..A) are ABSENT. The TomHarte vectors `cb 30.json`..`cb 37.json`
  EXIST (all 256 files present). **M3.4b must ADD the 8 SLL rows to the dataset** (Task 8). The base-page
  Z80Spec showed the gap (`Z80Spec.cs:348-364` lists SLA/SRA/SRL TODOs but no SLL).
- **The dataset CB `cycles` field is varied (8/12/15) but the emitter IGNORES it.** The base plane
  computes T-states from `Z80Cycles(mode, class, opKind)`, not the dataset (`CpuEmitter.cs:281-283,419`).
  The CB emitter likewise computes cycles from the opcode's `z`/`x` fields: reg (z≠6) → 8; BIT (HL)
  (x=1,z=6) → 12; rotate/RES/SET (HL) (x≠1,z=6) → 15. CONFIRMED: `cb 00`=8, `cb 40`=8, `cb 46`=12,
  `cb 06`/`cb 86`/`cb c6`=15.
- **The Q lifecycle is provable from the vectors.** `cb 00` (RLC B, writes flags): final.q = final.f =
  0x2D. `cb 86` (RES 0,(HL), no flags): init.q=0, final.q=0. `cb c6` (SET 0,(HL), no flags): init.q=212,
  **final.q=0** — the instruction that writes no flags clears Q. So: rotate/shift + BIT set Q=F; RES/SET
  set Q=0.
- **WZ is read-only for the CB plane.** Every CB vector has init.wz == final.wz (CB ops don't modify
  WZ). `BIT y,(HL)` only READS W for X/Y. CONFIRMED `cb 46` (BIT 0,(HL)): wz=0x5D48 (W=0x5D); final.f X
  bit3 = W bit3 = 1, Y bit5 = W bit5 = 0 — matches the final f=0x19.
- **No `ports` for the CB plane.** CB ops never touch the I/O bus; the ports array is empty for all CB
  vectors.
- **`JitMode` has no `Bit` member and the disassembler/`ModeLength` have no `Bit` arm.** Adding the `Bit`
  AddrMode forces additive growth of `JitMode` (`OpcodeDescriptor.cs:20`), the disassembler arm
  (`CpuEmitter.cs:2286`), and `ModeLength` (`CpuEmitter.cs:2014`).

**Design decision (recorded):** the CB rotate/shift family is modeled as ONE op record
`CbRotateOp(string Op, string Target)` carrying the op name (`"RLC"`/`"RRC"`/`"RL"`/`"RR"`/`"SLA"`/
`"SRA"`/`"SLL"`/`"SRL"`) and the target register name (`"B"`…`"A"`, or `"(HL)"` for the memory form).

index 0–7, and the target. The rotate-accumulators are four zero-arg ops `Rlca`/`Rrca`/`Rla`/`Rra`. This
keeps the generator's per-op switch small (one CB rotate arm, one CB bit arm) — the same shape as the
single `EmitZ80Alu8`/`EmitZ80MiscBody` arms. The `Op`/`Bit`/`Target` are STRING/INT literals the
constrained DSL allows (the parser already accepts `ArgKind.Reg`, and we add `ArgKind.Str`/`ArgKind.Int`
for the op-name + bit-index — see Step 3).

```csharp
    /// <summary>Emit the rotate/shift of an 8-bit value held in C# local <c>v</c> (byte), producing the
    /// result in local <c>r</c> (byte) and the carry-out in local <c>cout</c> (int 0/1). <paramref
    /// name="op"/> ∈ RLC/RRC/RL/RR/SLA/SRA/SLL/SRL. RL/RR consume the current carry via <paramref
    /// name="oldCarryExpr"/> (an int 0/1 expression). Shared by the rotate-accumulators (Task 4) and the
    /// CB rotate/shift (Task 5).</summary>
    private static void EmitRotateMath(StringBuilder sb, string op, string oldCarryExpr)
    {
        switch (op)
        {
            case "RLC":
                sb.AppendLine("        int cout = (v >> 7) & 1;");
                sb.AppendLine("        byte r = unchecked((byte)((v << 1) | cout));");
                break;
            case "RRC":
                sb.AppendLine("        int cout = v & 1;");
                sb.AppendLine("        byte r = unchecked((byte)((v >> 1) | (cout << 7)));");
                break;
            case "RL":
                sb.AppendLine("        int cout = (v >> 7) & 1;");
                sb.AppendLine($"        byte r = unchecked((byte)((v << 1) | {oldCarryExpr}));");
                break;
            case "RR":
                sb.AppendLine("        int cout = v & 1;");
                sb.AppendLine($"        byte r = unchecked((byte)((v >> 1) | ({oldCarryExpr} << 7)));");
                break;
            case "SLA":
                sb.AppendLine("        int cout = (v >> 7) & 1;");
                sb.AppendLine("        byte r = unchecked((byte)(v << 1));");
                break;
            case "SRA":
                sb.AppendLine("        int cout = v & 1;");
                sb.AppendLine("        byte r = unchecked((byte)((v >> 1) | (v & 0x80)));");
                break;
            case "SLL":   // undocumented: shift left, bit0 forced to 1
                sb.AppendLine("        int cout = (v >> 7) & 1;");
                sb.AppendLine("        byte r = unchecked((byte)((v << 1) | 1));");
                break;
            case "SRL":
                sb.AppendLine("        int cout = v & 1;");
                sb.AppendLine("        byte r = unchecked((byte)(v >> 1));");
                break;
            default:
                throw new System.InvalidOperationException($"unknown rotate op '{op}'");
        }
    }

    private static void EmitZ80RotBody(
        StringBuilder sb, InstructionModel insn, string pc, string pcType, string? statusReg, FlagBitMap flags)
    {
        string f = statusReg ?? "F";
        string kind = insn.Ops[0].Kind;
        // CB rotate/shift (CbRotate, Bit mode) is Task 5. Here: the four base-plane rotate-accumulators.
        if (kind == "CbRotate")
        {
            EmitZ80CbRotate(sb, insn, pc, f, flags);   // Task 5
            return;
        }

        // Rotate-accumulators: operate on A, set ONLY C/H/N + X/Y (from new A); PRESERVE S/Z/P-V.
        string cMask = $"0x{(byte)(1 << flags.BitOf("C")):X2}";
        string hMask = $"0x{(byte)(1 << flags.BitOf("H")):X2}";
        string nMask = $"0x{(byte)(1 << flags.BitOf("N")):X2}";
        string xMask = $"0x{(byte)(1 << flags.BitOf("X")):X2}";
        string yMask = $"0x{(byte)(1 << flags.BitOf("Y")):X2}";
        // Preserve mask = S|Z|P bits (everything the rotate-accumulators leave alone).
        byte preserveBits = (byte)((1 << flags.BitOf("S")) | (1 << flags.BitOf("Z")) | (1 << flags.BitOf("P")));
        string preserve = $"0x{preserveBits:X2}";
        string op = kind switch { "Rlca" => "RLC", "Rrca" => "RRC", "Rla" => "RL", _ => "RR" };
        string oldCarry = $"(({f} & {cMask}) != 0 ? 1 : 0)";

        sb.AppendLine("        byte v = A;");
        EmitRotateMath(sb, op, oldCarry);
        sb.AppendLine("        A = r;");
        sb.AppendLine($"        {f} = unchecked((byte)(({f} & {preserve})");
        sb.AppendLine($"            | (cout != 0 ? {cMask} : 0x00)");
        sb.AppendLine($"            | ((r & 0x20) != 0 ? {yMask} : 0x00)");
        sb.AppendLine($"            | ((r & 0x08) != 0 ? {xMask} : 0x00)));");
        sb.AppendLine($"        _ = {hMask}; _ = {nMask};   // H=0, N=0 (cleared by the preserve mask above)");
        sb.AppendLine("        _cycles += 3;   // RLCA/RRCA/RLA/RRA = 4 T-states (fetch + 3 internal)");
    }
```

```csharp
namespace CpuEmulator.SpecImporter;

/// <summary>
/// Computes the micro-op text for a Z80 CB-PLANE opcode ALGORITHMICALLY from the second byte (M3.4b),
/// the CB analogue of <see cref="Z80BaseSemantics"/>. The CB plane is the classic octal encoding
/// (x = bits 7-6, y = bits 5-3, z = bits 2-0): x selects the family (0 rotate/shift, 1 BIT, 2 RES,
/// 3 SET); for x=0, y selects rot[y]; for x≠0, y is the bit index; z selects the register operand
/// reg[z] (B C D E H L (HL) A). Returns the ops-text (e.g. "[CbRotate(\"RLC\",\"B\")]") for every
/// CB opcode 0x00..0xFF — all 256 are owned (the plane is total).
/// </summary>
public static class Z80CbSemantics
{
    private static readonly string[] Reg8 = ["B", "C", "D", "E", "H", "L", "(HL)", "A"];
    // rot[y] for x=0 — index 6 is SLL (undocumented shift-left-inline).
    private static readonly string[] Rot = ["RLC", "RRC", "RL", "RR", "SLA", "SRA", "SLL", "SRL"];

    public static string OpsFor(int opcode)
    {
        int x = (opcode >> 6) & 0x03;
        int y = (opcode >> 3) & 0x07;
        int z = opcode & 0x07;
        string target = Reg8[z];
        return x switch
        {
            0 => $"[CbRotate(\"{Rot[y]}\",\"{target}\")]",
            1 => $"[CbBit(\"BIT\",{y},\"{target}\")]",
            2 => $"[CbBit(\"RES\",{y},\"{target}\")]",
            _ => $"[CbBit(\"SET\",{y},\"{target}\")]",
        };
    }
}
```

```csharp
    /// <summary>Strip the surrounding quotes from a CbRotate/CbBit string arg ("RLC" → RLC, "(HL)" →
    /// (HL)). The parser stores Str args WITH quotes (Task 2) so the emitter can tell a string operand
    /// from a register operand.</summary>
    private static string Unquote(string s) => s.Length >= 2 && s[0] == '"' ? s[1..^1] : s;

    /// <summary>CB rotate/shift on reg[z] or (HL). Flags: S,Z from result; H=0; N=0; P/V=parity;
    /// C=bit shifted out; X=res bit3, Y=res bit5. Writes the result back (z=6: read/op/write (HL)).</summary>
    private static void EmitZ80CbRotate(StringBuilder sb, InstructionModel insn, string pc, string f, FlagBitMap flags)
    {
        string op = Unquote(insn.Ops[0].Args[0]);       // "RLC".."SRL"
        string target = Unquote(insn.Ops[0].Args[1]);   // "B".."A" or "(HL)"
        bool isMem = target == "(HL)";
        string cMask = $"0x{(byte)(1 << flags.BitOf("C")):X2}";
        string oldCarry = $"(({f} & {cMask}) != 0 ? 1 : 0)";

        if (isMem)
            sb.AppendLine("        byte v = ReadBus(HL);");
        else
            sb.AppendLine($"        byte v = {target};");

        EmitRotateMath(sb, op, oldCarry);   // produces byte r + int cout
```

```csharp
        StringBuilder sb, InstructionModel insn, string pc, string? statusReg, FlagBitMap flags)
    {
        string f = statusReg ?? "F";
        string opName = Unquote(insn.Ops[0].Args[0]);    // "BIT" / "RES" / "SET"
        int bit = int.Parse(insn.Ops[0].Args[1], System.Globalization.CultureInfo.InvariantCulture);
        string target = Unquote(insn.Ops[0].Args[2]);    // "B".."A" or "(HL)"

    /// <summary>BIT y,reg[z]/(HL): Z=(bit==0), P/V=Z, H=1, N=0, S=(y==7 && bit set), C preserved.
    /// X/Y: register operand → operand bits 3/5; (HL) → W=(WZ>>8) bits 3/5. NOT written back.
    /// Cycles: reg 8 T, (HL) 12 T.</summary>
    private static void EmitZ80CbBit(StringBuilder sb, string f, FlagBitMap flags, int bit, string target, bool isMem)
    {
        string sMask = $"0x{(byte)(1 << flags.BitOf("S")):X2}";
        string zMask = $"0x{(byte)(1 << flags.BitOf("Z")):X2}";
        string yMask = $"0x{(byte)(1 << flags.BitOf("Y")):X2}";
        string hMask = $"0x{(byte)(1 << flags.BitOf("H")):X2}";
        string xMask = $"0x{(byte)(1 << flags.BitOf("X")):X2}";
        string pMask = $"0x{(byte)(1 << flags.BitOf("P")):X2}";
        string cMask = $"0x{(byte)(1 << flags.BitOf("C")):X2}";

        if (isMem)
            sb.AppendLine("        byte v = ReadBus(HL);");
        else
            sb.AppendLine($"        byte v = {target};");
        sb.AppendLine($"        bool bitSet = (v & 0x{(1 << bit):X2}) != 0;");
        // X/Y source: (HL) → W (WZ high byte); register → the operand v.
        string xySrc = isMem ? "(byte)(WZ >> 8)" : "v";
        sb.AppendLine($"        int xy = {xySrc};");
        sb.AppendLine($"        {f} = unchecked((byte)(({f} & {cMask})");   // C preserved
        sb.AppendLine($"            | (bitSet ? 0x00 : {zMask})");           // Z = (bit == 0)
        sb.AppendLine($"            | {hMask}");                              // H = 1
        sb.AppendLine($"            | (bitSet ? 0x00 : {pMask})");           // P/V = Z
        sb.AppendLine($"            | ((bitSet && {bit} == 7) ? {sMask} : 0x00)");  // S = (y==7 && bit set)
        sb.AppendLine($"            | ((xy & 0x20) != 0 ? {yMask} : 0x00)");  // Y
        sb.AppendLine($"            | ((xy & 0x08) != 0 ? {xMask} : 0x00)));"); // X
        // Cycles: reg 8, (HL) 12. Z80Cycles returned the 8 base.
        if (isMem)
            sb.AppendLine($"        _cycles += {12 - 1 - 1};   // BIT y,(HL) = 12 T-states");
        else
            sb.AppendLine($"        _cycles += {8 - 1};   // BIT y,r = 8 T-states");
    }
```
